## 项目事实

### 01｜unslothai/unsloth

- 仓库：https://github.com/unslothai/unsloth
- 定位：把大模型、图像与音频模型留在本机运行、训练和部署，并接入代理或应用工作流。
- Star：72,798
- Fork：6,560
- 本期信号：+735 Star（snapshot）
- 许可证：Apache 2.0 and AGPL-3.0
- 能力：在本机运行和训练多类 AI 模型；把本地模型接入 Codex 等代理；从 PDF、CSV、DOCX 构建数据集；导出 GGUF、FP8 等部署格式；通过兼容 OpenAI 的 API 提供模型

### 02｜ToolJet/ToolJet

- 仓库：https://github.com/ToolJet/ToolJet
- 定位：把数据库、API 和 SaaS 数据拖进可视化界面，搭出内部工具、仪表盘与业务应用。
- Star：40,214
- Fork：5,338
- 本期信号：+663 Star（snapshot）
- 许可证：AGPL-3.0
- 能力：拖拽组件搭建多页面内部应用；连接数据库、API、云存储和 SaaS；在应用中运行 JavaScript 与 Python；用内置数据库保存业务数据；通过 Docker 或 Kubernetes 自托管

### 03｜cactus-compute/needle

- 仓库：https://github.com/cactus-compute/needle
- 定位：让小型设备在本地选择并调用工具，把自然语言请求转换成受约束的结构化结果。
- Star：6,777
- Fork：439
- 本期信号：+698 Star（snapshot）
- 许可证：MIT
- 能力：调用已声明的 Python 函数并回传结果；把自由文本抽取为 Pydantic 类型对象；用结构化语法约束工具名和参数输出；从大型工具目录筛出当前相关工具；通过 LoRA 微调并导出单个 .cact 模型
