### 01｜citrolabs/ego-lite

- 仓库：https://github.com/citrolabs/ego-lite
- 定位：让 AI Agent 直接操作你已登录的浏览器，并在独立空间并行完成网页任务，不占用你的标签页
- Star：3,608
- Fork：176
- 本期信号：+1,072 Star（snapshot）
- 许可证：MIT
- 能力：读取页面快照，定位可交互内容；填写、点击、等待并跳转网页；并行运行多个互不干扰的浏览任务；接入 Codex、Claude Code 等 Agent CLI；迁移 Chrome 数据供 Agent 继承登录状态

### 02｜obra/superpowers

- 仓库：https://github.com/obra/superpowers
- 定位：把需求澄清、方案确认、测试驱动开发和代码审查编成一套自动触发的 Agent 研发流程
- Star：261,114
- Fork：23,300
- 本期信号：+523 Star（snapshot）
- 许可证：MIT
- 能力：引导对话，把模糊想法整理成设计文档；拆解计划，写明文件、实现与验证步骤；创建隔离工作区并检查测试基线；分派子 Agent 执行任务并逐项审查；验证测试后提供合并或保留分支选项

### 03｜NousResearch/hermes-agent

- 仓库：https://github.com/NousResearch/hermes-agent
- 定位：把终端、聊天平台、定时任务和可学习技能接到同一个可长期运行的个人 Agent
- Star：220,471
- Fork：41,974
- 本期信号：+462 Star（snapshot）
- 许可证：MIT
- 能力：切换模型提供方，无需修改代码；接入 Telegram、Discord 等消息平台；安排定时任务并把结果发送到指定平台；派生隔离子 Agent 并行处理工作流；迁移 OpenClaw 的设置、记忆、技能与密钥
