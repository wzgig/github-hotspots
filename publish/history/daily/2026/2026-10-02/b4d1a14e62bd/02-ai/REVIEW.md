## 项目事实

### 01｜NVIDIA/OpenShell

- 仓库：https://github.com/NVIDIA/OpenShell
- 定位：为自主 AI Agent 提供受策略约束的隔离运行环境，限制它能访问的文件、网络和凭据
- Star：13,991
- Fork：1,622
- 本期信号：+1,420 Star（snapshot）
- 许可证：Apache-2.0
- 能力：按策略限制 Agent 的文件访问范围；隔离运行 Agent 并限制系统调用；拦截并审核 Agent 的网络连接；在策略变更前检查新增访问权限；通过网关和 SDK 接入沙箱能力

### 02｜mvschwarz/openrig

- 仓库：https://github.com/mvschwarz/openrig
- 定位：把 Claude Code、Codex 等编程 Agent 组织成可持续运行、分工协作的本地团队
- Star：3,694
- Fork：245
- 本期信号：+701 Star（snapshot）
- 许可证：Apache-2.0
- 能力：用 YAML 定义 Agent 团队拓扑；启动并查看多个 Agent 会话；让 Agent 通过消息和队列协作；发现并接管已有 tmux 会话；保存团队状态并在重启后恢复

### 03｜heygen-com/hyperframes

- 仓库：https://github.com/heygen-com/hyperframes
- 定位：把 HTML、CSS、媒体和动画组合成可重复渲染的 MP4 视频，适合人工或 Agent 编排
- Star：55,320
- Fork：5,017
- 本期信号：+614 Star（snapshot）
- 许可证：Apache-2.0
- 能力：用 HTML 和 CSS 编排视频画面；为元素设置时间轴和动画轨道；预览并检查视频组合内容；将组合渲染为 MP4 视频；接入媒体、字幕、图表和转场组件
