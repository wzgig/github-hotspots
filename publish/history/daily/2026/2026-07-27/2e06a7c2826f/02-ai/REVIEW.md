## 项目事实

### 01｜citrolabs/ego-lite

- 仓库：https://github.com/citrolabs/ego-lite
- 定位：让 Codex、Claude Code 等智能体复用你的登录态，在独立浏览空间执行网页任务而不占用当前标签页
- Star：4,441
- Fork：220
- 本期信号：+833 Star（snapshot）
- 许可证：MIT
- 能力：继承 Chrome 登录、Cookie、扩展和书签；分配互不干扰的独立浏览空间；并行执行多个智能体网页任务；调用快照、填写、点击和导航工具；接管或停止正在运行的智能体空间

### 02｜alibaba/open-code-review

- 仓库：https://github.com/alibaba/open-code-review
- 定位：把 Git 变更交给受约束的审查流水线和智能体，返回定位到具体代码行的结构化意见
- Star：13,756
- Fork：939
- 本期信号：+776 Star（snapshot）
- 许可证：Apache-2.0
- 能力：审查暂存、未暂存和未跟踪变更；比较分支范围或指定提交；扫描没有有效差异的完整文件；搜索代码库补充跨文件上下文；恢复中断的分支或提交审查

### 03｜OtterMind/Chat2DB

- 仓库：https://github.com/OtterMind/Chat2DB
- 定位：把多种数据库连接、SQL 编辑和自选模型助手放进同一个本地工作区
- Star：27,081
- Fork：2,941
- 本期信号：+397 Star（snapshot）
- 许可证：source-available license
- 能力：连接多种数据库并浏览元数据；编辑、补全、格式化并执行 SQL；生成、解释和优化 SQL；管理表和对象并就地编辑数据；导入导出数据并制作图表看板
