## 项目事实

### 01｜paperclipai/paperclip

- 仓库：https://github.com/paperclipai/paperclip
- 定位：把多个 AI Agent 组织起来，按目标分工、执行、审批并追踪成本
- Star：87,223
- Fork：15,422
- 本期信号：+1,838 Star（snapshot）
- 许可证：MIT
- 能力：创建组织目标并分派给多个 Agent；按角色、权限和汇报关系组织 Agent；用心跳任务定时唤醒 Agent 执行工作；设置预算并在超支时暂停任务；通过审批、日志和工作产物审核结果

### 02｜vectorize-io/hindsight

- 仓库：https://github.com/vectorize-io/hindsight
- 定位：给 AI Agent 加上会保存、检索并整理长期记忆的记忆层
- Star：32,120
- Fork：3,566
- 本期信号：+1,952 Star（snapshot）
- 许可证：MIT
- 能力：保存用户、项目或 Agent 的长期记忆；按语义、关键词、关系和时间检索记忆；基于已有记忆生成深入分析；把记忆自动接入现有 LLM 客户端；通过 MCP 暴露记忆工具

### 03｜rohitg00/ai-engineering-from-scratch

- 仓库：https://github.com/rohitg00/ai-engineering-from-scratch
- 定位：用可运行的课程，从数学基础一路构建 LLM、Agent 与 AI 工具
- Star：58,342
- Fork：10,118
- 本期信号：+637 Star（snapshot）
- 许可证：MIT
- 能力：按阶段学习数学、机器学习和深度学习；从零实现算法，再用框架完成同类任务；运行每课代码并保存命令和结果证据；使用 AI tutor 获取分阶段学习路径；产出可复用的 prompt、skill、agent 或 MCP server
