GitHub Hotspots 周报第7期。把这一周的 7 个热点压缩成一组可收藏的项目卡：先看用途，再看为什么值得关注。

先看结论：
01｜deepseek-ai/deepseek-harness：把 Agent 运行框架拆成插件：deepseek-harness 用统一架构启动本地 Web 界面，并为后续能力扩展留出空间。
02｜mattpocock/skills：把工程实践装进编程 Agent：skills 用可组合技能约束需求澄清、测试、调试、评审和架构改进。
03｜public-apis/public-apis：按领域整理可公开调用的 API，public-apis 让你比较认证、HTTPS 与 CORS，再为产品原型挑数据源。
04｜cathrynlavery/diagram-design：把架构、流程或数据关系交给 Agent，diagram-design 会生成可离线打开的 HTML 与 SVG，并按品牌样式重绘。
05｜cordiverse/cordis：Cordis 是研究“时空可组合性”的元框架入口，当前 README 主要提供论文与入门文档，实际用法仍需继续核对。
06｜NousResearch/hermes-agent：把长期记忆、技能学习和多渠道消息接入同一个 Agent，hermes-agent 可跨会话工作并把定时任务送到聊天平台。
07｜obra/superpowers：让编程 Agent 按一套研发方法工作：superpowers 从需求澄清一路管到计划、测试、子代理实现、评审和收尾。
