## 项目事实

### 01｜firecrawl/firecrawl

- 仓库：https://github.com/firecrawl/firecrawl
- 定位：输入网页或搜索需求，返回适合程序和 AI 使用的 Markdown、结构化数据或截图
- Star：167,819
- Fork：9,399
- 本期信号：+4,331 Star（snapshot）
- 许可证：AGPL-3.0
- 能力：搜索网页并获取结果正文；将网址转成 Markdown 或 JSON；点击、滚动或填写页面后再抓取；批量抓取多个网址；发现并遍历整站链接

### 02｜TencentCloud/TencentDB-Agent-Memory

- 仓库：https://github.com/TencentCloud/TencentDB-Agent-Memory
- 定位：把对话、文档和代码沉淀为团队可审核、共享并分配给不同 Agent 的记忆资产
- Star：21,996
- Fork：2,014
- 本期信号：+3,695 Star（snapshot）
- 许可证：MIT
- 能力：提炼对话中的事实、偏好和决策；抽取并管理可复用技能；把文档整理成关联 Wiki；索引代码符号和调用关系；为不同 Agent 分配记忆资产

### 03｜semantica-agi/semantica

- 仓库：https://github.com/semantica-agi/semantica
- 定位：在现有 LLM 与 Agent 下方建立可查询的上下文图，追踪每项事实和决策的来源
- Star：7,943
- Fork：814
- 本期信号：+5,339 Star（trending）
- 许可证：MIT
- 能力：导入文件、数据库和数据平台内容；抽取实体、关系、事件和三元组；检测冲突并合并重复实体；运行可解释的图规则推理；导出图谱、决策和来源记录

### 04｜NousResearch/hermes-agent

- 仓库：https://github.com/NousResearch/hermes-agent

### 05｜addyosmani/agent-skills

- 仓库：https://github.com/addyosmani/agent-skills
