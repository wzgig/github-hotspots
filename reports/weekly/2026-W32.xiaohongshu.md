- firecrawl：输入网址或数据需求，返回适合程序和智能体使用的 Markdown、结构化数据或网页截图。

01｜reverse-skill
为代码智能体分流逆向与授权安全任务，并串起工具检查、取证和报告交付。

它能做什么：

- 分流 APK、二进制、前端加密与竞赛任务
- 检查本机可用工具并刷新索引
- 建立授权范围、时间线和工作项
- 调用场景技能、脚本与 MCP 工具
- 复核证据关系并整理交付报告

核心亮点：先定范围，再按场景路由。任务先经过全局规则和授权范围检查，再由主路由选择场景技能与工具，过程同步记录时间线和证据关系，最后形成报告与工作日志。

适合谁：需要让代码智能体协助逆向、授权渗透、取证复核或安全竞赛的研究者与团队。
使用前准备：需要 Java / JDK、Node.js 22.12+、Python 3.x，以及兼容的代码 AI 客户端。

使用提醒：执行目标前需完成授权范围与网络配置；客户端适配应保持可选，不进入核心路由。

许可证：MIT（**CTF-Sandbox-Orchestrator/**: **GNU GPLv3**）

02｜TencentDB-Agent-Memory
把团队的对话、文档和代码沉淀成可审查、可共享、可分配给不同智能体的记忆资产。

它能做什么：

- 提取对话中的偏好、决策与事实
- 沉淀带版本和验证规则的技能
- 把文档整理成可检索的 Wiki
- 索引代码符号、调用关系与影响路径
- 为不同智能体绑定指定记忆资产

核心亮点：把团队经验做成智能体装备。系统把经验拆成对话记忆、技能、Wiki 和代码图，再通过所有权、版本、可见范围与绑定关系决定谁能使用，让新智能体从既有上下文开始工作。

适合谁：需要让多个智能体继承项目经验，并统一管理知识、技能和访问权限的个人开发者或团队。
使用前准备：需填写两组 LLM 参数，并启动 memory-core、memory-hub 与 proxy 服务。

使用提醒：Wiki 与代码图异步构建；代码图优先支持公开 HTTPS 仓库，自动记忆路由仍在迭代。

许可证：MIT

03｜skills
给编程智能体补上一组可组合的工程技能，用于澄清需求、测试、调试和控制代码复杂度。

它能做什么：

- 追问需求并补全设计分支
- 建立项目术语表与决策记录
- 按红绿重构循环编写代码
- 分阶段诊断缺陷与性能回退
- 扫描代码库中的架构改进机会

核心亮点：小技能组合，而非接管流程。每项技能只负责一类工程纪律，可由用户主动调用或由模型按任务触发；它们能组合进现有项目，也能按团队习惯修改，而不要求交出整个研发流程。

适合谁：希望保留开发控制权，并让代码智能体按工程方法完成需求澄清、实现和审查的开发者。
使用前准备：可通过 Claude Code 插件或 skills 安装器接入，并在每个仓库运行一次 setup-matt-pocock-skills。

使用提醒：插件方式为托管只读包，安装器方式会复制可编辑文件；两种方式同时安装会产生重复技能。

许可证：MIT

04｜superpowers
把编程智能体从需求澄清带到分支收尾，用自动触发的技能约束设计、实现、测试和审查。

它能做什么：

- 澄清想法并分段确认设计
- 创建隔离工作区并检查测试基线
- 把方案拆成可逐项执行的计划
- 派发子智能体并检查规格与代码质量
- 执行测试驱动开发并验证完成状态

核心亮点：从讨论到交付的强制流程。智能体不会直接写代码，而是先形成设计与计划，得到确认后再分派任务、测试和审查；收尾时重新验证，并把合并、提审或保留分支交给用户决定。

适合谁：想让编程智能体长时间推进功能，同时保留设计确认、测试反馈和合并决策权的开发者。
使用前准备：需按所用编程客户端分别安装；同时使用多个客户端时，每个客户端都要单独接入。

使用提醒：不同客户端需分别安装；可选视觉组件默认会加载远程徽标并附带版本信息，可通过环境变量关闭。

许可证：MIT

05｜book-to-skill
把技术书、文档目录或资料集合整理成按需加载的智能体技能，提问时只读取相关章节。

它能做什么：

- 读取书籍、目录或多份资料
- 提取干净文本与文档元数据
- 生成技能入口、章节和术语表
- 整理模式、算法与速查规则
- 把新增资料合并进已有技能

核心亮点：先结构化一次，再按需读章节。确定资料来源后，Python 提取器负责清洗文本，生成流程再整理核心模型、章节、术语和速查文件；后续提问只加载相关部分，避免反复遍历整份资料。

适合谁：经常查阅技术书、内部文档、规范或论文，希望在编码时直接向智能体提问的使用者。
使用前准备：需有支持 Agent Skills 格式的客户端；不同文件格式可能需要安装对应提取器。

使用提醒：只应处理你有权使用的资料；第三方版权书籍生成的技能应保持私有，不要公开或分享。

许可证：MIT（**not** to any book or document you process with it.）

06｜hermes-agent
让一个智能体跨终端和聊天平台持续工作，并从历史会话中形成记忆、技能与定时自动化。

它能做什么：

- 记录并检索跨会话记忆
- 从工作经验创建和改进技能
- 在多个聊天平台延续同一对话
- 按自然语言安排定时任务
- 派发隔离子智能体并行处理工作

核心亮点：会积累经验的跨平台智能体。它把会话记忆、用户模型和技能学习放进同一循环，既能从终端使用，也能由网关连接聊天平台；复杂任务还可交给子智能体并行执行或设为定时任务。

适合谁：希望把个人智能体放在本机或云端持续运行，并通过聊天工具远程交办任务的使用者。
使用前准备：需完成模型提供商、工具和消息平台配置；各操作系统应使用 README 对应的安装路径。

使用提醒：Termux 不能使用完整依赖集，因为其中包含不兼容的语音依赖，需改用专门的 termux 安装项。

许可证：MIT

07｜firecrawl
输入网址或数据需求，返回适合程序和智能体使用的 Markdown、结构化数据或网页截图。

它能做什么：

- 搜索网页并提取结果全文
- 把单个页面转换成多种数据格式
- 发现并抓取网站内的页面
- 批量异步处理多个网址
- 按描述自主寻找并整理网页数据

核心亮点：把动态网页变成智能体上下文。它把搜索、抓取、站点遍历和页面交互放在同一接口下，可先操作动态页面再提取内容，并输出 Markdown、结构化数据或截图供程序继续处理。

适合谁：需要为智能体、搜索产品或数据管道接入实时网页内容，并减少自建抓取环节的开发者。
使用前准备：使用托管服务需取得 Firecrawl API Key；本地运行或自托管需按对应文档准备环境。

使用提醒：开源版与云端功能不同；抓取者需遵守网站政策、隐私条款和 robots.txt 指令。

许可证：AGPL-3.0（The SDKs and some UI components are licensed under the MIT License.）
