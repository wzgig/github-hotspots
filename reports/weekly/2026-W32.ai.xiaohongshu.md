01｜reverse-skill
把逆向、安全测试或 CTF 任务交给编程 Agent，按授权范围匹配方法、工具和留证流程

它能做什么：

- 识别 APK、二进制、前端 JS 等任务类型
- 检查本机可用工具并刷新工具索引
- 初始化授权范围、时间线和工作项
- 路由到逆向、取证或安全测试技能
- 整理证据、发现、路径与交付报告

核心亮点：先定范围，再路由工具。任务先经过全局规则和授权范围检查，再由统一路由配置选择场景技能与本机工具，最终把操作过程沉淀为时间线、证据链和报告。

适合谁：使用编程 Agent 处理已授权逆向、渗透测试、安全研究或 CTF 任务的人员
使用前准备：需要 Java/JDK、Node.js 22.12+、Python 3.x，以及兼容的代码 AI 客户端。

使用提醒：必须先完成授权范围与网络配置，未就绪前不对目标执行操作。

许可证：MIT（are subject to their respective official licenses）

02｜TencentDB-Agent-Memory
把对话、文档和代码变成团队可审核、共享并分配给不同 Agent 的记忆资产

它能做什么：

- 提取对话中的事实、偏好和决策
- 沉淀带版本与验证规则的技能
- 把文档生成带链接关系的 Wiki
- 索引代码符号、调用关系和影响路径
- 审核并绑定资产给指定 Agent

核心亮点：给 Agent 团队装载记忆。系统把聊天、技能、文档和代码统一登记为记忆资产，再用所有权、版本、可见性和绑定规则决定谁能使用，让新 Agent 从已有经验开始工作。

适合谁：需要让多个 Agent 继承项目背景、工作经验和代码知识的个人开发者或团队
使用前准备：部署前需填写记忆组与代理组两套 LLM 参数，并启动 memory-core、memory-hub 和 proxy。

使用提醒：Wiki 与 CodeGraph 异步构建；私有仓库支持和自动记忆路由仍在完善。

许可证：MIT

03｜superpowers
让编程 Agent 先澄清需求、确认设计和拆分计划，再按测试与审查流程完成代码

它能做什么：

- 通过提问把模糊想法整理成设计
- 生成包含文件与验证步骤的实施计划
- 为每项任务派发独立子 Agent
- 按红绿重构循环先写测试再实现
- 完成测试后提供合并或保留选项

核心亮点：把编码变成受控研发流程。技能会按阶段自动触发：先讨论并确认设计，再拆分计划、测试实现、审查结果，最后验证分支状态并让用户决定如何交付。

适合谁：希望编程 Agent 遵循需求确认、规划、测试、审查和收尾流程的软件开发者
使用前准备：需要在所用编程客户端中单独安装；同时使用多个客户端时要分别安装。

使用提醒：不同编程客户端需分别安装；可选视觉伴侣默认会加载远程标识，可通过环境变量关闭。

许可证：MIT

04｜AI-For-Beginners
从基础概念到可运行 Notebook，带初学者按课程练习神经网络、视觉、文本和 AI 伦理

它能做什么：

- 学习知识表示与专家系统基础
- 运行神经网络和深度学习 Notebook
- 练习图像分类、检测与分割
- 实践文本表示、循环网络和 Transformer
- 讨论多智能体方法与负责任 AI

核心亮点：课程、代码与实验同步推进。每节课把预读材料、理论说明、可执行 Notebook、测验和部分实验放在一起，学习者可在 PyTorch 或 TensorFlow 路线中边理解边操作。

适合谁：准备系统入门人工智能，并希望边学概念边运行代码和完成实验的学习者与教师
使用前准备：需按课程设置说明配置开发环境，并在 VS Code、Codespace 或本地运行 Notebook。

使用提醒：不覆盖经典机器学习、商业应用、云端框架、聊天机器人和深度数学。

许可证：MIT

05｜hermes-agent
通过终端或聊天平台调用 AI Agent，让它记住过往会话、积累技能并定时执行任务

它能做什么：

- 切换不同模型提供商而无需改代码
- 从经验中创建并更新可复用技能
- 搜索历史会话并恢复跨会话背景
- 调度定时任务并发送到消息平台
- 派发隔离子 Agent 并行处理任务

核心亮点：让 Agent 从使用经历中成长。它把会话记忆、用户模型和技能形成闭环：完成复杂任务后沉淀方法，后续使用时继续修正，并通过历史搜索把经验带入新会话。

适合谁：需要长期运行个人 Agent，并从终端或消息平台安排研究、开发和自动化任务的用户
使用前准备：安装后需选择并配置模型提供商；使用消息平台时还要完成 gateway 设置。

使用提醒：Termux 的完整依赖含不兼容语音组件，需使用专用安装路径。

许可证：MIT

06｜airllm
把大模型按层送入显存，让显存较小的单卡也能运行远超其容量的模型推理

它能做什么：

- 按层拆分并保存下载的模型
- 逐层加载权重完成文本生成
- 通过 AutoModel 自动识别模型类型
- 启用预取重叠模型加载与计算
- 选择块级压缩减少加载数据量

核心亮点：用磁盘与分层加载换显存。AirLLM 先把模型拆成分层文件，推理时只将当前层载入 GPU，计算后再切换下一层，因此显存需求取决于单层大小而非完整模型。

适合谁：显存有限但需要在本地试跑大型开放模型，并能接受磁盘换显存方式的研究者和开发者
使用前准备：需安装 airllm；GPU 示例依赖相应 CUDA 环境，macOS 还需 MLX、PyTorch 和 Apple silicon。

使用提醒：首次推理会按层拆分并保存模型，需要为模型文件和缓存预留足够磁盘空间。

许可证：Apache-2.0

为什么本期上榜：GitHub Trending 显示过去 7 天 +5,711 Star

07｜firecrawl
输入网页或搜索需求，返回适合程序和 AI 使用的 Markdown、截图或结构化数据

它能做什么：

- 搜索网络并返回结果页完整内容
- 把网页转换为 Markdown 或结构化 JSON
- 抓取整站并异步汇总各页面
- 发现站点中的全部链接
- 操作页面后再读取目标内容

核心亮点：从网页入口直接交付可用数据。同一套接口覆盖搜索、单页抓取、整站爬取、链接发现和页面交互，并把结果整理成 Markdown、截图或结构化数据供后续流程使用。

适合谁：需要为 AI Agent、搜索、研究或数据管道持续接入网页内容的开发者
使用前准备：使用托管接口需注册并获取 API Key；本地运行或自托管需按对应指南部署。

使用提醒：抓取者需遵守网站隐私政策与使用条款；默认遵循 robots.txt。

许可证：AGPL-3.0（The SDKs and some UI components are licensed under the MIT License.）
