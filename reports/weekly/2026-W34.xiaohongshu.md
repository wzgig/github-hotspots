01｜deepseek-harness
把 Agent 运行框架拆成插件：deepseek-harness 用统一架构启动本地 Web 界面，并为后续能力扩展留出空间。

它能做什么：

- 通过 npx 启动本地 Web 界面
- 从源码构建并运行 dsh
- 把框架能力组织为插件
- 为插件仓库提供发现标签

核心亮点：万物皆插件的框架结构。核心不是预置一套固定 Agent，而是把框架组件放进“万物皆插件”的结构；底层由 Cordis 驱动，运行入口可直接打开本地 Web 界面。

适合谁：适合开发 Agent 框架、插件体系，或需要研究 Cordis 组合架构的开发者。
使用前准备：通过 npm 运行需安装 Node.js；从源码运行还需要 pnpm。

使用提醒：仍处于开发者预览阶段，快速迭代中会出现破坏兼容性的变更。

许可证：MIT

02｜skills
把工程实践装进编程 Agent：skills 用可组合技能约束需求澄清、测试、调试、评审和架构改进。

它能做什么：

- 追问需求并形成共享术语
- 用红绿重构推进测试开发
- 按阶段诊断难复现缺陷
- 把对话整理成规格与任务
- 扫描代码库中的架构改进点

核心亮点：小而可组合的工程技能。每项技能只负责一类工程纪律，可按任务组合：先对齐需求和术语，再进入测试、调试、架构或评审流程，避免由一套大流程接管整个项目。

适合谁：适合希望保留流程控制，并让编程 Agent 按工程方法处理真实项目的开发者。
使用前准备：安装后需在每个仓库运行一次 /setup-matt-pocock-skills，配置问题跟踪器、标签和文档位置。

使用提醒：Claude Code 插件是只读托管包；skills.sh 会复制可编辑文件，两种方式同时安装会产生重复技能。

许可证：MIT

03｜public-apis
按领域整理可公开调用的 API，public-apis 让你比较认证、HTTPS 与 CORS，再为产品原型挑数据源。

它能做什么：

- 按领域浏览公共 API
- 查看每项 API 的用途说明
- 比较认证方式与密钥要求
- 核对 HTTPS 与 CORS 支持
- 从索引跳转到接口文档

核心亮点：带接入条件的 API 索引。它不代替接口本身，而是把不同领域的 API 汇总成表格，并并列展示用途、认证方式、HTTPS 和 CORS，方便接入前快速筛选。

适合谁：适合为应用原型、课程作业或集成方案寻找外部数据接口的开发者和产品团队。

使用提醒：列表由社区人工维护；不同 API 的认证、HTTPS 与 CORS 状态各异，接入前仍需逐项核验。

许可证：MIT

04｜diagram-design
把架构、流程或数据关系交给 Agent，diagram-design 会生成可离线打开的 HTML 与 SVG，并按品牌样式重绘。

它能做什么：

- 选择适合内容的图表类型
- 从网站提取配色与字体
- 重绘 draw.io 与 Mermaid 源
- 导出独立 SVG 或 PNG
- 检查对比度与无障碍标注

核心亮点：先理解行为，再选择布局。遇到队列、策略链或安全边界时，它先判断语义模式，再选择最接近的图表类型；输出沿用统一品牌变量，并保持自包含、可离线打开。

适合谁：适合需要为技术文档、博客、演示稿或社交图片制作一致风格图表的内容作者和工程团队。
使用前准备：需安装到 Claude Code、Codex、Factory Droid 或 Pi；导出 PNG 还需 Playwright 与 Chromium。

使用提醒：静态且无脚本的 HTML 是默认输出；列表、前后对比或单个形状更适合文字或表格，不建议强行画图。

许可证：MIT

06｜hermes-agent
把长期记忆、技能学习和多渠道消息接入同一个 Agent，hermes-agent 可跨会话工作并把定时任务送到聊天平台。

它能做什么：

- 切换不同模型提供方
- 从经验创建并更新技能
- 检索过去会话与长期记忆
- 调度定时任务并推送结果
- 派生隔离子代理并行处理工作

核心亮点：会持续积累的学习闭环。它把记忆、技能和用户模型连成闭环：复杂任务后生成技能，使用中继续修订，并搜索历史会话，让后续任务复用已有经验。

适合谁：适合需要长期运行个人 Agent，并希望在终端、云主机和聊天平台之间延续任务的用户。
使用前准备：安装后需选择模型提供方；消息渠道还要配置 gateway。Windows 安装器会补齐 Python、Node.js 等依赖。

使用提醒：Termux 需使用精简依赖；消息平台、模型和外部工具仍要分别配置，某些服务需要账号或 API Key。

许可证：MIT

07｜superpowers
让编程 Agent 按一套研发方法工作：superpowers 从需求澄清一路管到计划、测试、子代理实现、评审和收尾。

它能做什么：

- 先通过提问澄清需求与设计
- 把设计拆成可执行实现计划
- 用子代理按任务分段实现
- 强制红绿重构测试循环
- 在完成前执行评审与验证

核心亮点：自动触发的研发方法链。技能会随任务阶段自动介入：先提问形成设计，再拆分计划，随后由子代理逐项实现，并在每个阶段加入测试、规格检查和代码评审。

适合谁：适合希望编程 Agent 严格按需求、计划和测试推进中大型开发任务的个人与团队。
使用前准备：需按所用编码 Agent 分别安装；多个宿主之间不会共享安装状态。

使用提醒：工作流把测试、评审和完成验证设为必经步骤；Hermes 长会话压缩后可能丢失启动引导，需新开会话。

许可证：MIT
