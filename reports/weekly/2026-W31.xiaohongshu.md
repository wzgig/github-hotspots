# 正文

别只看 Star。这期把上榜项目翻成三件能直接判断的事：它做什么、能帮你完成什么、适不适合你。

先看结论：
- buzz：让人类与 AI 代理在自托管协作空间里共同讨论、改代码、跑流程，并保留统一审计记录
- bitchat：在断网时通过蓝牙网状网络聊天，联网后再借助 Nostr 中继扩展到远距离通信
- skills：把需求澄清、测试驱动、故障诊断和代码评审整理成可组合的编码代理工作流
- OmniRoute：把多个模型供应商接到同一个兼容接口，并按额度、成本、延迟或故障情况自动切换路线
- open-code-review：读取代码差异并结合仓库上下文生成精确到行的审查意见，也能扫描没有有效差异的完整文件
- ego-lite：让外部 AI 代理在独立浏览空间里复用你的登录状态执行网页任务，同时不占用正在操作的标签页

01｜buzz
让人类与 AI 代理在自托管协作空间里共同讨论、改代码、跑流程，并保留统一审计记录

它能做什么：

- 搜索历史对话并附上相关讨论依据
- 接收补丁并在频道中组织代码评审
- 触发消息、定时或 Webhook 工作流
- 集中检索对话、Git 事件和审批记录
- 让多个代理创建频道、画布和协作流程

核心亮点：所有协作动作共用事件日志。人、代理、工作流和 Git 操作都以签名事件进入同一日志，沿用一致的身份、检索与审计方式，让一次变更的讨论、补丁和批准不再散落各处。

适合谁：希望自托管团队协作空间，并让 AI 代理参与代码评审、发布和项目沟通的研发团队
使用前准备：源码运行需要 Docker 与 Hermit，或准备 Rust、Node、pnpm 和 just；代理还需配置 BUZZ_PRIVATE_KEY。

使用提醒：项目明确尚未完成；移动客户端、工作流审批门和语音协作仍在接线，愿景栏目中的能力尚无代码，重要操作应保留人工参与。

许可证：Apache-2.0

GitHub 搜索：block/buzz

02｜bitchat
在断网时通过蓝牙网状网络聊天，联网后再借助 Nostr 中继扩展到远距离通信

它能做什么：

- 发现附近设备并建立蓝牙网状连接
- 通过周边设备多跳转发本地消息
- 自动选择蓝牙或 Nostr 发送私信
- 按地理坐标进入不同范围的地域频道
- 三击执行紧急清除本机数据

核心亮点：蓝牙与 Nostr 双路传输。私信会优先使用已有蓝牙加密会话，蓝牙不可用时切换到 Nostr 中继，两种方式都不可用则排队等待，恢复连接后再自动投递。

适合谁：需要在灾害、偏远地区或临时活动现场离线沟通，也希望联网后参与地域群聊的用户
使用前准备：可从应用商店安装；从源码构建需使用 Xcode，签名设备版本还要配置 Apple Developer Team ID。

使用提醒：网状网络会使用由身份密钥派生的持久设备标识；Nostr 私信格式仅与 BitChat 客户端互通，存储转发邮件不具备实时会话的前向保密。

许可证：Unlicense

为什么本期上榜：过去 7 天净增 +5,270 Star（历史快照核验）
GitHub 搜索：permissionlesstech/bitchat

03｜skills
把需求澄清、测试驱动、故障诊断和代码评审整理成可组合的编码代理工作流

它能做什么：

- 追问需求并补齐尚未决定的设计分支
- 建立项目术语表与架构决策记录
- 按红绿重构循环实现功能或修复缺陷
- 复现并缩小疑难故障后再验证修复
- 分别检查代码规范与需求实现偏差

核心亮点：小技能拼成工程流程。每项技能只封装一种工程纪律，可由用户主动启动，也可由模型按任务调用；它们能组合进规格、工单、实现、测试和评审流程，同时仍允许团队自行修改。

适合谁：经常使用 Claude Code、Codex 等编码代理，并希望保留流程控制权的软件工程师
使用前准备：需选择 Claude Code 插件或 skills.sh 安装方式，并在每个仓库运行一次 /setup-matt-pocock-skills 完成配置。

使用提醒：两种安装方式同时使用会产生重复技能；Claude Code 插件是托管只读包，而 skills.sh 复制的文件需由使用者自行选择更新时间。

许可证：MIT

为什么本期上榜：过去 7 天净增 +10,615 Star（历史快照核验）
GitHub 搜索：mattpocock/skills

04｜OmniRoute
把多个模型供应商接到同一个兼容接口，并按额度、成本、延迟或故障情况自动切换路线

它能做什么：

- 接入兼容 OpenAI 接口的模型工具
- 按成本、延迟或剩余额度选择模型
- 在供应商失败或限额后自动回退
- 组合多种压缩引擎缩减工具输出
- 通过 MCP、A2A 或远程 CLI 管理网关

核心亮点：按实时状态自动换模型。auto 会依据连接健康、额度、成本、延迟和成功率等状态为候选模型评分；自定义 combo 还能规定顺序、负载分配、上下文接力或多模型汇总路线。

适合谁：需要让编码工具共用多个模型供应商，并集中管理额度、路由与调用成本的 AI 开发者
使用前准备：快速安装需 Node.js 与 npm；启动本地服务后，还要连接供应商并把编码工具的基础地址和密钥指向 OmniRoute。

使用提醒：记忆功能默认关闭；原生 SQLite 不可用时会回退到其他引擎；当前 CLI 与网页面板由同一进程提供，没有独立的纯 CLI 包。

许可证：MIT

为什么本期上榜：过去 7 天净增 +7,015 Star（历史快照核验）
GitHub 搜索：diegosouzapw/OmniRoute

05｜open-code-review
读取代码差异并结合仓库上下文生成精确到行的审查意见，也能扫描没有有效差异的完整文件

它能做什么：

- 审查暂存、未暂存和未跟踪的改动
- 比较分支或指定提交并生成评论
- 扫描整个仓库、目录或单个文件
- 按文件特征匹配对应审查规则
- 保存审查会话并恢复中断的任务

核心亮点：硬约束流程配合动态代理。工程逻辑负责选文件、分组、匹配规则和定位评论，代理负责检索上下文与判断缺陷；两者分工，避免纯提示词流程在大改动中跳过文件或漂移位置。

适合谁：需要在本地、合并请求或持续集成流程中审查代码，并减少漏检和评论错位的研发团队
使用前准备：需要 Git >= 2.41；默认模式还需配置可用的 LLM 供应商与模型，委托模式可改用编码代理自己的模型。

使用提醒：项目明确以精确率优先，因此召回率低于通用代理；默认审查依赖已配置模型，委托模式则由外部编码代理实际执行判断。

许可证：Apache-2.0

为什么本期上榜：过去 7 天净增 +4,592 Star（历史快照核验）
GitHub 搜索：alibaba/open-code-review

06｜ego-lite
让外部 AI 代理在独立浏览空间里复用你的登录状态执行网页任务，同时不占用正在操作的标签页

它能做什么：

- 读取页面快照并定位可交互内容
- 填写表单、点击元素并等待页面变化
- 并行运行多个互不抢占标签页的任务
- 调用截图、导航和页面内脚本工具
- 随时接管或停止代理所在的浏览空间

核心亮点：同一浏览器里的隔离空间。每个代理在自己的 Space 中读取页面快照并执行 JavaScript 工具，多个任务可并行运行；用户仍使用原有标签页，也能看到、接管或终止代理任务。

适合谁：希望让 Codex、Claude Code 等外部代理处理已登录网页任务，同时继续正常浏览的 macOS 用户
使用前准备：目前需要 macOS，并安装 ego lite 应用与 ego-browser 技能；如需复用现有登录，可在首次启动时选择迁移 Chrome 数据。

使用提醒：Windows 与 Linux 仍在路线图中；经验积累与复用工作流属于即将推出的能力，当前不能按已完成功能使用。

许可证：MIT

为什么本期上榜：过去 7 天净增 +3,829 Star（历史快照核验）
GitHub 搜索：citrolabs/ego-lite

07｜jcode
在终端里运行可记忆、可并行协作的编码代理，并统一接入多种模型、MCP 工具与浏览器操作

它能做什么：

- 启动交互式终端或单次无交互任务
- 搜索并注入与当前对话相关的记忆
- 生成代理团队并行处理同一仓库任务
- 切换 OAuth、API 或本地模型供应商
- 通过 Firefox 执行点击、填写和截图

核心亮点：记忆、会话与代理群协作。每轮对话可写入语义记忆图，后续自动检索相关记录；服务器还能协调同仓库的多个代理，在文件被其他代理修改时通知受影响会话并提供沟通通道。

适合谁：需要同时运行多个编码代理、切换模型供应商，并希望控制内存占用与历史上下文的终端用户
使用前准备：可用安装脚本或包管理器安装；源码构建需要 Rust。使用模型前还需登录受支持供应商或配置兼容接口与模型。

使用提醒：内置浏览器后端目前仅接通 Firefox；MCP 当前只支持 stdio 服务，HTTP 与 SSE 配置会被识别后跳过；自我修改模式建议使用能力较强的模型。

许可证：MIT

GitHub 搜索：1jehuang/jcode
