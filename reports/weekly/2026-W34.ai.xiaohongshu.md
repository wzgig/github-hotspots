# 正文

2026-08-23 · W007 · AI 专题榜

AI 项目的名字往往很抽象。这一期不堆术语，只讲清它替谁做什么、能完成哪些任务，以及是否值得加入你的工具箱。

先看结论：
- deepseek-harness：用插件化架构组装 AI Agent，并通过本地网页界面运行和扩展功能
- superpowers：让编程 Agent 先澄清需求，再按设计、测试、审查和收尾流程完成开发
- hermes-agent：把终端、聊天平台、长期记忆和定时任务接进同一个可持续学习的 Agent
- MoneyPrinterTurbo：输入主题或关键词，自动完成脚本、素材、配音、字幕和背景音乐并合成短视频
- semantica：把分散数据建成可查询的上下文图，并记录 AI 决策依据、因果关系和来源
- OpenViking：把 Agent 的记忆、资料和技能放进可浏览的虚拟文件系统，按任务需要逐层读取
- firecrawl：把网页搜索、抓取和交互统一成 API，返回可供程序与 AI 使用的 Markdown 或结构化数据

01｜deepseek-harness
用插件化架构组装 AI Agent，并通过本地网页界面运行和扩展功能

它能做什么：

- 安装并启动本地网页界面
- 关闭启动时自动打开浏览器
- 从源码构建可运行产物
- 为项目编写和发布插件
- 通过架构文档了解组件设计

核心亮点：所有能力都按插件组织。项目把功能统一放进插件架构，由 Cordis 提供组合基础；开发者可运行网页界面，也能按插件方式继续扩展 Agent。

适合谁：想按插件拆分 Agent 能力，并在本地网页界面调试的开发者
使用前准备：直接运行需要安装 Node.js；从源码运行还需使用 pnpm 安装依赖并完成构建。

使用提醒：目前处于开发者预览阶段，迭代较快，并会出现破坏兼容性的变更。

许可证：MIT

02｜superpowers
让编程 Agent 先澄清需求，再按设计、测试、审查和收尾流程完成开发

它能做什么：

- 追问并整理模糊的软件需求
- 生成可逐项执行的实现计划
- 创建隔离工作区并验证测试基线
- 按测试先行方式完成实现
- 审查代码并给出合并或保留选项

核心亮点：把工程纪律写进 Agent 流程。技能会按任务自动触发，把头脑风暴、计划、测试先行、子 Agent 开发、代码审查和分支收尾串成强制工作流。

适合谁：希望编程 Agent 遵循固定工程方法，而不是收到需求后直接写代码的开发者
使用前准备：需按所用编程 Agent 分别安装插件；同时使用多个运行环境时需要逐一安装。

使用提醒：设计需要用户确认后才制定计划，执行也需明确开始；关键审查问题会阻止流程继续。

许可证：MIT

03｜hermes-agent
把终端、聊天平台、长期记忆和定时任务接进同一个可持续学习的 Agent

它能做什么：

- 切换模型服务而无需修改代码
- 从历史会话检索相关信息
- 创建并持续改进任务技能
- 定时执行报告、备份或审计
- 派出隔离子 Agent 并行处理任务

核心亮点：让经验沉淀为记忆和技能。它把会话搜索、用户画像、长期记忆和技能创建组成学习闭环，任务经验可在后续会话中被检索，并继续改进技能。

适合谁：需要让个人 Agent 长期记忆、远程接收任务并在不同运行环境执行工作的用户
使用前准备：安装后需选择模型服务并配置相应凭据；部分搜索、图像、语音和浏览器工具也需要服务授权。

使用提醒：部分云端工具依赖对应服务凭据；Termux 的完整依赖包含与 Android 不兼容的语音组件。

许可证：MIT

04｜MoneyPrinterTurbo
输入主题或关键词，自动完成脚本、素材、配音、字幕和背景音乐并合成短视频

它能做什么：

- 生成视频脚本或接收自定义脚本
- 匹配本地、在线和生成式素材
- 合成配音并实时试听音色
- 生成并调整字幕显示样式
- 批量生成成片并选择结果

核心亮点：把短视频制作串成自动流程。项目从主题或关键词出发，依次生成脚本、提炼素材词、准备画面、合成语音与字幕，再加入背景音乐输出成片。

适合谁：需要批量制作竖屏或横屏短视频，并希望减少脚本、素材和后期操作的内容创作者
使用前准备：本地部署需要 Python 3.11 或更高版本；使用部分模型、语音、素材和发布服务需配置 API Key。

使用提醒：Windows 项目路径应避免中文、特殊字符和空格；本地 Whisper 首次使用需要下载模型。

许可证：MIT

05｜semantica
把分散数据建成可查询的上下文图，并记录 AI 决策依据、因果关系和来源

它能做什么：

- 摄取文件、网页、数据库和数据平台
- 提取实体、关系、事件和三元组
- 检测冲突并合并重复实体
- 记录决策并追踪因果链
- 导出图谱、来源和审计记录

核心亮点：记录模型外部的完整决策链。它位于模型和数据层之间，把输入上下文、决策结果、来源、关系、规则与执行轨迹保存成图，便于查询和审计。

适合谁：需要审计 AI 决策、管理知识图谱，或处理受监管数据的数据与平台团队
使用前准备：核心包可通过 pip 安装；不同图数据库、向量库、数据平台和可视化功能需要安装对应扩展。

使用提醒：它不能解释或重建模型内部推理；当前 Rete 条件匹配较简单，接入合规关卡前需验证输出。

许可证：MIT

06｜OpenViking
把 Agent 的记忆、资料和技能放进可浏览的虚拟文件系统，按任务需要逐层读取

它能做什么：

- 添加项目文档、代码库和网页资源
- 用目录命令浏览 Agent 上下文
- 按任务相关性逐层加载内容
- 记录并查看上下文检索轨迹
- 从已提交会话提取长期记忆

核心亮点：像浏览文件一样读取上下文。记忆、资源和技能拥有统一虚拟地址；Agent 先定位目录，再从摘要到详情递归读取，并留下可检查的检索路径。

适合谁：需要统一管理 Agent 记忆、项目资料和技能，并排查检索过程的 AI 应用开发者
使用前准备：需要 Python 3.10 或更高版本，并通过初始化向导配置模型服务和生成的配置文件。

使用提醒：桌面管理工具仍处于 Beta，目前仅支持 macOS 和 Windows x64。

许可证：AGPL-3.0

为什么本期上榜：GitHub Trending 显示过去 7 天 +3,447 Star
GitHub 搜索：volcengine/OpenViking

07｜firecrawl
把网页搜索、抓取和交互统一成 API，返回可供程序与 AI 使用的 Markdown 或结构化数据

它能做什么：

- 搜索网络并获取结果页全文
- 抓取单个网址的主要内容
- 遍历网站并收集多个页面
- 发现站点内的页面地址
- 按提示操作页面后再提取

核心亮点：从网页地址直接得到可用上下文。它把搜索、单页抓取、整站遍历、地址发现和页面交互放进统一接口，输出 Markdown、结构化数据或截图。

适合谁：需要给 Agent、搜索产品或数据管道持续接入网页内容的开发者
使用前准备：使用托管接口需要注册并获取 API Key；也可依据自托管文档运行开源版本。

使用提醒：抓取者需遵守网站政策、隐私政策和使用条款；云端版本包含开源版之外的附加功能。

许可证：AGPL-3.0（The SDKs and some UI components are licensed under the MIT License.）
