01｜OmniRoute
把不同模型供应商收进一个本地网关，按配额、成本或延迟自动选路并故障切换。

它能做什么：

- 接入不同供应商的聊天、图像与音频接口
- 按配额、成本、延迟或成功率自动选路
- 把多个模型串成前后衔接的处理流水线
- 压缩提示与工具输出以减少上下文占用
- 通过 MCP、A2A 或远程 CLI 交给 Agent 控制

核心亮点：配额感知的自动模型接力。自动组合会持续评估可用连接；当额度耗尽、服务失败或成本变化时，请求可转向下一模型，也能按编码、速度或低成本等目标调整选择。

适合谁：需要让多个编程工具共用模型入口，或在额度、成本与故障之间自动调度请求的 AI 开发者。
使用前准备：需安装并启动 OmniRoute；指定供应商时还要连接账号或配置对应凭据。

使用提醒：远程模式下，启动进程的路由仅限本机回环；内存功能默认关闭，需主动启用。

许可证：MIT

02｜open-code-review
读取 Git 变更后，用确定性流程锁定审查范围，再让 Agent 给出精确到行的结构化意见。

它能做什么：

- 读取暂存、未暂存和未跟踪的代码变更
- 比较分支、提交或指定范围的差异
- 搜索完整文件和仓库上下文核对问题
- 生成精确到代码行的结构化审查意见
- 扫描整份文件或目录而不依赖差异

核心亮点：工程约束与 Agent 分工审查。文件选择、关联文件分组、规则匹配和评论定位由确定性模块控制；Agent 负责动态检索上下文和判断缺陷，避免只看差异表面。

适合谁：需要审查工作区、分支或提交，并希望减少漏看文件和位置漂移的研发团队。
使用前准备：需要 Git >= 2.41；默认模式还需配置 LLM，委托模式可由现有编程 Agent 执行审查。

使用提醒：更偏向减少误报，因此召回率低于通用 Agent；默认审查模式需要先配置 LLM。

许可证：Apache-2.0

03｜ego-lite
让 AI Agent 继承你的浏览器登录状态，在独立空间并行跑网页任务，同时不占用你的标签页。

它能做什么：

- 迁移 Chrome 登录、Cookie、扩展和书签
- 为每个 Agent 创建隔离的浏览空间
- 并行运行多个互不抢标签页的网页任务
- 读取页面快照并执行点击、填写和导航
- 通过 JavaScript 工具组合多步浏览流程

核心亮点：共享登录态的隔离浏览空间。每个 Agent 在同一浏览器里获得独立 Space，可继承现有登录数据并后台执行任务；你仍使用自己的标签页，也能随时接管或停止 Agent。

适合谁：希望让 Codex、Claude Code 等 Agent 使用真实登录态跑网页任务，同时继续正常浏览的 macOS 用户。
使用前准备：需安装 ego lite 应用或 ego-browser 技能；迁移现有登录状态时可选择导入 Chrome 数据。

使用提醒：目前只运行于 macOS，Windows 和 Linux 尚在路线图中；经验复用能力仍标为即将推出。

许可证：MIT

04｜jcode
在终端里运行可记忆、可并行协作的编程 Agent，并用常驻服务承载多个低资源会话。

它能做什么：

- 在 TUI 或非交互模式执行编程任务
- 自动检索会话记忆并注入相关上下文
- 启动多个 Agent 协作并提醒文件冲突
- 连接多家模型或自托管兼容端点
- 控制 Firefox 完成页面点击、输入和截图

核心亮点：服务器管理的多 Agent 协作。多个 Agent 可在同一仓库并行工作，由服务端跟踪文件读取和修改；发现代码在其他会话中变化时，会通知相关 Agent 检查差异或协调冲突。

适合谁：需要同时运行多个编程 Agent、跨会话保留上下文，或接入自托管模型的终端用户。
使用前准备：需先安装 jcode，并登录模型供应商或配置兼容端点；浏览器自动化还需设置 Firefox Agent Bridge。

使用提醒：内置浏览器后端目前只有 Firefox；MCP 只支持 stdio，HTTP 与 SSE 配置会被跳过。

许可证：MIT

05｜superpowers
把需求澄清、设计确认、测试先行、分工实现和代码复核装进编程 Agent 的固定工作流。

它能做什么：

- 通过提问把模糊想法整理成可确认设计
- 把设计拆成带文件路径和验证步骤的计划
- 按测试先行循环实现最小改动
- 为每个任务派出独立子 Agent 执行
- 在合并前复核规格、代码质量和测试结果

核心亮点：先确认设计，再交给子 Agent 实现。工作流先从对话中提炼规格，等待你确认设计，再生成细化计划；执行阶段按任务派出新子 Agent，并分别检查规格符合度和代码质量。

适合谁：希望编程 Agent 不直接开写，而是按设计、计划、测试、实现和复核流程完成研发任务的开发者。
使用前准备：需按所用编程 Agent 单独安装对应插件、扩展或包。

使用提醒：使用多个编程 Agent 时要分别安装；测试先行和阶段复核属于强制工作流，并非可选建议。

许可证：MIT

06｜hermes-agent
把长期记忆、自动学技能、多渠道消息和定时任务放进同一个可远程运行的个人 Agent。

它能做什么：

- 从历史对话提取记忆并跨会话召回
- 把复杂任务经验整理成可复用技能
- 通过聊天平台与终端延续同一段对话
- 按自然语言计划定时报告、备份或审计
- 派出隔离子 Agent 并行处理不同工作流

核心亮点：会从经历中沉淀技能的闭环。Agent 会周期性整理记忆，在复杂任务后创建技能，并在后续使用中继续改进；历史会话还能被搜索和概括，减少每次重新解释背景。

适合谁：需要跨设备使用个人 Agent，并让它记住历史、自动执行周期任务或在云端持续工作的用户。
使用前准备：需安装 Hermes，并选择模型供应商；使用聊天平台时还要配置并启动消息网关。

使用提醒：Termux 需使用专用安装路径；完整依赖会拉取 Android 不兼容的语音组件。

许可证：MIT

07｜ECC
给不同编程 Agent 补上一套可复用工程体系，让计划、测试、复核、记忆和安全检查连续运转。

它能做什么：

- 按需加载规划、测试、安全和文档技能
- 派出专门 Agent 处理评审、构建和架构
- 用 hooks 在模型上下文外执行确定性检查
- 把会话摘要和经验保存为可检索记忆
- 扫描提示、权限、MCP、密钥和 Agent 配置

核心亮点：技能、Agent、规则与 hooks 分层。技能负责按需加载工作流，专用 Agent 隔离任务上下文，规则保存长期标准，hooks 在模型外执行检查；各层分工可避免把全部配置塞进每次对话。

适合谁：需要在 Claude Code、Codex 等工具中复用工程流程，并加强测试、记忆和配置审计的开发者。
使用前准备：Claude Code 插件需 v2.1.0 及以上；其他工具按各自适配方式安装。

使用提醒：同一工具不能叠加多种安装方式；Codex 暂无 hooks 执行对等，市场插件技能加载也不稳定。

许可证：MIT
