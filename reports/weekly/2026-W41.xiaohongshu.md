01｜AnyPS5
为跨系统移植开发者转换可执行文件，让它们采用 Linux 或 Windows 的原生格式。

它能做什么：

- 转换可执行文件为目标系统原生格式
- 提供可供动态链接的系统库实现
- 将着色器重新编译为 SPIR-V
- 接入支持 SDL 映射的游戏手柄
- 通过配置文件设置键盘与鼠标控制

核心亮点：转换原生格式，而不是模拟运行。重链接器负责把可执行文件转换为目标系统的原生格式，系统库实现负责配合动态链接。这条移植路线不采用模拟，也不依赖单独的运行时进程。

适合谁：研究游戏兼容性、软件保存与跨系统移植，需要处理可执行文件的开发者。
使用前准备：用户需自行确保所用二进制文件的获取与使用符合适用法律及各自许可条款。

使用提醒：遇到不支持或意外状态会报错并终止进程；游戏兼容性需查测试清单。系统库进度仅统计项目已知函数，不代表全部系统函数。

许可证：GPL-2.0

02｜skills
把需求澄清、任务拆分、测试与审查做成可组合技能，帮助工程师指挥 AI 完成应用开发。

它能做什么：

- 通过追问澄清需求与设计决策
- 把讨论整理成需求规格并发布到工单
- 将计划拆成带依赖关系的任务单
- 按先写失败测试的流程实现功能
- 分别审查代码规范与需求符合程度

核心亮点：从需求追问到可组合的工程步骤。这些技能可以单独选用、修改和组合。需求访谈会同步整理项目术语表与决策记录，再衔接规格、任务、测试和审查，让人与 AI 使用同一套项目语言。

适合谁：用 AI 编程助手开发应用，希望先澄清需求、拆分任务，再用测试和审查推进改动的工程师。
使用前准备：使用工程技能前，每个仓库需运行一次初始化技能，配置工单系统、分类标签和文档保存位置。

使用提醒：每个编程助手只选一种安装方式，避免技能重复；复制到项目的技能需手动更新。架构扫描只提供改进候选，不会自动理清旧代码。

许可证：MIT

03｜hyperframes
写网页也能做视频：把 HTML、动画和媒体素材变成 MP4，供人或 AI 编程助手制作。

它能做什么：

- 将 HTML、样式和媒体渲染为 MP4
- 把网站素材制作成产品发布视频
- 将代码合并请求转成变更解说视频
- 为已有口播视频添加字幕
- 按音乐节拍编排视频画面

核心亮点：用网页代码编排视频时间线。用 HTML 属性标记时间和轨道，并让动画能够跳转到指定时刻。渲染器在无界面 Chrome 中逐帧取画面，再交给 FFmpeg 编码，便于重复生成同一视频。

适合谁：熟悉网页技术、需要制作产品介绍、代码变更解说或批量生成动态图文视频的开发者与内容团队。
使用前准备：本地命令行使用需要 Node.js 22+ 和 FFmpeg；克隆完整仓库参与开发前需安装 Git LFS。

使用提醒：创作流程会先确认制作需求；幻灯片流程输出可导航演示文稿而非视频，Remotion 迁移流程只支持单向转换。

许可证：Apache-2.0

04｜ECC
在 AI 写代码的流程里加入计划、测试、独立审查与记忆，不必每次从提示词重新搭起。

它能做什么：

- 将功能需求整理成可确认的实施计划
- 用失败测试驱动功能实现与回归验证
- 交给独立上下文的助手审查代码
- 保存可跨编程助手检索的会话记忆
- 扫描智能体配置中的权限与注入风险

核心亮点：把计划、验证和记忆接成流程。技能承载可复用流程，子助手分担规划和审查，规则保留项目标准，事件脚本执行检查。会话结束后再提炼记忆与经验，让下一次开发接着已有记录推进。

适合谁：持续使用 AI 编程助手，需要复用测试、审查、会话记忆和配置检查流程的个人开发者与软件团队。
使用前准备：通用包需 Node.js 18 或更新版本；Claude 插件另需 Git 和 Claude Code 2.1+。扫描需已安装并审查的 AgentShield。

使用提醒：各编程助手功能不完全一致，Windows 原生记忆写入仍有缺陷；自动脚本需明确授权，记忆不能当指令。私有仓库托管分析属付费 Pro 服务。

许可证：MIT

05｜ponytail
给 AI 编程助手加上少写必要代码的约束，在实现和审查时优先复用，而不是堆叠新抽象。

它能做什么：

- 检查现有组件以寻找更小的实现方案
- 审查改动涉及的代码与真实执行流程
- 按优先级列出整个仓库的待修问题
- 收集延期处理的捷径注释形成债务清单
- 为有分支或解析等风险的逻辑补测试

核心亮点：先读懂代码，再减少不必要的实现。核心是一份可加载进编程助手的提示词：先读相关代码、追踪真实流程，再寻找必要的最小改动；同时保留校验、错误处理与测试，并说明未检查的内容和风险。

适合谁：希望 AI 优先复用现有代码、减少过度设计，并在提交前审查改动风险的开发者。
使用前准备：完整命令需要支持技能的编程助手；不要求配置文件。

使用提醒：精简实现不能删去信任边界校验、数据丢失处理或无障碍支持；仅加载规则的适配器没有完整命令功能，Cursor 钩子仅支持强度切换。

许可证：MIT

06｜claude-mem
让 AI 编程助手换个会话也能接着工作：自动压缩操作记录，再找回相关项目背景。

它能做什么：

- 自动记录工具使用中产生的观察
- 将会话观察压缩为语义摘要
- 向新会话注入相关历史上下文
- 按日期、项目或类型检索记忆
- 在网页查看器中浏览实时记忆流

核心亮点：先查记忆索引，再按需读取细节。工具使用记录先被压缩并存储。查找历史时先取简短索引，再查看附近时间线，最后只读取选中记录的全文，让新会话按需找回项目背景。

适合谁：长期用 AI 编程助手维护项目，需要在会话结束、重连或切换任务后找回历史决策与工作记录的开发者。
使用前准备：需 Node.js 20.0.0 或更新版本；Claude Code 需支持插件。Bun 与 uv 缺失时自动安装，SQLite 已捆绑。

使用提醒：托管观察服务试用结束后，未订阅会退回 Anthropic 套餐；可跳过登录选用其他提供方。默认启动上下文仅含当前编程助手的记录。

许可证：Apache-2.0

为什么本期上榜：过去 7 天净增 +3,530 Star（历史快照核验）
GitHub 搜索：thedotmack/claude-mem

07｜deepseek-harness
为探索智能体架构的开发者提供插件化运行框架，并配有可在本地启动的网页界面。

它能做什么：

- 启动本地智能体网页界面
- 关闭启动时自动打开浏览器的行为
- 从源码构建项目运行所需产物
- 在修改源码后自动重建网页客户端

核心亮点：以插件组织智能体运行框架。智能体运行框架以 Cordis 为基础，把功能组织为插件。开发者可以通过软件包启动网页界面，也能从源码构建，并在开发模式下随修改自动重建客户端。

适合谁：希望研究插件化智能体架构、运行本地网页界面或参与界面与插件开发的工程师。
使用前准备：软件包运行方式需先安装 Node.js；源码运行需用 pnpm 安装依赖并完成构建。

使用提醒：仍处于开发者预览阶段，会出现破坏兼容性的变更；运行前需阅读安全说明。源码启动使用已构建产物，不会自动重新构建。

许可证：MIT
