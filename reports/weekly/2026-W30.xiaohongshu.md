01｜skills
把软件工程方法拆成可组合的 Agent 技能，帮助编码助手先对齐需求，再测试、调试与审查改动

它能做什么：

- 追问需求并补齐决策分支
- 建立项目术语表与架构决策记录
- 把对话整理成规格和可阻塞工单
- 按测试驱动循环实现功能或修复缺陷
- 审查改动是否符合规范与原始规格

核心亮点：可组合的工程技能链。每项技能只负责一段工程流程，可由用户手动调用或由 Agent 按任务自动选用；组合后覆盖需求澄清、规格拆解、实现、调试和审查。

适合谁：希望保留开发流程控制权，并让编码 Agent 按工程规范完成需求、调试和审查的开发者
使用前准备：需选择 Claude Code 插件或 skills.sh 其一，并在每个仓库运行 /setup-matt-pocock-skills。

使用提醒：两种安装方式同时使用会重复安装全部技能；Claude Code 插件提供的是托管只读副本。

许可证：MIT

02｜code-review-graph
把代码库解析成持久结构图，让 AI 审查改动时只读取相关函数、依赖文件和测试

它能做什么：

- 解析代码并建立函数、类和导入关系图
- 增量更新发生变化的文件
- 追踪改动涉及的调用方、依赖和测试
- 在合并请求中发布风险审查评论
- 导出交互图、GraphML 或代码库 Wiki

核心亮点：用代码图裁剪审查上下文。项目把语法树存成节点和调用、继承、测试等边，再从变更位置向外追踪影响范围，把最相关的文件和结构摘要交给 AI。

适合谁：需要审查大型仓库、排查跨文件影响，或在合并请求中自动标记风险与测试缺口的研发团队
使用前准备：需要 Python 3.10+；安装并配置 MCP 后需重启编辑器或工具，再为仓库构建代码图。

使用提醒：小型单文件改动中，图上下文可能比直接读文件更大；搜索排序与部分语言的执行流检测仍需改进。

许可证：MIT

为什么本期上榜：过去 7 天净增 +6,296 Star（历史快照核验）
GitHub 搜索：tirth8205/code-review-graph

03｜orca
在隔离的 Git worktree 中并行运行多个编程 Agent，并从桌面或手机统一跟进结果

它能做什么：

- 并排运行任意终端型编程 Agent
- 把同一提示分发到多个隔离 worktree
- 批注差异行并把意见发回 Agent
- 从手机监控任务并发送后续要求
- 通过 SSH 在远程主机运行 Agent

核心亮点：隔离工作树里的并行 Agent。每个 Agent 在独立 Git worktree 中处理同一任务，用户可比较结果、选择方案并合并；桌面端集中管理终端和差异，移动端负责提醒与跟进。

适合谁：需要并行比较多个 Agent 方案、远程运行开发任务，或集中审查 AI 代码改动的工程师
使用前准备：需安装桌面应用，并准备能在终端运行的编程 Agent；移动端需要与桌面应用配对。

使用提醒：会收集匿名使用数据，但隐私文档提供退出方式；移动端主要用于监控和控制桌面端 Agent。

许可证：MIT

为什么本期上榜：过去 7 天净增 +7,330 Star（历史快照核验）
GitHub 搜索：stablyai/orca

04｜ai-agent-book
从 LLM、上下文和工具的组合原理出发，用章节正文与配套实验讲清 AI Agent 的工程实现

它能做什么：

- 阅读从基础到多 Agent 协作的章节
- 运行按章配套的代码实验
- 下载 PDF 或 EPUB 离线阅读
- 按脚本编译多语言电子书
- 克隆外部仓库补齐进阶实验

核心亮点：正文与实验同步推进。全书围绕“Agent = LLM + 上下文 + 工具”展开，每章先解释设计原理，再链接对应代码与复现路径，适合边读边运行实验。

适合谁：想系统理解 Agent 原理，并通过代码练习上下文工程、RAG、工具调用、评估与多 Agent 的学习者
使用前准备：部分实验需自行申请模型 API Key；自行编译 PDF 需 pandoc、xelatex、ElegantBook 与相关字体。

使用提醒：部分外部仓库未内置；部分实验需 GPU、指定提交或 SO-100 机械臂，社区翻译可能滞后于中文原版。

许可证：Apache-2.0（部分子项目可能包含各自的许可证信息，请以子项目中的说明为准。）

05｜ai-engineering-from-scratch
从数学基础一路学到 Agent、部署与安全，每课都要求亲手实现并留下可复用工具

它能做什么：

- 推导并编码机器学习与深度学习算法
- 从零实现注意力、模型和 Agent 循环
- 运行测试并比较手写实现与常用框架
- 按知识水平生成个性化学习路径
- 安装课程产出的提示词与 Agent 技能

核心亮点：每课都交付可复用产物。课程采用“理解问题、推导概念、从零实现、调用框架、交付工具”的固定循环，让学习结果沉淀为提示词、技能、Agent 或 MCP 服务。

适合谁：已经会写代码，想从底层原理补齐 AI 工程能力，并积累可运行作品和日常工具的学习者
使用前准备：需要具备任意语言的编程能力，掌握 Python 会更方便；课程强调理解原理，而非只会调用 API。

使用提醒：课程要求亲自推导、编码并运行测试，不提供复制粘贴式部署或手把手教学；完整路径投入较长。

许可证：MIT

06｜worldmonitor
把全球新闻、地缘信号、金融与基础设施数据汇入同一套地图和态势仪表盘

它能做什么：

- 汇总新闻源并生成 AI 简报
- 切换三维地球与 WebGL 平面地图
- 关联跨数据流的异常与升级信号
- 查看交易所、商品和加密资产雷达
- 通过 MCP、REST、CLI 或 SDK 查询数据

核心亮点：跨来源的全球态势看板。系统把新闻、地图图层、市场与基础设施数据放进统一界面，并通过跨流关联找出同时出现的军事、经济、灾害和升级信号。

适合谁：需要持续观察国际新闻、市场、能源、灾害或基础设施变化，并希望自建统一看板的研究与分析人员
使用前准备：本地开发需安装依赖并运行 npm run dev；基础应用无需环境变量，特定数据源可能需要凭证。

使用提醒：部分数据源需要凭证；MCP 的 tools/call 需要 X-WorldMonitor-Key 或 OAuth，公开接口并非全部免认证。

许可证：AGPL-3.0-only（Separate commercial or trademark permission needed）

07｜OmniRoute
给编码工具提供统一模型端点，并按配额、成本、延迟和故障情况自动切换供应商

它能做什么：

- 把不同供应商接到统一兼容端点
- 按配额、成本或延迟自动选择模型
- 在供应商失败时切换到后备目标
- 压缩提示词、工具输出和历史上下文
- 通过 MCP、A2A 和远程 CLI 管理网关

核心亮点：配额感知的模型路由链。每个组合可串联多个模型目标，并为步骤选择路由策略；系统持续参考健康、配额、成本和延迟，失败或额度不足时转向下一目标。

适合谁：需要为 Codex、Claude Code、Cursor 等工具统一管理模型账号、额度、成本和故障回退的开发者
使用前准备：需要 Node ≥22.22.2；安装并启动后，连接可用供应商，再把编码工具指向本地兼容端点。

使用提醒：免费额度会随供应商调整而变化；远程访问令牌分为不同作用域，涉及进程启动的接口仅限本机回环。

许可证：MIT
