01｜prime-agent
让编码与研究智能体在后台持续工作，并把会话经验沉淀成可复用的记忆、技能和子智能体配置

它能做什么：

- 保持目标和执行状态跨会话延续
- 派出子智能体并行或后台处理工作
- 安排心跳和定时任务重新进入会话
- 把重复流程制作成可执行技能
- 复盘轨迹并更新补充记忆与提示

核心亮点：会持续积累经验的任务环境。它把持久化 IPython、子智能体和 Continual Harness 组合起来；任务状态不会随终端断开消失，还能从轨迹中提炼小幅、可审查且可回滚的经验更新。

适合谁：适合需要智能体跨多轮推进编码、研究或评测任务，并希望保留工作状态的使用者
使用前准备：稳定版安装面向 macOS 或 Linux；首次启动需登录，并选择订阅或 API Key 提供商。

使用提醒：会以当前用户权限执行模型生成的 Python 和项目命令，并非安全沙箱；应使用可恢复的工作区，检查改动，外部不可信内容需另行隔离。

许可证：MIT

02｜skills
把需求澄清、测试驱动、调试和代码审查等工程习惯装进编码智能体，减少失控和返工

它能做什么：

- 追问需求并补齐未决的设计分支
- 建立项目术语表并记录架构决策
- 按红绿重构流程实现功能或修复缺陷
- 分阶段定位复杂缺陷和性能回退
- 从规范与代码标准两条线审查改动

核心亮点：可组合的工程流程技能。每项技能聚焦一个工程动作，可单独调用，也能串成从澄清、规格、任务拆分到实现和审查的流程；文件可复制进项目后自行修改，不必交出整个开发过程。

适合谁：适合已经用 Claude Code、Codex 等智能体做真实项目，希望保留工程控制权的开发者
使用前准备：需在支持技能或插件的编码智能体中安装，并在每个仓库运行一次 setup-matt-pocock-skills 完成配置。

使用提醒：插件安装是托管只读包，文件安装则可编辑；两种方式同时安装会产生重复技能。架构扫描只提供候选，不会自动解开旧代码的复杂结构。

许可证：MIT

03｜diagram-design
让编码智能体把架构、流程、时序或数据关系制作成可离线打开、可按品牌定制的 HTML 与 SVG 图

它能做什么：

- 生成可离线打开的自包含 HTML 图
- 从网站提取颜色与字体并应用品牌样式
- 重绘 draw.io 文件并调整尺寸和细节
- 解析 Mermaid 文本并换成编辑式视觉
- 导出适合网页、幻灯片或设计工具的图像

核心亮点：先选语义，再决定版式。遇到队列、策略轨迹或安全边界等行为时，它先匹配语义模式，再加载最接近的图表类型；普通任务只读取相关参考文件，动效仍是可选项，静态输出保持默认。

适合谁：适合需要为技术文档、博客、演示稿或社交卡片制作编辑式图表的作者与开发者
使用前准备：需在 Claude Code、Codex 或 Pi 中安装对应插件或技能；导出 PNG 还需安装 Playwright 与 Chromium。

使用提醒：首次在品牌项目中使用会暂停并要求确认样式；默认输出静态且无脚本。列表、简单前后对比或单个形状不建议画图。

许可证：MIT

04｜TencentDB-Agent-Memory
把团队的对话、文档和代码整理成可审查、可共享、可分配给不同智能体的长期记忆资产

它能做什么：

- 导入历史会话并提取记忆和技能
- 索引代码符号、调用关系与影响路径
- 把文档整理成带链接关系的 Wiki
- 为不同智能体绑定所需记忆资产
- 审查版本、归属、状态与共享权限

核心亮点：给智能体团队装配共享记忆。Memory Hub 把聊天记忆、技能、Wiki 和 CodeGraph 统一成资产；先按团队、用户和智能体权限缩小范围，再按当前任务检索，让经验能流转而不是整库塞进上下文。

适合谁：适合多个智能体或团队成员反复处理同一项目，希望复用历史决策、文档和代码经验的团队
使用前准备：需启动 memory-core、memory-hub 和 proxy，并在环境文件中填写记忆组与代理组的模型参数。

使用提醒：Wiki 与 CodeGraph 异步构建，需要等待就绪；私有仓库和 SSH 凭据支持仍在完善，自动记忆路由也仍在迭代。

许可证：MIT

为什么本期上榜：过去 7 天净增 +3,695 Star（历史快照核验）
GitHub 搜索：TencentCloud/TencentDB-Agent-Memory

05｜public-apis
按主题查找可用于个人产品的公共 API，并在同一张表里比较认证、HTTPS 与跨域条件

它能做什么：

- 按业务主题浏览公共 API
- 查看每个接口提供的数据或服务
- 比较无需认证、密钥和 OAuth 等方式
- 检查 HTTPS 与 CORS 支持情况
- 沿条目链接进入接口文档继续评估

核心亮点：先筛选，再接入公共接口。它把分散的公共 API 按领域整理成表格，让你先从用途定位候选，再查看认证、HTTPS 和 CORS 条件，最后进入各自文档确认调用细节。

适合谁：适合做原型、练习项目或产品集成时，需要快速寻找外部数据与服务接口的开发者

使用提醒：这是社区人工维护的接口目录，不是统一调用服务；认证方式、HTTPS 和 CORS 条件因条目而异，接入前仍需查看各接口文档。

许可证：MIT

为什么本期上榜：过去 7 天净增 +5,081 Star（历史快照核验）
GitHub 搜索：public-apis/public-apis

06｜firecrawl
输入网址或描述所需资料，搜索并操作网页，再返回适合程序和 AI 使用的 Markdown、截图或结构化数据

它能做什么：

- 搜索网络并返回来源与页面正文
- 把单个网页转成 Markdown 或结构化数据
- 遍历站点并发现或抓取内部页面
- 操作页面后提取动态内容
- 按描述自动寻找并整理目标资料

核心亮点：从网页入口到可用上下文。它把搜索、页面抓取、站点遍历和交互放在同一套接口中：既能从已知网址抽取内容，也能只描述目标，让 Agent 自行寻找来源并按结构返回结果。

适合谁：适合为智能体、检索系统、市场研究或数据管道接入实时网页内容的开发者
使用前准备：使用托管服务需注册并取得 API Key；也可按自托管指南本地部署。

使用提醒：云端版本包含额外功能；抓取时需遵守网站政策、隐私政策和使用条款，默认遵循 robots.txt 指令。

许可证：AGPL-3.0（Users are advised to adhere to applicable privacy policies and terms of use.）

为什么本期上榜：过去 7 天净增 +4,331 Star（历史快照核验）
GitHub 搜索：firecrawl/firecrawl

07｜hermes-agent
把终端、聊天平台、定时任务和可自我改进的技能系统连成一个跨设备持续工作的个人智能体

它能做什么：

- 从任务经验创建并改进可复用技能
- 搜索旧会话并恢复跨会话上下文
- 通过聊天平台远程发送和接收任务
- 安排定时报告、备份或审计
- 派出隔离子智能体并行处理工作流

核心亮点：在使用中闭环学习。Hermes 会保存记忆、检索历史会话，并在复杂任务后创建技能；技能再次使用时还能继续改进。终端、消息网关和计划任务共享同一套持续上下文。

适合谁：适合希望智能体长期记住工作方式，并从终端或聊天软件调度研究、编码与自动化任务的使用者
使用前准备：安装后需选择模型提供商与模型，并配置所需工具；消息平台使用前还要完成网关设置。

使用提醒：Termux 的完整依赖包含不兼容的语音组件，需使用专门安装项；外部模型、搜索、图像或语音能力仍依赖对应提供商。

许可证：MIT
