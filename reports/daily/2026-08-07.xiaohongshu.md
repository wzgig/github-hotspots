别只看 Star。这期把上榜项目翻成三件能直接判断的事：它做什么、能帮你完成什么、适不适合你。

先看结论：
- skills：把工程经验整理成可组合的 Agent 技能，帮助编码代理先对齐需求、再测试和改进代码
- computer：为 AI Agent 提供可持久化的虚拟文件系统，并接入容器、Shell 或 JavaScript 执行环境
- TencentDB-Agent-Memory：把对话、文档和代码沉淀成可共享的团队记忆，再按需装配给不同 Agent

01｜skills
把工程经验整理成可组合的 Agent 技能，帮助编码代理先对齐需求、再测试和改进代码

它能做什么：

- 通过提问澄清要做的改动
- 生成项目术语和决策文档
- 用 TDD 推动功能或修复
- 按步骤诊断 Bug 和回归验证
- 扫描代码库寻找架构改进点

核心亮点：把工程方法变成 Agent 工作流。技能按用户调用和模型调用分层，覆盖需求澄清、领域建模、TDD、调试、代码审查与架构设计，可自由组合。

适合谁：希望让 Claude Code、Codex 等编码代理按工程流程工作的开发者
使用前准备：需使用 Claude Code、Codex 或其他编码代理；每个仓库先运行一次 setup 技能。

使用提醒：Claude Code 插件是只读托管包；通过 skills.sh 安装的文件可编辑，但不会自动更新。

为什么本期上榜：过去 24 小时净增 +2,214 Star（历史快照核验）
GitHub 搜索：mattpocock/skills

02｜computer
为 AI Agent 提供可持久化的虚拟文件系统，并接入容器、Shell 或 JavaScript 执行环境

它能做什么：

- 在 SQLite 中保存持久化工作区状态
- 通过 FUSE 挂载容器文件系统
- 在 Dynamic Worker 中运行 Shell 命令
- 在隔离 Worker 中执行 ECMAScript 模块
- 用统一入口切换多个执行后端

核心亮点：一个工作区，多种执行后端。它把权威状态放在 Durable Object 的 SQLite 中，再按需连接容器、Isolate shell 或 Isolate JavaScript；统一 exec 入口负责调度。

适合谁：想让 Agent 在 Cloudflare 工作区读写文件并执行任务的开发者
使用前准备：需安装 @cloudflare/computer，并按照该包 README 完成安装和示例配置。

使用提醒：README 明确标注为预览版，API 不稳定、设计会变更，当前不适合生产使用。

许可证：MIT

为什么本期上榜：过去 24 小时净增 +2,023 Star（历史快照核验）
GitHub 搜索：cloudflare/computer

03｜TencentDB-Agent-Memory
把对话、文档和代码沉淀成可共享的团队记忆，再按需装配给不同 Agent

它能做什么：

- 从对话和任务提取 Chat Memory 与 Skill
- 把文档整理成带链接图的 Wiki 页面
- 为代码库建立符号和调用关系图
- 按团队、用户和 Agent 分配记忆资产
- 按需检索相关文档、代码和历史上下文

核心亮点：把团队经验变成 Agent 记忆。项目把记忆拆成 Chat Memory、Skill、Wiki 和 CodeGraph 等资产，再通过权限、版本和 Agent 绑定控制使用范围。

适合谁：需要让多个 Agent 共享项目经验、文档和代码上下文的团队
使用前准备：需配置 memory-core、memory-hub 和 proxy，并在 .env 中填写两组 LLM 参数。

使用提醒：Wiki 和 CodeGraph 异步构建；CodeGraph 目前优先支持公开 HTTPS 仓库；记忆绑定仍需手动完成。

许可证：MIT

为什么本期上榜：过去 24 小时净增 +1,427 Star（历史快照核验）
GitHub 搜索：TencentCloud/TencentDB-Agent-Memory
