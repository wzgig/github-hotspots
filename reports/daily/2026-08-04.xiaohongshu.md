01｜reverse-skill
给代码 AI 客户端分派逆向、安全测试与 CTF 任务，并按场景接上工具、证据链和报告流程

它能做什么：

- 识别 APK、二进制、前端 JS 等任务场景
- 按路由矩阵选择对应方法与工具
- 检查本机工具并刷新可用工具索引
- 初始化范围、时间线和工作项记录
- 串联证据、发现、路径与报告输出

核心亮点：先定范围，再路由工具链。任务先经过规则与范围门禁，确认授权和网络配置后，再进入场景技能、工具与脚本；过程同步记录时间线、证据链和报告，减少临时猜命令。

适合谁：需要让代码 AI 在授权范围内处理逆向、安全测试或 CTF 任务的研究者与竞赛参与者
使用前准备：需 Java/JDK、Node.js 22.12+、Python 3.x 和代码 AI 客户端。

使用提醒：目标操作前需完成授权与网络范围确认；外部工具仍受各自许可证约束。

许可证：MIT（are subject to their respective official licenses）

02｜TencentDB-Agent-Memory
把对话、文档和代码整理成可复用的团队记忆，让不同 Agent 继承上下文、技能和知识关系

它能做什么：

- 提取对话中的偏好、事实与决策
- 沉淀带版本和触发边界的技能
- 导入文档并生成结构化 Wiki
- 索引代码符号、调用关系与影响路径
- 按团队、角色和 Agent 配置访问权限

核心亮点：把团队经验做成 Agent 装备。Memory Hub 把 Chat Memory、Skill、Wiki 和 CodeGraph 统一成可审阅、可授权、可绑定的资产；Agent 按任务取用所需内容，不必整包塞进上下文。

适合谁：需要让多个 Agent 跨会话、跨角色复用项目经验，并由团队管理权限与版本的开发团队
使用前准备：需复制 `.env.example`，填写 memory 与 proxy 两组 LLM 参数，再运行 `start-all.sh`。

使用提醒：Wiki 和 CodeGraph 异步构建，私有仓库与 SSH 凭据支持仍在完善，记忆资产目前需手动绑定。

许可证：MIT

为什么本期上榜：过去 24 小时净增 +1,069 Star（历史快照核验）
GitHub 搜索：TencentCloud/TencentDB-Agent-Memory

03｜DeepSeek-Reasonix
在终端、桌面或 VS Code 中调用编程 Agent，用配置切换模型、组合工具并维持长会话上下文

它能做什么：

- 启动交互会话处理代码任务
- 配置任意 OpenAI 兼容模型端点
- 组合执行模型与规划模型协作
- 接入 MCP 兼容的外部工具插件
- 在 VS Code 中审批工具调用

核心亮点：为前缀缓存维护稳定上下文。它保留稳定的环境摘要，裁剪过期工具输出，再做摘要压缩；模型、工具和插件由配置文件声明，长会话中更容易复用 DeepSeek 的前缀缓存。

适合谁：希望在终端或编辑器中运行编程 Agent，并自行配置模型端点、工具和插件的开发者
使用前准备：CLI/TUI 可通过 npm 或 Homebrew 安装；VS Code 扩展需先安装本地 CLI，并配置模型提供方。

使用提醒：VS Code 扩展不内置 CLI；桌面端与 CLI 的安装和启动路径不同，使用时需按对应入口配置。

许可证：MIT
