AI 项目的名字往往很抽象。这一期不堆术语，只讲清它替谁做什么、能完成哪些任务，以及是否值得加入你的工具箱。

先看结论：
- deepseek-harness：用插件组合 AI Agent 的运行框架，可在本地启动网页界面并按需扩展组件

- ECC：把规划、测试、实现、审查和记忆串成 Agent 编程流程，减少每次提示里重复交代规范

01｜deepseek-harness
用插件组合 AI Agent 的运行框架，可在本地启动网页界面并按需扩展组件

它能做什么：

- 启动本地 Web UI 操作 Agent
- 通过插件架构组合功能组件
- 使用 npx 直接运行项目
- 从源码安装并构建项目产物
- 关闭启动时自动打开浏览器

核心亮点：一切皆插件的 Agent 框架。框架以 Cordis 为基础，把 Agent 能力拆成插件；开发者可按需组合组件，并通过本地 Web UI 启动和使用整套运行环境。

适合谁：想搭建可插拔 Agent 框架，并通过本地网页界面调试或使用的开发者
使用前准备：通过 npm 运行需安装 Node.js；从源码运行还需使用 pnpm 安装和构建。

使用提醒：项目处于开发者预览阶段，仍会快速迭代并出现破坏兼容性的变更；运行前需阅读安全说明。

许可证：MIT

GitHub 搜索：deepseek-ai/deepseek-harness

02｜scientific-agent-skills
把科学数据库、Python 工具和研究流程封装成技能，让兼容的 AI Agent 执行多步科研任务

它能做什么：

- 检索科学数据库并记录数据来源
- 编排跨工具的多步科研流程
- 分析组学、化学与临床研究数据
- 生成可追溯的研究文稿和图表
- 按主题选装所需科研技能

核心亮点：把科研方法装进 Agent。每项技能用 SKILL.md 提供流程说明、代码示例和参考材料，让 Agent 知道如何调用科研软件与数据库，并把多个步骤串成可复核的研究任务。

适合谁：需要让 AI Agent 辅助文献检索、科学计算、数据分析或研究材料整理的科研人员与工程师
使用前准备：需 Python 3.13+、uv、兼容 Agent Skills 的客户端，以及 macOS、Linux 或 Windows WSL2。

使用提醒：技能可执行代码、安装包、联网和修改文件，安装前需人工审查；临床与监管输出仍需合格人员复核。

许可证：MIT（These licenses may differ from the repository's MIT License.）

03｜ECC
把规划、测试、实现、审查和记忆串成 Agent 编程流程，减少每次提示里重复交代规范

它能做什么：

- 规划功能并生成可编辑实施方案
- 按测试驱动流程实现代码改动
- 调用独立审查者检查回归与盲点
- 保存会话摘要并检索长期记忆
- 扫描技能、钩子和配置中的风险

核心亮点：把 Agent 编程变成闭环。ECC 将计划、测试、实现、独立审查、最终验证和经验沉淀连接起来，并用技能、Agent、规则与钩子分别承担流程、分工、规范和自动检查。

适合谁：希望统一 AI 编程流程，并在多个 Agent 工具间复用技能、规则和记忆的软件团队
使用前准备：引导安装需 Node.js 18 或更高版本；Claude Code 插件路径还需 Git 和 Claude Code 2.1 或更高版本。

使用提醒：不同工具的能力并不完全一致；同一工具只能选择一种安装路径，叠加安装会造成技能、命令或钩子重复。

许可证：MIT
