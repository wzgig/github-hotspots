01｜reverse-skill
为代码 AI 分派逆向与授权安全任务，检查本地工具后按场景执行可复用流程

它能做什么：

- 识别任务类型并选择对应分析方法
- 检查本机可用工具并刷新工具索引
- 初始化案件目录、范围、时间线和工作项
- 调用场景技能、脚本或 MCP 工具
- 整理证据链、发现路径和分析报告

核心亮点：先过范围门，再路由工具。任务先经过全局规则和范围检查，确认授权与网络条件后，再由主路由选择场景技能和工具；过程同步记录时间线、证据链与发现，减少临时猜命令和重复踩坑。

适合谁：需要让代码 AI 协助逆向分析、授权渗透、CTF 或安全研究，并希望流程可复查的使用者
使用前准备：需准备 Java / JDK、Node.js 22.12+、Python 3.x，以及一个代码 AI 客户端。

使用提醒：必须先确认授权范围和网络配置；范围未就绪前不得对目标执行操作。

许可证：MIT（This repo only invokes it via CLI or MCP and does not include its source code）

02｜TencentDB-Agent-Memory
把对话、文档和代码沉淀为团队记忆资产，让不同 Agent 接续已有经验工作

它能做什么：

- 提取对话中的事实、偏好和决策
- 沉淀带版本与验证规则的工作技能
- 生成带链接关系的文档知识页
- 索引代码符号、调用关系和影响路径
- 审核、共享并绑定各类记忆资产

核心亮点：给 Agent 团队装载经验。系统把对话、流程、文档和代码整理成 Chat Memory、Skill、Wiki 与 CodeGraph，再通过权限和固定绑定分配给不同 Agent，使新会话能从已有背景和方法继续推进。

适合谁：适合需要跨会话复用项目背景、共享团队工作方法，或为多个 Agent 分配不同知识资产的团队
使用前准备：安装时需复制 .env.example，并填写记忆组和代理组的 LLM 参数。

使用提醒：Wiki 和 CodeGraph 异步构建；代码图优先支持公开 HTTPS 仓库，私有仓库、自动记忆路由和更多框架迁移仍在完善。

许可证：MIT

03｜DeepSeek-Reasonix
在终端、桌面或编辑器中运行 AI 编程任务，并用稳定上下文减少长会话的重复消耗

它能做什么：

- 配置兼容接口的模型服务
- 组合规划模型与执行模型
- 通过 JSON-RPC 子进程接入外部工具
- 在终端运行交互或单次编码任务
- 从检查点恢复并管理长会话上下文

核心亮点：围绕缓存维护长会话。Reasonix 用稳定的环境摘要和分离的模型会话保持前缀缓存，并在上下文变旧时裁剪工具输出、压缩摘要；模型、工具和插件都由配置声明，便于替换和组合。

适合谁：适合希望在终端持续处理代码任务，或把同一本地编程 Agent 接入桌面端和 VS Code 的开发者
使用前准备：需先配置模型服务商和模型；VS Code 扩展还需安装本地 CLI，并启动 reasonix acp 后端。

使用提醒：VS Code 扩展不内置 CLI；桌面端与扩展依赖同一本地 Reasonix 引擎。

许可证：MIT
