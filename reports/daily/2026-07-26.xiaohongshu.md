01｜buzz
让人和 AI Agent 在同一工作区协作，把对话、代码、流程与审批留在统一记录中

它能做什么：

- 创建频道、私聊、画布与媒体讨论空间
- 让 Agent 打开仓库、提交补丁并审查代码
- 把功能分支关联为包含检查与审批的房间
- 用消息、反应、计划或 Webhook 触发流程
- 搜索对话、补丁、流程结果与审计记录

核心亮点：人和 Agent 共用事件日志。人、Agent、工作流与 Git 操作都写成带签名的事件，共用身份模型、搜索索引和审计轨迹，便于追溯一次决策从讨论到合并的全过程。

适合谁：适合希望自托管团队协作空间，并让 AI Agent 参与开发、审查和发布流程的团队
使用前准备：源码运行需 Docker 与 Hermit；也可自行准备 Rust、Node、pnpm 和 just。

使用提醒：项目尚未完成；移动客户端和流程审批仍在接线中，愿景栏目中的能力还没有代码，使用时应保留人工参与。

许可证：Apache-2.0

为什么本期上榜：过去 24 小时净增 +2,094 Star（历史快照核验）
GitHub 搜索：block/buzz

02｜Instatic
把可视化建站、内容管理与静态发布收进一个自托管 Bun 服务

它能做什么：

- 拖放模块并组合可复用组件与模板
- 从 HTML 或整站文件导入可编辑页面
- 创建集合并管理草稿、定时发布和版本
- 生成静态页面并按需加载访客动态部分
- 安装沙箱插件扩展路由、模块与数据源

核心亮点：编辑器不进入发布页面。画布负责设计，内容引擎管理数据，发布器把页面烘焙为语义化 HTML 与紧凑 CSS；常见访问直接读取静态文件，编辑器框架不会跟进前台。

适合谁：适合想自托管博客、作品集或企业网站，并统一管理设计、内容、表单和发布的建站者与团队
使用前准备：本地开发只需 Bun，默认使用 SQLite，无需启动额外服务。

使用提醒：项目仍处早期版本，接口和工作流在正式版前可能变化；当前分析功能侧重后台状态、审计历史和表单数据。

许可证：MIT

为什么本期上榜：过去 24 小时净增 +835 Star（历史快照核验）
GitHub 搜索：CoreBunch/Instatic

03｜ego-lite
让外部 AI Agent 借用你的登录状态执行网页任务，同时不占用你正在浏览的标签页

它能做什么：

- 读取页面快照并定位可操作内容
- 填写、点击、等待、跳转和截取页面
- 并行运行多个 Agent 或多个网页任务
- 迁移 Chrome 数据供 Agent 使用现有登录
- 随时接管或停止 Agent 所在空间

核心亮点：同一浏览器里的隔离空间。每个 Agent 在独立 Space 中读取快照并执行 JavaScript 工具调用，可并行使用已有登录状态；你的标签页和鼠标保持原位，也能随时接管或终止任务。

适合谁：适合用 Codex、Claude Code 等 Agent 处理登录后网页操作，又想继续使用自己浏览器的用户
使用前准备：当前需使用 macOS，并安装 ego lite 应用及 ego-browser skill。

使用提醒：目前仅支持 macOS，Windows 和 Linux 尚在路线图中；经验积累与复用能力也仍未上线。

许可证：MIT

为什么本期上榜：过去 24 小时净增 +1,072 Star（历史快照核验）
GitHub 搜索：citrolabs/ego-lite
