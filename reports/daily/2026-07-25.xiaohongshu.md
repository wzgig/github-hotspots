01｜buzz
把人类、AI 代理、代码与工作流放进同一协作空间，让讨论、执行和审计留在一条事件记录里

它能做什么：

- 创建频道、私聊、画布和媒体讨论
- 让代理打开仓库、提交补丁并评审代码
- 把功能分支变成承载 CI 与合并决策的房间
- 用 YAML 触发消息、反应、定时或 Webhook 流程
- 搜索消息、补丁、审批与工作流记录

核心亮点：同一事件日志里的协作。消息、反应、流程步骤、审批和 Git 事件都写成带签名的事件；人和代理沿用同一身份模型、搜索索引与审计轨迹。

适合谁：适合希望自建协作空间，并让 AI 代理参与代码评审、故障追溯、发布流程和团队讨论的开发团队
使用前准备：源码运行需 Docker、Hermit；或 Rust 1.88+、Node 24+、pnpm 10+、just。Windows 需 bash 兼容 shell。

使用提醒：移动端、审批门禁和语音会话生命周期仍在接线；愿景栏目尚未落地，协作强调人类保持参与。

许可证：Apache-2.0

为什么本期上榜：过去 24 小时净增 +3,084 Star（历史快照核验）
GitHub 搜索：block/buzz

02｜worldmonitor
把新闻、地缘政治、市场与基础设施信号汇总到一张态势面板，方便持续观察全球事件变化

它能做什么：

- 汇总新闻源并生成 AI 简报
- 切换地球与 WebGL 平面地图
- 关联军事、经济、灾害和升级信号
- 查看国家压力、市场与基础设施指标
- 通过 MCP、REST、CLI 或 SDK 读取数据

核心亮点：跨数据流的态势关联。同一界面将新闻、地图、市场和基础设施数据并排呈现，再把军事、经济、灾害等信号做交叉关联，减少在多个来源间来回切换。

适合谁：适合需要追踪全球新闻、地缘风险、市场和基础设施动态的研究人员、分析团队与信息整合开发者
使用前准备：本地开发需安装项目依赖并运行开发服务；基础应用无需环境变量，特定数据源可能需要凭据。

使用提醒：特定数据源可能需要凭据；MCP 工具调用需要密钥或 OAuth，公开访问仅支持列出工具。

许可证：AGPL-3.0-only（Separate commercial or trademark permission needed）

为什么本期上榜：过去 24 小时净增 +1,725 Star（历史快照核验）
GitHub 搜索：koala73/worldmonitor

03｜OmniRoute
把多个 AI 模型供应商收进一个兼容 OpenAI 的入口，按额度、成本和健康状态自动选路与切换

它能做什么：

- 接入兼容 OpenAI 的聊天与多媒体接口
- 按成本、延迟、额度和健康状态路由
- 组合多个模型做回退、融合或流水线
- 压缩提示词、工具日志和历史上下文
- 通过 MCP、A2A、CLI 与 Webhook 管理网关

核心亮点：配额感知的自动模型路由。自动组合会持续评分已连接模型；遇到额度耗尽、服务失败或成本变化时转向下一目标，并可为编码、低延迟、低成本等任务选不同策略。

适合谁：适合需要统一管理多个模型供应商，并为编码工具、代理或应用配置路由、回退和用量控制的开发者
使用前准备：全局安装需 Node ≥22.22.2；源码运行需复制 .env 并安装依赖。

使用提醒：记忆功能默认关闭；远程令牌按权限分级，启动进程的接口仅允许本机回环访问。

许可证：MIT
