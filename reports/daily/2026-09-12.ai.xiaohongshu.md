# 标题

GitHub AI 日报 D063｜3 个项目到底能做什么

# 正文

2026-09-12 · D063 · AI 专题榜

AI 项目的名字往往很抽象。这一期不堆术语，只讲清它替谁做什么、能完成哪些任务，以及是否值得加入你的工具箱。

先看结论：
- deepseek-harness：为 AI Agent 搭建可插拔的多步任务执行框架，并提供本地 Web UI
- spec-kit：把需求转成规格、计划和任务，再交给 AI coding agent 按流程实现
- superpowers：给编程 Agent 加上一套从头脑风暴到测试收尾的开发方法

01｜deepseek-harness
为 AI Agent 搭建可插拔的多步任务执行框架，并提供本地 Web UI

它能做什么：

- 组合可插拔的 Agent 功能模块
- 组织连续多步任务流程
- 接入模型能力完成任务执行
- 启动本地 Web UI 操作项目
- 从源码构建并运行项目

核心亮点：Everything-is-a-plugin 的。项目以插件作为基本扩展单元，并基于 Cordis 组织可组合能力；这样可以把模型、工具和任务流程拆开接入。

适合谁：需要搭建可扩展 AI Agent 和本地任务流程的开发者
使用前准备：需要 Node.js；从源码运行还需要 Git、pnpm，并先执行 pnpm install 和 pnpm run build。

使用提醒：项目处于 developer preview 阶段，README 明确提示会发生兼容性破坏变更；运行前需查看安全说明。

许可证：MIT

GitHub 搜索：deepseek-ai/deepseek-harness

02｜spec-kit
把需求转成规格、计划和任务，再交给 AI coding agent 按流程实现

它能做什么：

- 建立项目原则和开发规范
- 把想法整理成规格说明
- 生成技术实现计划
- 拆分可执行开发任务
- 对照规格检查实现结果

核心亮点：让规格成为可执行流程。Spec Kit 将开发拆成 constitution、specify、plan、tasks、implement 和 converge 六步，让 AI coding agent 先理解目标，再

适合谁：希望让 AI coding agent 按规格推进新项目或迭代开发的团队
使用前准备：需要 Linux、macOS 或 Windows、受支持的 AI coding agent、uv 或 pipx、Python 3.11+ 和 Git。

使用提醒：流程依赖 AI coding agent 对规格的理解；README 说明社区扩展由各自作者维护，安装前需自行检查源码。

许可证：MIT

为什么本期上榜：过去 24 小时净增 +806 Star（历史快照核验）
GitHub 搜索：github/spec-kit

03｜superpowers
给编程 Agent 加上一套从头脑风暴到测试收尾的开发方法

它能做什么：

- 通过提问细化需求和设计
- 创建隔离的 Git worktree
- 生成带验证步骤的实施计划
- 按任务调度子 Agent 并复核
- 执行测试驱动开发流程

核心亮点：让 Agent 按研发方法工作。Superpowers 将 brainstorming、writing-plans、subagent-driven-development、TDD 和 code review 等可组合技能串成

适合谁：希望让编程 Agent 遵循固定研发方法的开发者和团队
使用前准备：需要在对应 coding agent 中单独安装插件；不同 harness 的安装方式不同，使用多个 harness 时需分别安装。

使用提醒：部分安装和更新方式依赖具体 coding agent；README 还说明可选视觉伴侣功能默认包含遥测，可通过环境变量关闭。

许可证：MIT
