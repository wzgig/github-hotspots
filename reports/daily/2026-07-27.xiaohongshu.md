01｜bitchat
让手机在无网时通过蓝牙组网聊天，有网时切到 Nostr 中继继续传递消息

它能做什么：

- 建立无需互联网的蓝牙网状聊天
- 通过附近设备多跳转发消息
- 切换到 Nostr 中继发送远程消息
- 创建按地理范围划分的位置频道
- 清除设备内保存的全部聊天数据

核心亮点：蓝牙与 Nostr 双通道传信。私信会优先使用已建立加密会话的蓝牙连接；蓝牙不可用时改走 Nostr，均不可用则排队，待通道恢复后自动发送。

适合谁：适合灾害、偏远地区或临时现场的离线沟通，也可用于基于地理范围的社区聊天
使用前准备：源码构建需 Xcode；真机签名还要填写 Apple Developer Team ID。使用 just 流程需先安装 just。

使用提醒：网状网络会使用由身份密钥派生的持久设备标识；Nostr 私信格式仅与 BitChat 客户端互通。

许可证：Unlicense

GitHub 搜索：permissionlesstech/bitchat

02｜buzz
把人、AI Agent、代码变更和工作流放进同一协作空间，并保留统一审计记录

它能做什么：

- 检索历史讨论并附上相关线程
- 让 Agent 分诊问题并保留独立身份记录
- 集中搜索对话、补丁、运行结果与审批
- 用 YAML 配置消息、反应或定时工作流
- 通过命令行以 JSON 接收和返回任务数据

核心亮点：所有协作动作汇入同一日志。消息、反应、补丁、审批、工作流和 Git 事件都以签名事件进入同一日志，因此人和 Agent 共用身份模型、搜索入口与审计轨迹。

适合谁：适合希望自托管团队空间，并让人和 AI Agent 共同处理代码、评审、发布与项目记忆的团队
使用前准备：源码启动需 Docker 与 Hermit；也可自备 Rust、Node、pnpm 和 just。Windows 还需 Git Bash。

使用提醒：移动客户端、工作流审批门和语音房间生命周期仍在接入；项目明确未完成，并要求人保持在决策环节。

许可证：Apache-2.0

为什么本期上榜：过去 24 小时净增 +1,235 Star（历史快照核验）
GitHub 搜索：block/buzz

03｜ego-lite
把已登录的浏览器状态交给 AI Agent 使用，同时让你的标签页不被自动化任务打扰

它能做什么：

- 迁移 Chrome 登录、Cookie、扩展和书签
- 为每个 Agent 创建独立浏览器空间
- 并行运行多个互不干扰的网页任务
- 读取包含嵌套 iframe 的页面快照
- 调用 snapshot、fill、click 等页面工具

核心亮点：共享登录状态，隔离操作空间。ego-browser 把页面快照、填写、点击、等待和跳转封装为 JavaScript 工具；Agent 在独立空间运行组合脚本，你仍可继续使用自己的标签页。

适合谁：适合让 Codex、Claude Code 等外部 Agent 使用现有登录状态执行网页采集、填写或批量处理任务的人
使用前准备：需要 macOS；可安装应用或通过 npx 添加 ego-browser skill，首次浏览任务会引导安装应用。

使用提醒：当前仅运行于 macOS，Windows 与 Linux 仍在路线图；经验积累功能尚未上线。

许可证：MIT
