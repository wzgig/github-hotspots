别只看 Star。这期把上榜项目翻成三件能直接判断的事：它做什么、能帮你完成什么、适不适合你。

先看结论：
- skills：把软件工程方法整理成可组合技能，帮助编程 Agent 按步骤完成研发任务
- superpowers：为编程 Agent 配置一套从需求澄清到代码交付的强制式开发流程
- agent-skills：把资深工程师的研发规范装进 AI 编程 Agent，覆盖定义、构建、验证、审查到发布

01｜skills
把软件工程方法整理成可组合技能，帮助编程 Agent 按步骤完成研发任务

它能做什么：

- 通过提问澄清需求和设计
- 建立项目共享术语与文档
- 按测试驱动流程实现功能
- 分阶段诊断错误与回归验证
- 扫描代码库寻找架构改进点

核心亮点：把工程经验变成可复用工作流。项目将需求澄清、共享术语、测试驱动开发、调试和架构审视拆成小型技能，可按需组合并写入项目文件。

适合谁：使用 Claude Code、Codex 等编程 Agent，希望规范研发流程的开发者
使用前准备：需在支持技能或插件的编程 Agent 中安装，并按仓库说明运行初始化技能。

使用提醒：架构扫描只是寻找改进候选，不会自动替你拆解老旧代码；安装方式也分为托管只读包和可编辑文件。

许可证：MIT

02｜superpowers
为编程 Agent 配置一套从需求澄清到代码交付的强制式开发流程

它能做什么：

- 通过头脑风暴澄清需求
- 创建隔离工作区并检查测试基线
- 把设计拆成可验证的小任务
- 按红绿重构编写测试和代码
- 在合并前执行代码审查与分支收尾

核心亮点：让 Agent 先规划，再动手写代码。Superpowers 会先提炼规格并让用户确认，再生成实施计划，随后按任务调用子 Agent、执行测试和代码审查，直到完成分支收尾。

适合谁：希望让编程 Agent 遵循测试、审查和交付流程的个人开发者与团队
使用前准备：需要针对所使用的 coding agent 或 harness 单独安装插件；不同工具有对应安装方式。

使用提醒：流程包含人工确认节点；可选的视觉伴侣功能会加载带版本信息的遥测资源，可通过环境变量关闭。

许可证：MIT

GitHub 搜索：obra/superpowers

03｜agent-skills
把资深工程师的研发规范装进 AI 编程 Agent，覆盖定义、构建、验证、审查到发布

它能做什么：

- 用命令澄清需求并生成规格
- 把规格拆成带验收标准的任务
- 按小步迭代实现并测试
- 执行代码、安全和性能审查
- 准备发布、迁移和可观测性工作

核心亮点：覆盖完整生命周期的技能包。项目按定义、计划、构建、验证、审查和发布分组技能，并配套命令、专业 Agent 与参考清单，让流程能跨多种编程工具复用。

适合谁：需要在多个 AI 编程工具中复用统一工程流程的开发者和团队
使用前准备：需要通过 skills CLI、原生插件或对应工具的技能目录安装；单独安装某项技能时可能缺少共享参考文件。

使用提醒：单独安装技能不会复制仓库级 references 目录，相关补充清单路径可能不可用；部分原生集成还需按工具单独配置。

许可证：MIT
