# 正文

2026-09-26 · D077 · AI 专题榜

AI 项目的名字往往很抽象。这一期不堆术语，只讲清它替谁做什么、能完成哪些任务，以及是否值得加入你的工具箱。

先看结论：
- hindsight：hindsight 可以搭建能够连续执行多步任务的 AI Agent，同时把模型能力接入可重复的任务流程
- ai-engineering-from-scratch：想要把外部工具和数据接入支持 MCP 的模型应用，可以用 ai-engineering-from-scratch；它能用统一协议建立工具调用连接
- superpowers：主要任务是给编程 Agent 提供可复用的软件开发技能；superpowers 还能让需求、编码和验证按固定流程推进

01｜hindsight
hindsight 可以搭建能够连续执行多步任务的 AI Agent，同时把模型能力接入可重复的任务流程

它能做什么：

- 把复杂任务拆成连续的执行步骤
- 让 Agent 围绕目标推进任务流程
- 为工具调用和工作流扩展提供基础

适合谁：需要搭建自动化智能体或多步骤 AI 工作流的开发者

为什么本期上榜：过去 24 小时净增 +2,351 Star（历史快照核验）
GitHub 搜索：vectorize-io/hindsight

02｜ai-engineering-from-scratch
想要把外部工具和数据接入支持 MCP 的模型应用，可以用 ai-engineering-from-scratch；它能用统一协议建立工具调用连接

它能做什么：

- 为模型应用提供标准化工具接口
- 连接外部数据源和可调用工具
- 把工具能力暴露给兼容 MCP 的客户端

适合谁：需要开发 MCP 服务或集成外部工具的应用开发者

为什么本期上榜：过去 24 小时净增 +1,107 Star（历史快照核验）
GitHub 搜索：rohitg00/ai-engineering-from-scratch

03｜superpowers
主要任务是给编程 Agent 提供可复用的软件开发技能；superpowers 还能让需求、编码和验证按固定流程推进

它能做什么：

- 把常用开发方法封装成可复用技能
- 按规划、实现和验证步骤组织任务
- 在不同项目中复用同一套开发流程

适合谁：希望让编程 Agent 按固定方法完成研发任务的开发者

为什么本期上榜：过去 24 小时净增 +492 Star（历史快照核验）
GitHub 搜索：obra/superpowers
