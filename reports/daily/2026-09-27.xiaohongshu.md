01｜paperclip
把多个 AI Agent 组织起来，按目标分工、执行、审批并追踪成本

它能做什么：

- 创建组织目标并分派给多个 Agent
- 按角色、权限和汇报关系组织 Agent
- 用心跳任务定时唤醒 Agent 执行工作
- 设置预算并在超支时暂停任务
- 通过审批、日志和工作产物审核结果

核心亮点：把多个 Agent 组织成一家公司。Paperclip 把 Agent 接入同一控制台：上层管理目标、组织、预算和审批，下层连接不同模型与运行时，让任务从分派、执行到审计都有记录。

适合谁：需要统筹多个 AI Agent、自动化业务流程并控制执行成本的团队或个人
使用前准备：需要 Node.js 24.11+ 和 pnpm 9.15+；可自托管并自动创建嵌入式 PostgreSQL。

使用提醒：遥测默认开启，可通过环境变量、配置文件或标准约定关闭；通过管道安装时，README 建议先审阅 install.sh。

许可证：MIT

02｜hindsight
给 AI Agent 加上会保存、检索并整理长期记忆的记忆层

它能做什么：

- 保存用户、项目或 Agent 的长期记忆
- 按语义、关键词、关系和时间检索记忆
- 基于已有记忆生成深入分析
- 把记忆自动接入现有 LLM 客户端
- 通过 MCP 暴露记忆工具

核心亮点：让 Agent 从记忆中持续学习。Hindsight 将信息写入隔离的 memory bank，再用 retain、recall、reflect 三种操作分别保存、检索和分析；观察结果会持续整合，帮助 Agent 根据新证据修

适合谁：需要让聊天机器人、Coding Agent 或业务 Agent 持续记住用户和项目上下文的开发者
使用前准备：自托管需配置 LLM 提供商和 API key；可通过 Docker、pip 或 Kubernetes 部署。

使用提醒：README 提醒：简单的 n8n 等 AI 工作流可能用不上 Hindsight，使用它可能显得过重。

许可证：MIT

为什么本期上榜：过去 24 小时净增 +1,952 Star（历史快照核验）
GitHub 搜索：vectorize-io/hindsight

03｜ai-engineering-from-scratch
用可运行的课程，从数学基础一路构建 LLM、Agent 与 AI 工具

它能做什么：

- 按阶段学习数学、机器学习和深度学习
- 从零实现算法，再用框架完成同类任务
- 运行每课代码并保存命令和结果证据
- 使用 AI tutor 获取分阶段学习路径
- 产出可复用的 prompt、skill、agent 或 MCP server

核心亮点：从数学推导到可运行 AI 工具。课程采用“理解概念—推导数学—手写实现—运行测试—交付工件”的路径，覆盖从基础算法到 LLM、Agent、MCP、生产部署和安全实践。

适合谁：想系统学习 AI 原理，并通过代码构建 LLM、Agent、MCP 和生产系统的学习者
使用前准备：会写代码（任何语言；Python 有帮助），并希望理解 AI 原理，而不只是调用 API。

使用提醒：认证学习内容不隶属于相关机构，也不能保证通过考试。

许可证：MIT（Attribution appreciated, not required.）
