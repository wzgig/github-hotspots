先看结论：
- rea：rea 可以把重复的开发操作整理成自动化流程，同时减少手动执行和重复配置

- claude-plugins-official：主要任务是把外部工具和数据接入支持 MCP 的模型应用；claude-plugins-official 还能用统一协议建立工具调用连接

01｜rea
rea 可以把重复的开发操作整理成自动化流程，同时减少手动执行和重复配置

它能做什么：

- 把常用开发步骤组合成可复用任务
- 通过脚本重复执行同一套操作
- 让团队共享一致的自动化工作流

适合谁：需要减少重复操作并统一研发流程的软件团队

为什么本期上榜：过去 24 小时净增 +18,671 Star（历史快照核验）
GitHub 搜索：morluto/rea

02｜ai-job-search
想要搭建能够连续执行多步任务的 AI Agent，可以用 ai-job-search；它能把模型能力接入可重复的任务流程

它能做什么：

- 把复杂任务拆成连续的执行步骤
- 让 Agent 围绕目标推进任务流程
- 为工具调用和工作流扩展提供基础

适合谁：需要搭建自动化智能体或多步骤 AI 工作流的开发者

为什么本期上榜：过去 24 小时净增 +2,224 Star（历史快照核验）
GitHub 搜索：MadsLorentzen/ai-job-search

03｜claude-plugins-official
主要任务是把外部工具和数据接入支持 MCP 的模型应用；claude-plugins-official 还能用统一协议建立工具调用连接

它能做什么：

- 为模型应用提供标准化工具接口
- 连接外部数据源和可调用工具
- 把工具能力暴露给兼容 MCP 的客户端

适合谁：需要开发 MCP 服务或集成外部工具的应用开发者

为什么本期上榜：过去 24 小时净增 +1,327 Star（历史快照核验）
GitHub 搜索：anthropics/claude-plugins-official
