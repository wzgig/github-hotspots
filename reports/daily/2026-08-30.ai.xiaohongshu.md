01｜scientific-agent-skills
给科研 AI Agent 装上可复用技能，覆盖检索、分析、建模与报告工作流

它能做什么：

- 检索论文、监管文件与临床试验记录
- 查询生物、化学与临床数据库
- 分析组学、分子与时序数据
- 生成可追溯的研究报告与图表
- 编排实验、建模和实验室自动化流程

核心亮点：把科研流程变成 Agent 技能。每项技能包含文档、代码示例、使用场景和参考资料，让 Agent 能按步骤连接数据库、Python 包与研究工具。

适合谁：做生物、化学、医学或数据研究的团队，想让 AI Agent 执行多步科研流程
使用前准备：需要支持 Agent Skills 标准的客户端；仓库工具要求 Python 3.13+ 和 uv

使用提醒：技能可执行代码、安装包并发起网络请求；安装前需逐项审阅 SKILL.md

许可证：MIT

02｜hermes-agent
让 AI Agent 持续执行任务、记住上下文，并从终端或聊天平台接收指令

它能做什么：

- 拆解并行推进多步任务
- 搜索历史对话与持久记忆
- 按计划执行任务并投递结果
- 通过 CLI、Telegram 等入口交互
- 切换模型并连接外部工具

核心亮点：让 Agent 在不同入口持续工作。Hermes 把终端界面、消息网关、记忆系统、定时调度和子 Agent 组合起来，支持本地、云端或远程环境运行。

适合谁：需要搭建个人助理、自动化流程或远程 Agent 工作台的开发者
使用前准备：需要配置模型提供方；部分工具还需各自的 API key

使用提醒：工具、消息平台和模型提供方需要分别配置，实际能力随目标运行环境而变化

许可证：MIT

为什么本期上榜：过去 24 小时净增 +264 Star（历史快照核验）
GitHub 搜索：NousResearch/hermes-agent

03｜firecrawl
把网页 URL 或搜索需求转成 Markdown、结构化数据和可供 Agent 使用的上下文

它能做什么：

- 搜索网页并返回结果正文
- 抓取 URL 并输出 Markdown、JSON 或截图
- 先点击、滚动页面再提取内容
- 发现整站 URL 并批量抓取页面
- 让 Agent 按自然语言寻找资料

核心亮点：把网页变成 Agent 可用数据。通过 Search、Scrape、Interact 等接口，Firecrawl 能搜索、操作和抓取网页，再输出 Markdown、结构化数据或截图。

适合谁：需要为 AI 应用、搜索系统或数据流程接入网页内容的开发者
使用前准备：需要注册托管服务并配置 API key；也可按文档自托管

使用提醒：抓取时需遵守网站政策、隐私政策与使用条款；默认遵守 robots.txt 指令

许可证：AGPL-3.0（The SDKs and some UI components are licensed under the MIT License.）
