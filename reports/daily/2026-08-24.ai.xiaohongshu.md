01｜hermes-agent
让 AI Agent 从任务经历中沉淀记忆与技能，并跨终端和聊天平台持续工作

它能做什么：

- 创建并持续改进任务技能
- 搜索历史会话并总结相关上下文
- 切换模型提供商而无需修改代码
- 派生隔离子智能体并行处理任务
- 用自然语言安排定时自动化任务

核心亮点：从经历中形成可复用技能。它把会话记忆、技能创建、使用中改进和跨会话检索连成学习闭环，让智能体不只执行当前指令，还能把复杂任务经验留给后续工作。

适合谁：适合需要长期运行个人智能体、跨平台处理任务，或并行编排多个子任务的开发者
使用前准备：需配置模型提供商；网页搜索、图像生成、语音等工具可能需要相应账号或 API Key

使用提醒：Termux 的完整依赖包含不兼容的语音组件；消息平台使用前需配置并启动网关

许可证：MIT

02｜MoneyPrinterTurbo
输入视频主题或关键词，自动完成脚本、素材、配音、字幕与短视频合成

它能做什么：

- 生成多语言视频脚本
- 匹配本地或在线高清素材
- 合成配音、字幕和背景音乐
- 批量生成多个候选视频
- 自动发布到短视频平台

核心亮点：把主题变成完整短视频。工作流从主题或关键词出发，依次生成脚本、提炼素材词、匹配或生成画面，再加入语音、字幕和音乐，最终输出可挑选或发布的成片。

适合谁：适合需要批量制作解说类短视频，并希望通过网页、接口或命令行控制流程的内容团队与开发者
使用前准备：本地部署需要 Python 3.11 或更高版本，并配置所用模型、素材源或语音服务的凭据

使用提醒：GPU 不是必需项，但本地转录和批量处理会更依赖硬件；AI Agent 生成方式目前支持 macOS 和 Windows

许可证：MIT

03｜ComfyUI
用可视化节点拼装图像、视频、音频与三维生成流程，并复用到应用接口

它能做什么：

- 拖拽节点搭建多媒体生成流程
- 保存并复用子图和工作流模板
- 局部重跑发生变化的处理节点
- 加载多类模型组件与控制模块
- 通过本地 API 接入其他应用

核心亮点：节点图驱动的生成工作流。每个节点负责模型加载、条件控制或媒体处理，连线决定数据流向；修改局部后只执行变化节点及其依赖，复杂流程还能保存、复用或封装成简化界面。

适合谁：适合需要细调生成链路的视觉创作者，以及把可复用 AI 工作流接入应用的开发者
使用前准备：本地手动安装需准备 Python、PyTorch、项目依赖，并把模型文件放入对应目录

使用提醒：稳定标签之外的提交可能不稳定并破坏自定义节点；部分 API 节点为付费可选项

许可证：GPL-3.0
