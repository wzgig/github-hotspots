01｜prime-agent
让编码与研究任务持续推进的自我改进型 agent

它能做什么：

- 在持久 REPL 中运行 Python 与命令
- 调用子 agent 并行或后台处理
- 把重复流程封装成可导入技能
- 让会话断开后任务继续运行
- 用目标、心跳和计划维持长期任务

核心亮点：把一次对话变成持续工作的任务环境。它用持久 Python 控制环境承载工具、子 agent 和上下文，再用 Continual Harness 保存提示、记忆与技能，让工作模式能在会话间延续。

适合谁：需要让编码、研究或评测任务跨聊天窗口持续推进的人
使用前准备：需要在 macOS 或 Linux 安装，并在首次启动运行 /login 选择订阅或 API-key provider。

使用提醒：会以当前用户权限执行模型生成的 Python 和项目命令，不是安全沙箱；应审查改动，并在外部受限环境运行不可信代码。

许可证：MIT

为什么本期上榜：过去 24 小时净增 +1,426 Star（历史快照核验）
GitHub 搜索：PrimeIntellect-ai/prime-agent

02｜firecrawl
把网页搜索、抓取和交互结果变成 AI 可用数据

它能做什么：

- 搜索网页并获取结果正文
- 抓取网址并输出 Markdown
- 抽取结构化 JSON 或截图
- 点击、滚动后再提取内容
- 批量抓取网站和多条网址

核心亮点：先找到网页，再交付可用数据。Search、Scrape、Interact 分别负责找页面、转格式和操作页面；Agent、Crawl、Map、Batch Scrape 覆盖更复杂的采集流程。

适合谁：为 AI agent、搜索产品或数据流程接入网页内容的开发者
使用前准备：先注册托管服务并获取 API key；也可安装 Python 或 Node.js SDK。

使用提醒：抓取者需遵守网站政策、隐私政策和使用条款；默认遵守 robots.txt。

许可证：AGPL-3.0

为什么本期上榜：过去 24 小时净增 +736 Star（历史快照核验）
GitHub 搜索：firecrawl/firecrawl

03｜ComfyUI
用节点图搭建并复用图像、视频、音频与 3D 创作流程

它能做什么：

- 搭建图像、视频、音频和 3D 流程
- 加载模型、VAE、LoRA 与 ControlNet
- 执行局部重算并管理显存
- 保存或恢复完整工作流与种子
- 用自定义节点扩展能力

核心亮点：把创作过程拆成可复用节点图。节点图把模型、参数和处理步骤连成工作流；支持子图、模板、JSON 保存与局部重算，便于反复调整和接入应用。

适合谁：需要精细控制模型、参数和输出的视觉创作者与内容团队
使用前准备：可在 Windows、Linux、macOS 运行；手动安装需准备 Python、PyTorch、依赖和模型文件。

使用提醒：Python 3.14 可能让部分自定义节点出问题；master 分支提交可能很不稳定并破坏许多自定义节点。

许可证：GPL-3.0

为什么本期上榜：过去 24 小时净增 +610 Star（历史快照核验）
GitHub 搜索：Comfy-Org/ComfyUI
