01｜MoneyPrinterTurbo
输入主题或关键词，自动完成脚本、素材、配音、字幕、音乐与高清短视频合成

它能做什么：

- 生成或导入视频脚本
- 匹配本地或在线高清素材
- 合成语音并提供实时试听
- 调整字幕样式与背景音乐
- 发布成片到 TikTok、Instagram 和 YouTube Shorts

核心亮点：从主题到成片的自动工作流。它把脚本生成、素材检索、语音合成、字幕与配乐串成自动流程，并提供 WebUI、API、CLI 和 AI Agent 入口，适合从主题快速产出成片。

适合谁：需要批量制作短视频，同时控制脚本、素材、配音、字幕和发布流程的内容创作者与自动化开发者。
使用前准备：本地部署需要 Python 3.11 或更高版本；也可使用 Windows 启动包、Docker 或 AI Agent。

使用提醒：部分云端模型与语音服务需要对应平台凭据；首次使用 Whisper 会下载模型，Windows 项目路径应避开中文、特殊字符和空格。

许可证：MIT

02｜ai-memory
让不同 AI 编码代理共享项目记忆，换工具后仍能接着未完成的工作

它能做什么：

- 捕获提示、工具调用和会话边界
- 编译可用 Git 追踪的 Markdown wiki
- 在不同编码代理间递送任务交接
- 检索决策、失败尝试与项目规则
- 隔离不同项目的记忆空间

核心亮点：跨编码代理延续任务上下文。它用生命周期钩子收集经过清理的会话观察，在会话结束时编译成 Git 版本化的 Markdown wiki，再把有限的交接摘要送给下一个代理。

适合谁：经常在 Claude Code、Codex 等编码代理间切换，并希望保留项目决策、失败尝试和待办线索的个人或团队。
使用前准备：需要 Docker 加支持矩阵中的代理 CLI，或其他能使用 MCP 的客户端。

使用提醒：直接启动的捕获不是完整原生转录；Codex 没有自动的真实会话结束钩子，需手动运行 finalize-session；历史代码结论应回到当前代码核验。

许可证：MIT

03｜omlx
把 Apple Silicon 上的本地模型变成可由 OpenAI 或 Anthropic 客户端调用的推理服务

它能做什么：

- 自动发现多类 MLX 模型
- 同时托管语言、视觉、嵌入与重排模型
- 按内存压力自动卸载闲置模型
- 缓存相同前缀以减少重复计算
- 提供 OpenAI 与 Anthropic 兼容接口

核心亮点：冷热分层的 KV 缓存。它把常用 KV 缓存留在内存、冷数据转存 SSD，并用连续批处理承接并发请求；菜单栏和管理面板负责模型装卸、监控与参数调整。

适合谁：想在 Apple Silicon Mac 上托管本地模型，并接入编码代理、聊天工具或兼容 API 客户端的用户。
使用前准备：需要 macOS 15.0+、Python 3.11–3.13 和 Apple Silicon；安装原生自定义内核还需要完整 Xcode。

使用提醒：工具调用取决于模型聊天模板是否支持 tools；部分模型的原生自定义内核需完整 Xcode，普通源码安装不会构建这些内核。

许可证：Apache-2.0
