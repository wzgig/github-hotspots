# 正文

别只看 Star。这期把上榜项目翻成三件能直接判断的事：它做什么、能帮你完成什么、适不适合你。

先看结论：
- public-apis：按领域整理公开 API，帮你为应用寻找可调用的数据与服务接口
- skills：把软件工程方法拆成可组合技能，让编码 Agent 按步骤协作、测试和改进代码
- unsloth：在本地运行、训练和部署多类 AI 模型，并通过界面或 API 接入工作流

01｜public-apis
按领域整理公开 API，帮你为应用寻找可调用的数据与服务接口

它能做什么：

- 按领域查找天气、金融、地图等 API
- 查看接口是否需要 apiKey 或 OAuth
- 核对接口是否支持 HTTPS 和 CORS
- 从条目描述判断可提供的数据或服务
- 通过贡献指南补充或修正 API 条目

核心亮点：把找 API 变成按领域查清单。仓库将公开 API 按动物、金融、地图、开发等领域分组，并为条目列出描述、认证、HTTPS 与 CORS，便于先筛选再接入。

适合谁：需要为原型、网站或工具寻找外部数据接口的开发者
使用前准备：具体认证方式随 API 条目而异，需按列表准备 apiKey、OAuth 或免认证访问。

使用提醒：清单由社区人工维护；每个接口的认证、HTTPS、CORS 和实际可用性仍需逐条核对。

许可证：MIT

为什么本期上榜：过去 24 小时净增 +2,005 Star（历史快照核验）
GitHub 搜索：public-apis/public-apis

02｜skills
把软件工程方法拆成可组合技能，让编码 Agent 按步骤协作、测试和改进代码

它能做什么：

- 通过提问澄清需求和目标
- 建立项目共享术语与决策文档
- 按红绿重构流程推动测试开发
- 分阶段诊断并修复代码问题
- 扫描代码库寻找架构改进机会

核心亮点：把工程习惯封装成可调用技能。技能按用户调用与模型调用拆分，分别负责组织流程和复用工程纪律；文件保持小巧、可组合并能改写成自己的工作流。

适合谁：希望让 Claude Code、Codex 等编码 Agent 遵循工程流程的开发者
使用前准备：安装 Claude Code 插件或使用 npx skills@latest add mattpocock/skills，再在每个仓库运行 /setup-m将?

使用提醒：Claude Code 插件以只读方式管理并自动更新；可编辑安装会把文件复制进项目，不能同时安装两种方式，否则技能会重复。

许可证：MIT

为什么本期上榜：过去 24 小时净增 +1,129 Star（历史快照核验）
GitHub 搜索：mattpocock/skills

03｜unsloth
在本地运行、训练和部署多类 AI 模型，并通过界面或 API 接入工作流

它能做什么：

- 在本地运行 LLM、扩散和音频模型
- 通过 LoRA、QLoRA 等方式微调模型
- 把模型接入 Claude Code、Codex 和 MCP
- 从 PDF、CSV、DOCX 构建训练数据集
- 导出模型并提供 OpenAI 兼容 API

核心亮点：从本地模型到 Agent 工作流。Unsloth 用桌面应用、Web UI 和代码版覆盖模型运行、训练、导出与部署，还能把本地模型作为 Claude Code、Codex 等 Agent 的子模型。

适合谁：想在本机运行或训练大模型，并连接编码 Agent 的开发者
使用前准备：桌面版无需额外设置；代码版需按系统安装 Python 3.13、uv，并准备对应的 PyTorch 或硬件环境。

使用提醒：公开访问时，持有链接和 API key 的人可运行服务器工具与代码；默认仅本机访问，开放网络前需保护密钥并确认网络边界。

许可证：Apache-2.0

为什么本期上榜：过去 24 小时净增 +735 Star（历史快照核验）
