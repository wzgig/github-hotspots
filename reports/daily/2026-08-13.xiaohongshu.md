01｜semantica
把企业数据整理成可追溯的知识图谱，为 AI 决策补上依据与审计链

它能做什么：

- 导入文件、网页、数据库和企业数据平台
- 抽取实体、关系和事件并构建知识图谱
- 记录决策并追溯因果链与来源
- 检测冲突并合并重复实体
- 用规则推理并导出审计轨迹

核心亮点：让 AI 决策留下完整来路。Semantica 把实体、事实、决策和因果关系放进可查询图谱，再用来源记录、规则推理和审计导出解释结果。

适合谁：需要让 AI Agent 使用可查询、可解释上下文的 AI 平台、数据与合规团队
使用前准备：需要先安装 semantica Python 包；连接 Databricks、Snowflake 等数据源需安装对应扩展。

使用提醒：ReteEngine 的条件匹配器较简单，接入合规流程前仍需用实际规则集核对 match_patterns() 输出。

许可证：MIT

为什么本期上榜：过去 24 小时净增 +840 Star（历史快照核验）
GitHub 搜索：semantica-agi/semantica

02｜orca
把多个编程 Agent 放进同一工作台，隔离执行、统一查看并继续跟进

它能做什么：

- 并排运行 Codex、Claude Code、OpenCode 或 Pi
- 为多个 Agent 创建隔离 Git worktree
- 从手机监控状态并发送后续指令
- 拆分终端窗口并保留滚动记录
- 标注 diff 并把修改意见发回 Agent

核心亮点：并行 Agent 的统一工作台。Orca 让多个命令行 Agent 各自在独立 worktree 中运行，集中显示执行状态，还能从终端、手机和代码 diff 继续推进任务。

适合谁：需要并行开发、比较多个 Agent 结果并远程跟进任务的个人开发者和团队
使用前准备：需要安装 Orca 桌面端；手机伴侣需要与桌面应用配对。

使用提醒：手机端依赖桌面端配对；匿名使用数据的收集范围和退出方式需按隐私与遥测文档配置。

许可证：MIT

为什么本期上榜：过去 24 小时净增 +1,092 Star（历史快照核验）
GitHub 搜索：stablyai/orca

03｜diagram-design
把架构、流程和数据关系转成带品牌样式的可交付图表

它能做什么：

- 生成架构图、流程图和时序图
- 选择浅色、深色或编辑风格变体
- 读取网站并提取颜色与字体
- 把 draw.io 或 Mermaid 重绘为指定尺寸和细节
- 导出 SVG 或 PNG 用于 Figma、演示和社交卡片

核心亮点：从源图到品牌化交付图。它先按图表类型生成或重绘内容，再根据目标尺寸、细节和受众调整布局，并把网站配色与字体应用到整套图表。

适合谁：用 Claude Code、Codex 或 Pi 制作技术文档、演示和内容配图的人
使用前准备：需要 Claude Code、Codex 或 Pi 等兼容 Agent Skills 的工具；导出 PNG 需安装 Playwright 与 Chromium。

使用提醒：Mermaid 导入只解析文本，不渲染 JavaScript、浏览器或网络内容；导入结果会提供被合并、折叠或删除内容的说明。

许可证：MIT
