01｜TencentDB-Agent-Memory
把对话、文档和代码沉淀成团队可复用的 Agent 记忆资产

它能做什么：

- 提取对话中的事实、偏好和决策
- 从任务中整理可复用 Skill
- 把文档生成结构化 Wiki 页面
- 索引代码符号、调用关系和影响路径
- 按成员、角色或 Agent 分配资产

核心亮点：让 Agent 团队继承共同经验。它把对话、Skill、Wiki 和 CodeGraph 统一成可管理资产，再按团队、权限和 Agent 绑定关系按需调用。

适合谁：需要让多个 Agent 共享项目知识、经验和权限边界的团队
使用前准备：需启动 memory-core、memory-hub 和 proxy，并在 .env 填入两组 LLM 参数。

使用提醒：Wiki 和 CodeGraph 需要异步处理；CodeGraph 目前优先支持公开 HTTPS 仓库，私有仓库和 SSH 支持仍在完善；资产绑定仍需人工操作。

许可证：MIT

GitHub 搜索：TencentCloud/TencentDB-Agent-Memory

02｜superpowers
让编程 Agent 先澄清需求，再按计划、测试和复盘流程完成开发

它能做什么：

- 通过提问澄清需求和设计选项
- 保存设计并拆分实施任务
- 创建隔离工作区并检查测试基线
- 按 RED-GREEN-REFACTOR 编码
- 审查任务是否符合规格和代码质量

核心亮点：把编码 Agent 变成流程化协作者。它用可组合技能串起头脑风暴、设计确认、计划拆解、子 Agent 开发、测试驱动和代码审查，技能会按任务自动触发。

适合谁：希望让编程 Agent 按固定研发方法推进项目的开发者
使用前准备：需在所使用的 coding agent 中单独安装 Superpowers；不同 harness 需要分别安装。

使用提醒：设计需先获得用户确认；部分执行流程保留人工检查点；项目通常不接受新增技能贡献，技能改动还需兼容支持的 coding agent。

许可证：MIT

GitHub 搜索：obra/superpowers

03｜DeepSeek-Reasonix
在终端、桌面端或 VS Code 里运行可配置、可扩展的 DeepSeek 编程 Agent

它能做什么：

- 在 reasonix.toml 中配置 Provider 和工具
- 接入 OpenAI 兼容的模型端点
- 通过 MCP 服务扩展工具和资源
- 用 CLI、TUI、桌面端或 VS Code 工作
- 裁剪过期工具输出并维护会话上下文

核心亮点：围绕前缀缓存设计的本地 Agent。Reasonix 是单一静态 Go 二进制，通过配置驱动模型、工具和插件，并在长会话中保持稳定前缀、裁剪过期输出。

适合谁：想在本地终端或编辑器中使用可配置 coding agent 的开发者
使用前准备：CLI 使用前需安装二进制并运行 reasonix setup 配置 Provider 和模型；VS Code 扩展需先完成 CLI 安装。

使用提醒：VS Code 扩展不内置 CLI，而是启动本地 reasonix acp 后端；不同入口的安装方式不同，部分插件能力依赖对应宿主环境。

许可证：MIT
