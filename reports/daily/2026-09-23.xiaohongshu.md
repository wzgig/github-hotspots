01｜ECC
把 AI 写代码变成有计划、测试和复核的开发流程，并留下可供下次接手的经验。

它能做什么：

- 生成可供确认和修改的功能实施计划
- 用失败测试复现缺陷，再验证修复结果
- 在独立上下文中审查代码改动
- 把会话经验提炼为可复用技能
- 扫描智能体配置中的权限与注入风险

核心亮点：让编程助手按工程流程交付。ECC 用分工明确的智能体和可复用技能串起计划、测试、实现与审查，再由事件触发脚本执行检查、记忆模块保存经验，让开发流程不必每次靠提示词重建。

适合谁：使用 AI 编程助手开发功能、修复缺陷，需要把计划、测试、代码审查和会话交接串起来的软件团队。
使用前准备：通用安装包需 Node.js 18 或更新版本；Claude 插件另需 Git 和 Claude Code 2.1 或更新版本。

使用提醒：各平台能力不齐；启用执行脚本需明确确认，记忆内容须核验；Windows 原生记忆写入有已知缺陷；私有仓库托管分析属于付费 Pro。

许可证：MIT

02｜mvt
帮取证调查员分析手机采集数据，寻找 Android 和 iOS 设备可能遭间谍软件攻击的痕迹。

它能做什么：

- 分析 iOS 设备采集的取证数据
- 分析 Android 设备采集的取证数据
- 下载用于比对的已知入侵线索
- 比对公开线索，查找已知间谍软件痕迹
- 通过插件加入额外取证模块

核心亮点：用已知攻击线索辅助手机取证。MVT 分别分析 Android 和 iOS 设备采集数据，并用入侵指标——已知攻击留下的线索——寻找疑似间谍软件痕迹。它辅助调查，不把未命中线索等同于设备没有问题。

适合谁：具备数字取证知识的技术人员和调查员，在设备持有人同意的前提下调查疑似手机间谍软件攻击。
使用前准备：需要理解数字取证并会使用命令行；安装还需按文档准备依赖。

使用提醒：不适合普通用户自查；公开指标不足以证明设备未受攻击，全面调查还需非公开线索与威胁情报；v3 引入不兼容变化，依赖旧输出的脚本可能失效。

为什么本期上榜：过去 24 小时净增 +379 Star（历史快照核验）
GitHub 搜索：mvt-project/mvt

03｜deepseek-harness
为想扩展智能体运行方式的开发者提供插件化框架，并带有可本地启动的网页界面。

它能做什么：

- 启动可在浏览器访问的本地网页界面
- 选择仅启动服务而不自动打开浏览器
- 从源码构建并运行项目
- 在修改源码时自动重建网页客户端

核心亮点：以插件组织智能体运行框架。DeepSeek Harness 基于 Cordis，把智能体运行框架组织成插件架构。项目提供本地网页入口，也提供源码构建和修改后自动重建客户端的开发流程，方便研究和扩展。

适合谁：想研究插件化智能体运行框架、开发相关插件，或从源码调试网页界面的开发者。
使用前准备：通过 npm 运行前需安装 Node.js；从源码运行需用 pnpm 安装依赖并完成构建。

使用提醒：仍处于开发者预览阶段，会出现不兼容变更；运行前需阅读安全说明；从源码启动时使用已构建产物，不会自动重新构建。

许可证：MIT
