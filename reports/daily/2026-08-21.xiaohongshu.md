01｜skills
把软件工程方法拆成可组合的 Agent 技能，帮助开发者澄清需求、测试代码、诊断缺陷和改进架构。

它能做什么：

- 追问需求，补齐变更前的关键决策
- 建立共享术语并更新 CONTEXT.md 与 ADR
- 按红绿重构循环实现功能或修复问题
- 分阶段定位缺陷并补上回归测试
- 扫描架构改进机会并输出可视化报告

核心亮点：可组合的工程实践技能。每项技能聚焦一个工程环节，可由用户主动调用或由模型按任务匹配；它们把需求访谈、领域建模、测试、调试和代码审查组织成可重复流程，同时允许按项目修改。

适合谁：希望保留开发控制权，并让编码 Agent 遵循需求澄清、测试、调试和架构实践的开发者。
使用前准备：通过 Claude Code 插件或 skills.sh 任选一种方式安装，再在每个仓库运行一次 /setup-matt-pocock-skills。

使用提醒：两种安装方式不要同时使用，否则每项技能会重复；插件版为只读托管包，复制到项目的技能文件需自行更新。

许可证：MIT

02｜career-ops
把职位链接变成匹配评估、定制简历和申请记录，帮助求职者筛出更值得投入的机会。

它能做什么：

- 粘贴职位网址，生成评估、简历和跟踪记录
- 扫描招聘门户并汇总新职位
- 对照简历评估匹配度与岗位真实性
- 生成定制简历、求职信和申请邮件草稿
- 跟踪申请状态并分析拒绝与晋级模式

核心亮点：把职位链接变成决策包。系统读取职位链接或描述，对照个人简历和偏好评估匹配度、岗位风险与准备方向，再生成定制材料并写入统一跟踪表；AI 负责分析和起草，最终操作留给求职者。

适合谁：使用 AI 编码命令行求职，希望集中筛选职位、定制材料并跟踪申请进度的候选人。
使用前准备：需安装 Node.js，并准备可用的 AI 编码命令行、个人简历、资料档案和目标岗位信息；生成 PDF 还需安装 Playwright Chromium。

使用提醒：不会自动提交、发送或点击申请；所有 AI 生成内容都应在提交前核对，评估只是建议，也需遵守招聘平台条款。

许可证：MIT（without warranty of any kind）

03｜MoneyPrinterTurbo
输入主题或关键词，自动完成脚本、素材、配音、字幕与配乐，合成高清短视频。

它能做什么：

- 生成视频脚本或接入自定义脚本
- 匹配本地素材或在线高清素材
- 合成配音、字幕和背景音乐
- 输出横屏或竖屏高清视频
- 批量生成并跨平台发布成片

核心亮点：串起短视频制作全流程。工作流从主题或关键词出发，依次生成脚本、提炼素材关键词、匹配画面、合成语音与字幕，再加入背景音乐输出成片；模型、语音、素材和发布服务均可按需要替换。

适合谁：需要批量制作解说类短视频，并希望自行选择模型、语音、素材来源和发布渠道的内容创作者。
使用前准备：本地部署需 Python 3.11 或更高版本；按所选模型、语音或发布服务配置对应 API Key。

使用提醒：GPU 不是必需项，但本地转录、较重处理和批量生成更依赖显卡；在线模型、语音和发布功能可能需要外部服务凭据。
