AI 项目的名字往往很抽象。这一期不堆术语，只讲清它替谁做什么、能完成哪些任务，以及是否值得加入你的工具箱。

01｜speech-to-speech
把语音检测、转写、模型回复和语音合成串成可替换的实时语音 Agent 管线

它能做什么：

- 检测说话边界并处理对话轮次
- 实时转写语音并返回部分文本
- 流式生成模型回复和工具调用
- 合成语音并持续传回客户端
- 切换本地模型、托管接口或自建服务

核心亮点：四段式可替换语音管线。它把 VAD、STT、LLM、TTS 分线程串联，用队列传递语音、文本和回复；每段都能更换后端，便于按硬件、语言和部署方式组合。

适合谁：适合开发语音助手、机器人对话后端或需要自选模型与部署位置的团队
使用前准备：需要 Python 3.10+；使用默认远程模型时需配置对应接口密钥，本地模型则需自行启动兼容服务。

使用提醒：TCP 模式不含打断、实时转写事件和工具调用事件；LLM 代理自身不做认证与限流，只应在可信网络或网关后启用。

许可证：Apache-2.0

02｜ECC
把规划、测试、实现、复核和记忆固化为可复用的编程 Agent 工作体系

它能做什么：

- 规划功能并生成可审阅的实施方案
- 按测试先行流程推进代码修改
- 调用独立审查角色检查回归与风险
- 保存会话摘要并沉淀可复用技能
- 扫描提示词、钩子、权限和密钥配置

核心亮点：分层装配 Agent 工作体系。ECC 将技能、专用 Agent、规则、钩子和记忆分开管理：任务需要时加载流程，独立角色负责审查，外部钩子执行确定性检查。

适合谁：适合希望统一 AI 编程流程，并在 Claude Code、Codex 等工具间复用规范的团队
使用前准备：Claude Code 插件要求 CLI v2.1.0+；Codex 同步前需先运行一次，让本地配置文件存在。

使用提醒：同一工具不要叠加安装方式，否则会重复技能、命令或钩子；Codex 市场插件当前可能无法完整复制技能。

许可证：MIT

为什么本期上榜：过去 24 小时净增 +659 Star（历史快照核验）
GitHub 搜索：affaan-m/ECC

03｜hermes-agent
让 AI Agent 跨终端和聊天平台执行任务，并从会话经验中积累记忆与技能

它能做什么：

- 切换不同模型提供商而无需改代码
- 连接终端和多个消息平台继续对话
- 安排定时报告、备份和审计任务
- 搜索过往会话并生成上下文摘要
- 启动隔离子 Agent 并行处理任务

核心亮点：会积累经验的跨端 Agent。Hermes 把会话记忆、技能创建、历史搜索和用户模型连成学习循环，再通过统一网关把同一段工作延续到终端与聊天平台。

适合谁：适合需要长期运行个人 Agent、跨设备继续对话或安排周期任务的个人与团队
使用前准备：快速安装支持 Linux、macOS、WSL2、Termux 与原生 Windows；安装后需选择模型提供商并配置工具。

使用提醒：Termux 的完整依赖包含不兼容的语音组件，需使用精简安装项；记忆和自动任务仍需用户配置模型、工具与平台权限。

许可证：MIT
