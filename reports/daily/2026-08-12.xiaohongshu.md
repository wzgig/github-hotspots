01｜prime-agent
把编程与研究任务放进可持续运行的代理会话，并保留上下文、子代理和工作进度

它能做什么：

- 调用文件、终端和代理工具完成任务
- 启动子代理并以程序方式接收结果
- 断开终端后继续运行后台会话
- 设置目标、心跳和定时任务保持进度
- 复盘轨迹并更新可回滚的补充状态

核心亮点：会话之外仍能延续的代理状态。它把持久化 Python 控制环境与可保存的提示、记忆、技能和子代理配置组合起来，让长任务跨回合、跨终端继续，并允许基于证据做小幅更新和回滚。

适合谁：适合需要跨多个回合推进编程、研究或评测任务，并希望中断后继续工作的用户
使用前准备：需在 macOS 或 Linux 安装；首次启动用 /login 选择订阅或 API Key 提供方。

使用提醒：会以当前用户权限执行模型生成的 Python 与项目命令，不是安全沙箱；应审查改动，并在外部隔离环境运行不可信内容。

许可证：MIT

02｜semantica
把分散数据整理成可查询的上下文图，并为 AI 决策保留因果关系、来源和审计记录

它能做什么：

- 摄取文件、网页、数据库和数据平台内容
- 抽取实体、关系和事件并构建知识图谱
- 记录决策并追踪原因、先例和后续影响
- 检测冲突与重复实体后再合并数据
- 导出图谱、来源记录和审计结果

核心亮点：让每次决策都能沿图追溯。系统把决策作为图节点保存，并连接上游原因、证据和下游影响；再结合来源记录、规则校验与历史检索，回答决策为何发生、参考了什么以及影响了哪些对象。

适合谁：适合要为智能代理建立共享上下文、决策追踪或合规审计能力的数据、平台与风控团队
使用前准备：使用核心包需通过 pip 安装；连接图数据库、向量库或企业数据平台时还要安装对应可选依赖。

使用提醒：当前 ReteEngine 条件匹配较简单，接入合规闸门前需用实际规则集核对输出；性能结果也会受硬件、数据和后端影响。

许可证：MIT

03｜agency-agents
从角色库挑选专项 AI 代理，并安装到多种编程助手中处理开发、设计、营销和运营任务

它能做什么：

- 浏览不同专业团队的代理角色
- 按团队或角色筛选需要安装的内容
- 转换代理文件以适配多种编程助手
- 组合多个专项角色处理跨职能项目
- 复制并调整角色个性、流程和交付要求

核心亮点：把角色库装进现有编程助手。仓库用独立文件描述每个代理的身份、工作流程、交付物和衡量方式，再通过转换与安装脚本生成各工具需要的格式；用户可以只选一个角色，也能组合成跨职能团队。

适合谁：适合希望给现有编程助手补充专项角色，或按项目组建开发、设计、营销与测试协作流程的用户
使用前准备：可直接使用桌面应用；若走脚本方式，需在仓库中运行 convert.sh 和 install.sh，并已安装目标工具。

使用提醒：OpenCode 当前只会注册约 119 个代理并静默丢弃其余项，需按 division 安装子集；不同工具的安装目录和格式也不同。

许可证：MIT（Attribution appreciated but not required.）
