01｜gods-eye-view
把航班、船舶、卫星和公共摄像头放进可探索的实时三维地球

它能做什么：

- 追踪实时飞机、船舶和卫星
- 锁定目标并查看轨迹与元数据
- 切换夜视、热成像等视觉样式
- 叠加地震、火灾、交通和公共摄像头
- 用语音绘制路线、标注区域和查询图层

核心亮点：把公开信号汇成一颗可交互地球。项目把航班、船舶、卫星、地震、交通和公共摄像头等公开信号放进同一颗三维地球，并允许用户点击、追踪、标注或用语音操作。

适合谁：适合想把公开地理信号放到同一张地图上探索、演示或扩展的开发者
使用前准备：可直接启动；需要 Node.js 24.x（24.14.0 或更高）或 26.x。三维城市、语音等能力需要相应服务商密钥。

使用提醒：数据可能延迟、不完整、经过建模或推断；交通和摄像头部分包含模拟或粗略估计，不应用于导航、应急或其他安全关键场景。

许可证：MIT License

02｜i-have-adhd
让编程助手先给结论、列步骤，再带你完成下一步操作

它能做什么：

- 优先给出下一步行动
- 为多步任务生成编号清单
- 压缩无关延伸内容
- 在每轮回复中重述当前状态
- 以明确的下一步结束回答

核心亮点：让编程助手先行动再解释。这个 skill 会调整编程助手的输出方式：先说下一步行动，再把复杂任务拆成编号步骤，并压缩旁枝内容，让回答更容易直接执行。

适合谁：适合希望编程助手少铺垫、少跑题并更快执行任务的人
使用前准备：需要将该 skill/plugin 安装到你的编码助手；README 提供了 Claude Code 的安装方式。

使用提醒：README 只说明它改变编码助手的回复格式与流程，未说明适用于哪些其他助手或任务类型。

许可证：MIT

为什么本期上榜：过去 24 小时净增 +3,513 Star（历史快照核验）
GitHub 搜索：ayghri/i-have-adhd

03｜superpowers
让编程 Agent 按需求、计划、测试和评审流程推进开发

它能做什么：

- 通过提问澄清需求和设计
- 生成带文件路径的实现计划
- 按测试驱动流程编写代码
- 派发子 Agent 执行并进行两阶段评审
- 用独立工作树隔离开发分支

核心亮点：把开发方法装进 Agent 工作流。Superpowers 由可组合 skills 组成，会从需求澄清开始，经过设计确认、计划拆分、测试驱动实现和代码评审，组织 Agent 完成软件任务。

适合谁：适合希望让编程 Agent 遵循固定研发方法完成软件任务的开发者
使用前准备：需要按所用 coding agent 分别安装插件；不同 harness 的安装方式不同。

使用提醒：项目强调测试驱动和人工检查，但具体能力依赖所使用的 coding agent；部分 Agent 的安装、更新和会话行为不同。

许可证：MIT
