01｜rea
没有源码也想弄懂应用功能？rea 让智能体检查程序，带着证据解释实现方式。

它能做什么：

- 提取原生程序的伪代码与调用关系
- 梳理 Electron 模块与进程间通信
- 查看网页结构、脚本和网络活动
- 检查 Android 安装包中的类与方法
- 对比进程运行时的输出与文件变化

核心亮点：沿着证据追查应用功能。MCP 是智能体调用分析工具的接口。REA 在本地检查目标，返回代码、引用和未知项；智能体据此继续追查、解释行为，再编写和测试类似实现。

适合谁：需要在没有源码时追查应用功能、分析程序行为，并为自己的项目重建类似功能的开发者。
使用前准备：需 Node.js 22.x（>=22.19）、24.x（>=24.11）或26+及 npm；深度原生分析另需 Hopper、Ghidra 或 IDA。

使用提醒：安装配置变更需确认；运行时采集会以用户权限执行或操作目标。工具结果交给智能体后受模型方数据政策约束；使用者需自行取得必要授权。

许可证：MIT

02｜claude-mem
claude-mem 把编程会话中的操作变成长期记忆，让 Claude Code 下次接着项目背景工作。

它能做什么：

- 记录会话中的工具使用情况
- 生成供后续会话使用的语义摘要
- 按项目、日期或类型检索历史记录
- 展开某条记录前后的时间线
- 在网页查看实时记忆流

核心亮点：先找线索，再取记忆详情。先搜索精简索引，再沿时间线查看背景，最后只取相关记录的详情。配合自动记录与摘要，新会话能找回项目背景，不必一次塞入全部历史。

适合谁：使用 Claude Code 持续开发同一项目，需要跨会话保留工作背景、回查历史决策与修复记录的人。
使用前准备：需 Node.js 20.0.0 或更高版本，以及支持插件的新版 Claude Code；缺少 Bun、uv 时会自动安装，安装后需重启。

使用提醒：托管记忆试用结束后，未订阅会回退到 Anthropic 套餐；全局 npm 安装仅提供开发库，不会注册插件或配置后台服务。

许可证：Apache-2.0

03｜cc-switch
频繁换模型服务时，用 cc-switch 在桌面统一管理编程工具配置，不必逐个手改配置文件。

它能做什么：

- 切换编程工具使用的模型服务商
- 同步 MCP 外部工具连接配置
- 聚合多家服务商的模型到同一列表
- 在路由请求失败时切换备用服务商
- 按服务商和模型查看用量与支出

核心亮点：换模型连接，保留原有配置。选好服务商后，应用只替换地址、密钥和模型等连接字段，保留已有插件与其他共享设置；也可按项目保存整套配置，换项目时一起切换。

适合谁：同时使用多款 AI 编程工具，经常切换模型服务、维护工具配置，并需要核对用量与会话记录的开发者。
使用前准备：需图形桌面：Windows 10+、macOS 12+；Linux 需 glibc 2.35+ 与 WebKitGTK 4.1。

使用提醒：聚合模式不提供故障切换，Codex 模型列表变化需完整重启；连通性检查不验证密钥和模型。跨客户端使用订阅可能违反服务商条款，需自行评估。

许可证：MIT
