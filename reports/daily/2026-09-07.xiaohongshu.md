01｜ECC
让 AI 编程代理按计划、测试、评审和记忆协作完成开发任务

它能做什么：

- 规划功能并生成实施蓝图
- 按测试先行流程推进编码
- 从新上下文复查代码和安全问题
- 跨会话保存摘要、交接和经验
- 扫描代理配置、钩子和 MCP 风险

核心亮点：把 AI 编程变成工程化工作流。ECC 把规划、测试、实现、评审、验证和记忆串成一条流程，并用 agents、skills、hooks 与规则分别承载不同任务。

适合谁：使用 Claude Code、Codex 等编程代理，希望统一开发流程的软件团队
使用前准备：通用安装需要 Node.js 18 或更新版本；Claude 插件还需要 Git 和 Claude Code 2.1 或更新版本。

使用提醒：不同宿主的能力并不完全一致；GitHub Copilot 不提供 ECC hooks、运行时 agents、委派或原生 skill 发现。

许可证：MIT

GitHub 搜索：affaan-m/ECC

02｜diagram-design
把需求变成可直接打开的 HTML/SVG 图表，并按品牌和输出场景重绘

它能做什么：

- 按内容选择合适的图表类型
- 生成自包含 HTML 和 SVG 文件
- 读取网站配色与字体建立品牌样式
- 重绘 draw.io 或 Mermaid 图表
- 按格式、尺寸和细节导出 PNG 或 SVG

核心亮点：先判断语义，再选择图表布局。它把行为模式和视觉类型分开：先判断是队列、策略链或信任边界，再选择最合适的布局，默认输出静态图。

适合谁：需要制作技术文档、演示文稿或品牌化信息图的设计师与工程师
使用前准备：使用 PNG 导出需要安装 Playwright 和 Chromium；其他自包含 HTML 可直接在浏览器打开。

使用提醒：默认输出静态、无脚本 HTML；可选动效受固定控制器、无远程资源和可访问性规则约束。

许可证：MIT

为什么本期上榜：过去 24 小时净增 +645 Star（历史快照核验）
GitHub 搜索：cathrynlavery/diagram-design

03｜humanizer
把 AI 味较重的文字改写得更像人写，同时保留原意和事实

它能做什么：

- 识别 25 类常见写作模式
- 先生成改写稿再指出残留问题
- 根据样文匹配个人写作声音
- 改写文件时只处理文字内容
- 遇到缺失事实时先询问而不是编造

核心亮点：先找写作痕迹，再改写核对。Humanizer 会先标出 AI 文本的具体模式，再重写并对照原文事实；处理文件时保留代码、数据、frontmatter 和链接目标。

适合谁：需要润色发布稿、文档或产品文案，同时保留作者观点的人
使用前准备：通用安装需要 Skills CLI；使用 Claude 插件时需要 Claude Code 2.1.142 或更新版本。

使用提醒：它不会补写缺失事实；文件模式只修改 prose，代码、数据、frontmatter 和 link targets 会保持不变。

许可证：MIT
