01｜prime-agent
让编程与研究代理跨越单次对话，持续推进长任务并复用积累的工作方法

它能做什么：

- 编排子代理并行或后台处理任务
- 保留目标、上下文与运行中的会话
- 按心跳或计划时间重新进入任务
- 复盘轨迹并小幅更新辅助状态
- 把重复流程制作成可导入技能

核心亮点：会延续工作的持久代理。它把持久化 Python 控制环境与可更新的辅助状态结合起来，让会话、子代理、目标和经验跨终端连接继续保留，并支持回滚状态更新。

适合谁：适合需要代理长期处理代码、研究评测或后台任务，并希望保留进度与工作模式的用户
使用前准备：需在 macOS 或 Linux 安装，首次启动通过登录选择订阅或 API Key 提供方。

使用提醒：会以用户权限执行模型生成的 Python 和项目命令，并非安全沙箱；应检查改动，只使用可信仓库、指令、技能和扩展。

许可证：MIT

GitHub 搜索：PrimeIntellect-ai/prime-agent

02｜ComfyUI
用可视化节点拼装图片、视频、音频与三维内容流程，并保存为可复用工作流

它能做什么：

- 搭建图片、视频、音频和三维工作流
- 载入模型、编码器、LoRA 与适配器
- 执行修补、扩图、蒙版和图像合成
- 保存工作流并从生成媒体恢复参数
- 通过本地接口把工作流接入应用

核心亮点：把生成流程画成节点图。每个模型或处理步骤都能成为节点，用户用连线明确数据如何流动；工作流可保存、复用或包装成简化界面，修改后只执行受影响的部分。

适合谁：适合希望精细控制模型、参数和输出的视觉创作者，以及需要把生成流程接入应用的开发者
使用前准备：本地使用需选择桌面版、便携版或手动安装，并准备对应系统、硬件环境及所需模型文件。

使用提醒：主分支稳定标签之外的提交可能不稳定并破坏自定义节点；云端版本和可选 API 节点涉及付费服务。

许可证：GPL-3.0

为什么本期上榜：过去 24 小时净增 +736 Star（历史快照核验）
GitHub 搜索：Comfy-Org/ComfyUI

03｜agency-agents
把工程、设计、营销和运营等岗位拆成可安装的专职 AI 角色，按任务组建协作团队

它能做什么：

- 浏览并挑选不同职能的专职代理
- 安装代理到多种编程与助手工具
- 按部门筛选所需角色组合
- 转换角色文件以适配目标工具
- 复制并修改角色的个性与工作流

核心亮点：按岗位组建 AI 协作团队。每个角色文件包含身份、任务流程、交付物、衡量标准和沟通方式；转换与安装脚本再把同一套角色适配到不同工具，便于按项目组合使用。

适合谁：适合想为开发、设计、营销、测试或业务任务配置专职 AI 角色，并在现有工具中复用的人
使用前准备：可使用桌面应用直接安装；命令行方式需获取仓库，并运行转换或安装脚本选择目标工具与角色。

使用提醒：不同工具的角色格式和安装位置不同；OpenCode 当前只注册约 119 个角色，超出后会静默丢弃，需安装子集。

许可证：MIT
