# 正文

2026-07-26 · D015 · AI 专题榜

AI 项目的名字往往很抽象。这一期不堆术语，只讲清它替谁做什么、能完成哪些任务，以及是否值得加入你的工具箱。

先看结论：
- ego-lite：让 AI Agent 直接操作你已登录的浏览器，并在独立空间并行完成网页任务，不占用你的标签页
- superpowers：把需求澄清、方案确认、测试驱动开发和代码审查编成一套自动触发的 Agent 研发流程
- hermes-agent：把终端、聊天平台、定时任务和可学习技能接到同一个可长期运行的个人 Agent

01｜ego-lite
让 AI Agent 直接操作你已登录的浏览器，并在独立空间并行完成网页任务，不占用你的标签页

它能做什么：

- 读取页面快照，定位可交互内容
- 填写、点击、等待并跳转网页
- 并行运行多个互不干扰的浏览任务
- 接入 Codex、Claude Code 等 Agent CLI
- 迁移 Chrome 数据供 Agent 继承登录状态

核心亮点：人与 Agent 共用浏览器。每个 Agent 在独立 Space 中读取页面快照并调用浏览器工具；任务可并行执行，你仍保留自己的标签页和鼠标控制。

适合谁：需要让编码 Agent 使用真实登录状态处理网页流程，同时自己继续浏览的 macOS 用户
使用前准备：当前仅支持 macOS；需安装 ego lite 应用及 ego-browser 技能。

使用提醒：Windows 和 Linux 仍在路线图中；经验积累与技能自我改进能力标注为即将推出。

许可证：MIT

GitHub 搜索：citrolabs/ego-lite

02｜superpowers
把需求澄清、方案确认、测试驱动开发和代码审查编成一套自动触发的 Agent 研发流程

它能做什么：

- 引导对话，把模糊想法整理成设计文档
- 拆解计划，写明文件、实现与验证步骤
- 创建隔离工作区并检查测试基线
- 分派子 Agent 执行任务并逐项审查
- 验证测试后提供合并或保留分支选项

核心亮点：自动触发的研发方法链。技能会随开发阶段自动介入：先澄清与确认设计，再规划、测试驱动实现、代码审查，最后验证并处理开发分支。

适合谁：希望编码 Agent 按明确方案、测试和审查流程完成研发任务，而不是直接动手写代码的开发者
使用前准备：需按所用编码 Agent 单独安装；同时使用多个工具时要分别安装。

使用提醒：通常不接受新增技能贡献，更新还需兼容全部受支持的编码 Agent；可选视觉组件默认会向网站加载标识并携带版本信息，可关闭。

许可证：MIT

为什么本期上榜：过去 24 小时净增 +523 Star（历史快照核验）
GitHub 搜索：obra/superpowers

03｜hermes-agent
把终端、聊天平台、定时任务和可学习技能接到同一个可长期运行的个人 Agent

它能做什么：

- 切换模型提供方，无需修改代码
- 接入 Telegram、Discord 等消息平台
- 安排定时任务并把结果发送到指定平台
- 派生隔离子 Agent 并行处理工作流
- 迁移 OpenClaw 的设置、记忆、技能与密钥

核心亮点：会积累经验的闭环 Agent。它把持久记忆、会话检索、用户建模和技能创建串成学习闭环；复杂任务完成后沉淀技能，后续使用时继续改进。

适合谁：想把个人 Agent 部署在云端或本机，并通过终端和聊天应用持续处理自动化任务的用户
使用前准备：需选择并配置模型提供方；消息平台使用前需完成 gateway 设置。安装器会准备 Python、Node.js 等依赖。

使用提醒：Termux 的完整依赖包含不兼容的语音组件，需使用专用安装选项；手动开发安装应把虚拟环境放在源码目录外。

许可证：MIT
