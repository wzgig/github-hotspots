01｜rea
让 AI 追踪应用、网页和二进制的工作原理，并给出证据与实现线索

它能做什么：

- 分析原生二进制并返回伪代码、汇编和调用关系
- 拆解 JavaScript/Electron 的模块、路由与 IPC
- 观察网页结构、脚本、网络请求并截图
- 读取 .NET 程序集的元数据与 CIL 指令
- 让 AI 根据证据解释行为并编写实现

核心亮点：让 AI 沿着证据完成逆向分析。REA 通过 MCP 把多类分析工具接给 AI，返回代码引用、证据和未知项，方便继续追问、解释和实现。

适合谁：需要分析应用行为、还原二进制逻辑或让 AI 辅助逆向研究的人
使用前准备：需要 Node.js 22.x、24.x 或 26+；原生分析还要 Hopper、Ghidra 或 IDA。

使用提醒：静态分析不会运行应用；运行时采集会以当前用户权限与目标交互。

许可证：MIT（You must legally obtain and be authorized to use commercial tools）

为什么本期上榜：过去 24 小时净增 +10,351 Star（历史快照核验）
GitHub 搜索：morluto/rea

02｜VoiceStudio
把声音生成、克隆、配音和转写放进本地工作流

它能做什么：

- 克隆声音或设计新的声音风格
- 为视频生成带时间信息的配音
- 用悬浮组件进行语音听写
- 批量制作故事和有声书内容
- 通过本地 API 或 MCP 接入工作流

核心亮点：把声音制作整合进本地工作流。VoiceStudio 把声音克隆、设计、配音、听写和批处理放进桌面工作区，模型在本机运行，也能通过 API 或 MCP 接入其他工具。

适合谁：需要本地制作配音、克隆声音、视频字幕或有声内容的创作者和团队
使用前准备：支持 macOS、Linux 和 Windows；需按所选引擎安装模型，硬件会影响支持与速度。

使用提醒：远程服务可选；模型权重、声音和生成内容另有条件，克隆声音需获得许可。

许可证：AGPL-3.0（Clone voices only with permission.）

为什么本期上榜：过去 24 小时净增 +1,060 Star（历史快照核验）
GitHub 搜索：debpalash/VoiceStudio

03｜iFixAi
用可复现的检查和评分，审计 AI Agent 是否按业务规则完成任务

它能做什么：

- 运行 10 项默认检查或全部 60 项检查
- 通过 HTTP 接口测试真实部署的 Agent
- 检查权限、提示注入、隐私和失败处理
- 用独立模型裁判生成可引用评分
- 输出 A–F 评分、JSON 与 Markdown 报告

核心亮点：把 Agent 风险变成可核对评分。iFixAi 把 Agent 当作黑盒，通过检查权限、操作、提示注入和业务规则执行情况生成分项分数与总评。

适合谁：需要审计 AI Agent 权限、可靠性和业务规则执行情况的研发、风控与治理团队
使用前准备：需要 Python 3.10+；按被测模型和裁判配置 API 密钥，也可先用内置 mock 测试。

使用提醒：自评结果会标记为不可引用；接口暴露不足时可能记为 insufficient_evidence；Pro 是另行提供的服务。

许可证：Apache-2.0

为什么本期上榜：过去 24 小时净增 +585 Star（历史快照核验）
GitHub 搜索：ifixai-ai/iFixAi
