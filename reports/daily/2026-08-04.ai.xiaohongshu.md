01｜reverse-skill
为代码 AI 客户端判断安全任务类型，匹配工具与方法，并沉淀可复用的调查记录

它能做什么：

- 识别 APK、二进制、JS 等任务类型
- 检查本机可用工具并刷新工具索引
- 创建包含范围、时间线与工单的案例目录
- 调用逆向、恶意软件或接口安全流程
- 整理证据、发现、分析路径与报告

核心亮点：先定范围，再路由安全流程。任务先经过全局规则与范围门禁，确认授权和网络范围后，再由主路由选择场景技能、工具与脚本，最终把过程写入时间线、证据链和报告。

适合谁：使用代码 AI 客户端处理授权逆向、渗透测试、CTF 或安全研究任务的人员
使用前准备：需要 Java/JDK、Node.js 22.12+、Python 3.x，以及 Claude Code、Codex CLI、Cursor 等代码 AI 客户端

使用提醒：开始目标操作前必须完成授权与网络范围确认，未就绪时不执行目标操作。

许可证：MIT（**CTF-Sandbox-Orchestrator/**: **GNU GPLv3**）

02｜TencentDB-Agent-Memory
把对话、文档和代码整理成团队可审核、共享并按角色分配的 Agent 记忆资产

它能做什么：

- 提取对话中的事实、偏好与决策
- 沉淀带版本和验证规则的技能
- 生成文档 Wiki 与链接关系图
- 索引代码符号、调用关系和影响路径
- 为不同 Agent 绑定所需记忆资产

核心亮点：把团队经验变成可分配资产。系统把对话提炼为分层记忆和技能，把文档与代码构建成 Wiki、CodeGraph，再通过所有者、版本、可见性和 ACL 决定哪些 Agent 能按需调用。

适合谁：需要让多个 Agent 继承项目背景、工作经验和代码知识，并由团队统一管理权限的开发团队
使用前准备：部署前需准备两组 LLM 参数，并启动 memory-core、memory-hub 与 proxy 服务。

使用提醒：Wiki 和 CodeGraph 需异步构建；私有仓库与 SSH 凭据支持仍在完善，记忆资产目前以人工绑定为主。

许可证：MIT

03｜airllm
把大模型按层加载到显存，让低显存设备也能运行原本放不下的模型推理

它能做什么：

- 从 Hugging Face ID 或本地路径加载模型
- 把原始模型拆分并按层保存
- 逐层流式加载模型完成文本生成
- 启用 4bit 或 8bit 权重压缩
- 切换保存路径、预取与分析配置

核心亮点：只让一层模型占用显存。AirLLM 先把模型拆成分层文件，推理时只将当前层加载到 GPU，并可预取下一层；显存取决于单层大小，而不是整个模型体积。

适合谁：想在低显存 GPU 或 Apple silicon 设备上尝试大型开放模型推理的研究者与开发者
使用前准备：先安装 airllm；macOS 还需安装 mlx 和 torch，并且仅支持 Apple silicon。

使用提醒：首次推理会拆分并保存模型，需要充足磁盘空间；受限模型需 Hugging Face Token，部分配置仅特定模型支持。

许可证：Apache-2.0
