01｜MoneyPrinterTurbo
输入一个主题或关键词，MoneyPrinterTurbo 会生成脚本、匹配素材并合成高清短视频

它能做什么：

- 根据主题自动生成或接收自定义脚本
- 匹配本地素材或在线高清素材
- 生成配音与可调整样式的字幕
- 批量合成多个视频版本供选择
- 自动上传到多个短视频平台

核心亮点：从主题到成片的自动化链路。它把脚本生成、素材检索、配音、字幕和背景音乐串成一条流程，并提供 WebUI、API、CLI 与 AI Agent 多种入口。

适合谁：需要批量制作短视频，并希望减少脚本撰写、素材搜集和后期合成操作的内容创作者
使用前准备：本地部署需要 Python 3.11 或更高版本；云端模型、语音或发布服务可能需要对应 API Key。

使用提醒：跨平台发布需配置 Upload-Post 账号与 API Key；Whisper 首次使用需下载模型。

许可证：MIT

02｜career-ops
把职位网址或描述交给 career-ops，它会评估匹配度、生成定制简历并写入求职追踪记录

它能做什么：

- 扫描招聘门户并收集新职位
- 按结构化维度评估岗位匹配度
- 生成 ATS 定制 PDF 简历
- 研究公司并寻找合适联系人
- 追踪申请状态并检查数据完整性

核心亮点：把职位输入变成求职流水线。它把职位输入依次转成评估报告、ATS 简历 PDF 和追踪记录；AI 负责筛选与草拟，提交申请仍由你决定。

适合谁：希望在本地 AI 编程命令行中筛选职位、定制申请材料并管理求职进度的求职者
使用前准备：需要 Node.js 与受支持的 AI 编程 CLI；生成 PDF 时还需安装 Playwright Chromium。

使用提醒：不会自动发送、提交或点击申请；应人工核对生成内容，并遵守招聘门户的服务条款。

许可证：MIT（"as is", without warranty of any kind.）

03｜superpowers
给编程 Agent 装上一套可组合技能，让需求澄清、规划、测试、审查和收尾按固定流程推进

它能做什么：

- 启动编码前通过提问完善需求
- 将确认后的设计拆成小粒度任务
- 按测试先行流程实现与重构
- 派发子 Agent 执行并审查任务
- 在结束前验证测试并选择收尾方式

核心亮点：让编程 Agent 先设计再动手。它用可组合技能约束研发顺序：先澄清和确认设计，再规划任务、测试实现、分工审查，最后验证结果并处理开发分支。

适合谁：希望编程 Agent 先确认需求、遵循测试流程并分阶段审查实现结果的开发者
使用前准备：需要使用受支持的编程 Agent，并按对应插件、扩展或包管理方式单独安装。

使用提醒：多个编程工具需要分别安装；可选视觉伴侣默认从网站加载标志并携带版本信息。

许可证：MIT
