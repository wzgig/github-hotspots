01｜skills
把软件工程方法整理成可组合的代理技能，帮助团队约束需求、测试、调试与代码设计流程

它能做什么：

- 追问需求细节并消除设计分歧
- 建立共享术语并更新上下文文档
- 按红绿重构循环推进测试开发
- 分阶段诊断缺陷和性能回退
- 扫描代码库并列出架构改进候选

核心亮点：小而可组合的工程技能。每项技能封装一个工程环节，可由用户手动触发或由代理按任务调用；团队能按需组合、修改文件，而不是把整个开发过程交给固定框架。

适合谁：适合希望保留开发主导权，并用编码代理处理需求澄清、任务拆分、实现和审查的工程团队
使用前准备：先选择插件或 skills.sh 其中一种安装方式，并在每个仓库运行一次 setup-matt-pocock-skills。

使用提醒：插件方式安装的是托管只读集合；两种安装方式同时使用会产生重复技能，架构扫描也不会自动解开旧代码问题。

许可证：MIT

GitHub 搜索：mattpocock/skills

02｜OpenLogi
在本地管理罗技鼠标、键盘和摄像头，完成按键映射、设备参数与应用配置切换

它能做什么：

- 重映射鼠标与键盘按键动作
- 调整鼠标 DPI 与 SmartShift 滚轮
- 按应用焦点自动切换配置覆盖层
- 控制摄像头画面参数并保存配置
- 管理 Litra 灯光亮度与色温

核心亮点：配置直接写入设备与文本。图形界面旁提供命令行，通用设置集中在 TOML 文件；摄像头参数可写入 UVC 硬件，鼠标和键盘则通过 HID++ 与系统输入钩子控制。

适合谁：适合需要在 macOS、Linux 或 Windows 上本地配置罗技外设，并希望同步文本配置的用户
使用前准备：安装前先退出 Logi Options+；macOS 需要 macOS 13 或更高版本，Linux 安装后需启用用户代理服务。

使用提醒：项目仍在积极开发，功能和配置可能变化；应用配置在 Linux 仅支持 X11 或 XWayland，部分平台动作会失效。

许可证：Apache-2.0（all rights reserved, and are not covered by the MIT/Apache licenses above）

为什么本期上榜：过去 24 小时净增 +996 Star（历史快照核验）
GitHub 搜索：AprilNEA/OpenLogi

03｜codex
把编码代理带进本地终端，让用户通过命令行在自己的电脑上启动和使用 Codex

它能做什么：

- 通过 codex 命令启动终端代理
- 使用安装脚本部署命令行工具
- 通过 npm 或 Homebrew 完成安装
- 使用 ChatGPT 账户登录服务
- 改用 API Key 配置访问凭据

核心亮点：本地终端里的编码代理。Codex CLI 在用户电脑本地运行，通过独立安装器、包管理器或发布二进制部署；启动后可选择 ChatGPT 登录，也可另行配置 API Key。

适合谁：适合偏好终端工作流、希望在本地电脑运行编码代理，并能自行完成账户认证的开发者
使用前准备：先安装 Codex CLI，再准备可登录的 ChatGPT 账户；若使用 API Key，还需要完成额外配置。

使用提醒：仓库介绍的是终端版；编辑器版、桌面应用和云端代理属于其他入口，发布包也需按操作系统与处理器选择。

许可证：Apache-2.0
