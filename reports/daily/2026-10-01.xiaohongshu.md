- dbx：用一个跨平台客户端连接 100+ 数据库，完成查询、数据管理和 AI Agent 接入

01｜OpenShell
为自主 AI Agent 提供受策略约束的沙箱运行环境，控制文件、系统调用和网络访问

它能做什么：

- 隔离运行自主 AI Agent
- 限制文件、系统调用和网络连接
- 仅向获批端点注入真实凭据
- 验证策略变更可能新增的访问权限
- 通过网关统一管理沙箱与访问策略

核心亮点：把 Agent 的权限变成可审核策略。Agent 在隔离沙箱中运行，内核持续检查文件、系统调用和网络请求；策略变更先经形式化验证，再决定是否人工批准。

适合谁：需要让 AI Agent 访问文件、API 或凭据，同时控制权限边界的团队
使用前准备：需要 Linux、Apple Silicon 上的 macOS，或实验性的 Windows WSL 2，并配合 Docker、Podman 或主机虚拟化。

使用提醒：策略变更可能需要人工审核；软件访问的外部材料受其各自条款和许可证约束，需自行核查。

许可证：Apache-2.0

为什么本期上榜：过去 24 小时净增 +1,668 Star（历史快照核验）
GitHub 搜索：NVIDIA/OpenShell

02｜VoiceStudio
在本地完成声音克隆、语音设计、视频配音、听写和有声书制作

它能做什么：

- 克隆参考声音并生成文本语音
- 设计新的声音风格
- 为视频生成带时间对齐的配音
- 通过浮动组件进行听写
- 批量制作故事和有声书

核心亮点：把语音创作流程放到本地。VoiceStudio 将声音克隆、声音设计、配音、听写和模型管理放进同一桌面工作区，默认使用本地引擎，也可通过 API 或 MCP 接入代理。

适合谁：需要制作配音、有声书、听写稿或批量音频内容的创作者与团队
使用前准备：从源码运行需 Git、Node.js 22+、Bun、Rust/Cargo 和平台构建工具；模型需按所选引擎安装。

使用提醒：远程服务是可选项；使用分析需获得同意。模型有各自许可证，克隆声音需取得许可。

许可证：AGPL-3.0（Models have their own licenses; review them before commercial use.）

为什么本期上榜：过去 24 小时净增 +1,465 Star（历史快照核验）
GitHub 搜索：debpalash/VoiceStudio

03｜dbx
用一个跨平台客户端连接 100+ 数据库，完成查询、数据管理和 AI Agent 接入

它能做什么：

- 连接并浏览 100+ 数据库
- 编辑、执行和保存 SQL 查询
- 用自然语言生成、解释和优化 SQL
- 导入导出数据并迁移数据库
- 通过 MCP 让 AI Agent 查询数据库

核心亮点：数据库管理与 AI 接入合在一处。dbx 用一个客户端覆盖数据库连接、SQL 编辑器、数据操作和结构分析，并通过独立 MCP Server 把已配置连接提供给 AI Agent。

适合谁：需要同时管理多种数据库，并希望接入 AI 助手或 MCP 的开发者与运维人员
使用前准备：从源码开发需 Node.js >= 18、pnpm 和 Rust >= 1.88；Linux 还需安装 README 列出的系统依赖。

使用提醒：MCP Server 独立分发，安装 DBX 不会自动安装；MCP 的写入权限需在设置中管理，Windows 便携版还需配置 DBX_DATA_DIR。

许可证：Apache-2.0

为什么本期上榜：过去 24 小时净增 +700 Star（历史快照核验）
GitHub 搜索：t8y2/dbx
