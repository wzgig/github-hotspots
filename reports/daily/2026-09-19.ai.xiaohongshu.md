# 标题

GitHub AI 日报 D070｜3 个项目到底能做什么

# 正文

2026-09-19 · D070 · AI 专题榜

AI 项目的名字往往很抽象。这一期不堆术语，只讲清它替谁做什么、能完成哪些任务，以及是否值得加入你的工具箱。

先看结论：
- open-code-review：open-code-review 可以检查代码变更并整理审查意见，同时帮助团队发现问题和统一修改建议
- ECC：想要把重复的开发操作整理成自动化流程，可以用 ECC；它能减少手动执行和重复配置
- BrowserSkill：主要任务是搭建能够连续执行多步任务的 AI Agent；BrowserSkill 还能把模型能力接入可重复的任务流程

01｜open-code-review
open-code-review 可以检查代码变更并整理审查意见，同时帮助团队发现问题和统一修改建议

它能做什么：

- 逐项检查提交中的代码变更
- 标出潜在缺陷和需要确认的实现
- 把审查意见整理成可跟进的建议

适合谁：需要审查合并请求或统一代码质量标准的研发团队

为什么本期上榜：过去 24 小时净增 +2,237 Star（历史快照核验）
GitHub 搜索：alibaba/open-code-review

02｜ECC
想要把重复的开发操作整理成自动化流程，可以用 ECC；它能减少手动执行和重复配置

它能做什么：

- 把常用开发步骤组合成可复用任务
- 通过脚本重复执行同一套操作
- 让团队共享一致的自动化工作流

适合谁：需要减少重复操作并统一研发流程的软件团队

为什么本期上榜：过去 24 小时净增 +1,090 Star（历史快照核验）
GitHub 搜索：affaan-m/ECC

03｜BrowserSkill
主要任务是搭建能够连续执行多步任务的 AI Agent；BrowserSkill 还能把模型能力接入可重复的任务流程

它能做什么：

- 把复杂任务拆成连续的执行步骤
- 让 Agent 围绕目标推进任务流程
- 为工具调用和工作流扩展提供基础

适合谁：需要搭建自动化智能体或多步骤 AI 工作流的开发者

为什么本期上榜：过去 24 小时净增 +1,360 Star（历史快照核验）
GitHub 搜索：Tencent/BrowserSkill
