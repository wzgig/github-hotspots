AI 项目的名字往往很抽象。这一期不堆术语，只讲清它替谁做什么、能完成哪些任务，以及是否值得加入你的工具箱。

先看结论：
- deepseek-harness：为搭建 AI 智能体的开发者提供插件化运行框架，可启动本地网页界面。
- ECC：把规划、测试、审查和会话记忆装进编程助手，不必每次用提示词重搭研发流程。
- superpowers：先让编程助手问清需求，再把确认过的设计拆成任务，按先写测试、再实现的顺序推进。

01｜deepseek-harness
为搭建 AI 智能体的开发者提供插件化运行框架，可启动本地网页界面。

它能做什么：

- 启动本地网页界面并自动打开浏览器
- 关闭启动时自动打开浏览器的行为
- 构建源码后使用构建产物运行服务

核心亮点：以插件组织智能体框架。框架基于 Cordis，把各部分按插件架构组织。README 提供 npm 启动和源码构建两条运行路径，开发者可先启动网页界面，再了解架构与插件开发。

适合谁：希望研究插件化智能体框架，或从源码构建并启动网页界面的开发者。
使用前准备：通过 npm 启动前需安装 Node.js；从源码运行需先安装依赖并完成构建。

使用提醒：目前处于开发者预览阶段，明确会有破坏兼容性的变更；运行前需阅读安全说明。

许可证：MIT

02｜ECC
把规划、测试、审查和会话记忆装进编程助手，不必每次用提示词重搭研发流程。

它能做什么：

- 生成新功能的实施计划
- 用失败测试复现缺陷并验证修复
- 审查代码变更中的回归与遗漏
- 保存可供不同编程助手读取的任务记忆
- 扫描智能体配置中的权限与注入风险

核心亮点：把研发步骤变成可复用工作流。技能封装任务流程，专职助手分担规划与审查，事件触发脚本执行检查，会话记忆保留交接信息。由此串起计划、测试、实现、审查和验证，并积累可复用经验。

适合谁：需要让编程助手按流程开发功能、修复缺陷，并在长会话或不同助手间交接任务的软件团队。
使用前准备：通用安装包需 Node.js 18 或更新版本；Claude 插件还需 Git 和 Claude Code 2.1 或更新版本。

使用提醒：各平台功能不齐；同一助手勿叠加安装。钩子执行脚本需明确授权，记忆须核验；扫描器需预装并审查。私有库托管分析属于付费 Pro，Windows 原生记忆写入仍有缺陷。

许可证：MIT

03｜superpowers
先让编程助手问清需求，再把确认过的设计拆成任务，按先写测试、再实现的顺序推进。

它能做什么：

- 把需求对话整理成分段确认的设计文档
- 拆出带文件位置和验证步骤的实施任务
- 创建隔离工作区并检查测试基线
- 按先失败再通过的测试流程实现代码
- 逐项检查实现是否符合设计及质量要求

核心亮点：每项任务都经过两阶段审查。设计经用户认可后，计划被拆成小任务，分别交给新的子助手执行；先检查是否符合规格，再检查代码质量。任务之间继续审查，严重问题会阻止后续推进。

适合谁：希望先确认需求，再让编程助手分任务实现功能，并保留设计确认与代码审查环节的开发者。
使用前准备：需在所用编程助手中安装对应插件、扩展或包；使用多个助手时需分别安装。

使用提醒：设计与开工需用户确认；可选视觉辅助默认加载含版本信息的远程标志，可关闭遥测。Hermes 长会话压缩后可能丢失启动指引，需新开会话。

许可证：MIT
