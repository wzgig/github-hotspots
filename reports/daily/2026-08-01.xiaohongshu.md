01｜openwork
把技能、插件和服务集中共享，让团队在不同 AI Agent 中复用同一套工作流

它能做什么：

- 复用已分配的技能、插件和 MCP 连接
- 接入 Google Workspace 与 Microsoft 365 能力
- 搜索当前账号可以使用的能力
- 执行找到的能力完成具体任务
- 按组织、团队或个人分配技能和插件

核心亮点：一套能力跨 Agent 复用。OpenWork MCP 是连接层：兼容 Agent 通过它搜索和执行已分配能力，团队则在管理界面发布技能、配置服务连接并控制成员访问。

适合谁：需要跨多种 AI Agent 复用工作流，或统一管理团队能力与连接的个人、团队和组织管理员
使用前准备：需使用兼容 MCP 的 Agent；接入后通过浏览器登录并选择 OpenWork 组织

使用提醒：从现有 Agent 使用时仍需在浏览器完成登录和组织选择；桌面应用可选，并非必要组件。

为什么本期上榜：过去 24 小时净增 +787 Star（历史快照核验）
GitHub 搜索：different-ai/openwork

02｜hermes-agent
主要任务是搭建能够连续执行多步任务的 AI Agent；hermes-agent 还能把模型能力接入可重复的任务流程

它能做什么：

- 把复杂任务拆成连续的执行步骤
- 让 Agent 围绕目标推进任务流程
- 为工具调用和工作流扩展提供基础

适合谁：需要搭建自动化智能体或多步骤 AI 工作流的开发者

许可证：MIT

为什么本期上榜：过去 24 小时净增 +532 Star（历史快照核验）
