01｜rea
把应用功能从表面追到代码、二进制和运行行为

它能做什么：

- 检查原生二进制并返回伪代码、汇编与调用关系
- 分析 JavaScript 或 Electron 应用的模块与 IPC
- 观察网站结构、脚本、网络请求和页面截图
- 读取 .NET、Android APK、Flutter 应用等静态信息
- 让代理依据证据解释行为并编写测试实现

核心亮点：让代理沿着证据追查软件行为。REA 通过 MCP 把代理连接到多类分析工具，返回代码引用、证据和未知点；代理再据此追问、解释、实现和测试。

适合谁：需要分析应用、二进制或运行行为，并把结论用于复现功能的开发者
使用前准备：需要 Node.js 22.x（>=22.19）、24.x（>=24.11）或 26+，以及 npm；不同目标还需对应工具。

使用提醒：静态分析读取文件但不运行应用；运行时捕获会以当前用户权限运行或交互目标。

许可证：MIT（You must legally obtain and be authorized to use commercial tools）

GitHub 搜索：morluto/rea

02｜VoiceStudio
在本地完成克隆音色、视频配音和有声内容制作

它能做什么：

- 克隆已有声音或设计新的声音
- 按时间轴为视频生成配音
- 把语音实时听写成文字
- 制作故事、有声书和批量音频任务
- 通过本地 API、MCP、配方和监视文件夹接入工作流

核心亮点：把声音制作串进本地工作流。VoiceStudio 把声音克隆、语音设计、视频配音和模型管理放进桌面工作区，并提供本地 API 与 MCP，方便接入代理和重复任务。

适合谁：需要本地完成配音、克隆音色、语音输入或有声内容制作的创作者与开发者
使用前准备：需要 Node.js 22+、Bun、Rust/Cargo 和平台构建工具来从源码构建；模型与硬件要求因引擎而异。

使用提醒：模型权重、分词器、声音和生成结果的使用条件另行规定；Windows ARM 支持为实验性，部分硬件需远程后端。

许可证：AGPL-3.0（Clone voices only with permission.）

为什么本期上榜：过去 24 小时净增 +1,060 Star（历史快照核验）
GitHub 搜索：debpalash/VoiceStudio

03｜iFixAi
把 AI 代理当黑盒审计，检查它是否按业务规则完成任务

它能做什么：

- 用十项或六十项检查评估代理行为
- 测试权限边界、提示注入和破坏性操作
- 检查代理是否编造、偏题、隐瞒失败或过度自信
- 通过 HTTP 端点测试真实部署的代理
- 输出 JSON、Markdown 报告和分项评分卡

核心亮点：用可追溯评分检查代理是否按规矩办事。iFixAi 把被测代理作为黑盒，通过检查权限、可靠性、操控风险和透明度等维度评分；独立评审模型可生成更适合引用的结果。

适合谁：需要检查 AI 代理是否遵守权限、业务规则和任务目标的团队与评估人员
使用前准备：安装 Skill 只需 uv 和 Python 3.10+；运行测试还需模型提供商密钥或被测代理端点。

使用提醒：自评结果会标记为 self-judged，不能作为可引用结果；适配器未暴露足够能力时会标为 insufficient_evidence。

许可证：Apache 2.0

为什么本期上榜：过去 24 小时净增 +585 Star（历史快照核验）
