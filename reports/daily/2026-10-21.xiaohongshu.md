# 正文

别只看 Star。这期把上榜项目翻成三件能直接判断的事：它做什么、能帮你完成什么、适不适合你。

先看结论：
- ai-job-search：ai-job-search 可以搭建能够连续执行多步任务的 AI Agent，同时把模型能力接入可重复的任务流程
- rea：想要把重复的开发操作整理成自动化流程，可以用 rea；它能减少手动执行和重复配置
- orca：主要任务是集中运行和管理多个编程 Agent；orca 还能让开发任务可以并行推进

01｜ai-job-search
ai-job-search 可以搭建能够连续执行多步任务的 AI Agent，同时把模型能力接入可重复的任务流程

它能做什么：

- 把复杂任务拆成连续的执行步骤
- 让 Agent 围绕目标推进任务流程
- 为工具调用和工作流扩展提供基础

适合谁：需要搭建自动化智能体或多步骤 AI 工作流的开发者

为什么本期上榜：过去 24 小时净增 +4,160 Star（历史快照核验）
GitHub 搜索：MadsLorentzen/ai-job-search

02｜rea
想要把重复的开发操作整理成自动化流程，可以用 rea；它能减少手动执行和重复配置

它能做什么：

- 把常用开发步骤组合成可复用任务
- 通过脚本重复执行同一套操作
- 让团队共享一致的自动化工作流

适合谁：需要减少重复操作并统一研发流程的软件团队

为什么本期上榜：过去 24 小时净增 +14,079 Star（历史快照核验）
GitHub 搜索：morluto/rea

03｜orca
主要任务是集中运行和管理多个编程 Agent；orca 还能让开发任务可以并行推进

它能做什么：

- 在同一界面启动多个编程 Agent
- 把任务拆给不同 Agent 并行执行
- 集中查看各个 Agent 的执行状态

适合谁：需要统一管理多个编程 Agent 和并行任务的研发团队

为什么本期上榜：过去 24 小时净增 +1,867 Star（历史快照核验）
GitHub 搜索：stablyai/orca
