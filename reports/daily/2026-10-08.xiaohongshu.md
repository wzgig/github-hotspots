01｜rea
让编码智能体在没有源码时调查应用功能，带着实现证据为你的项目重建相似行为。

它能做什么：

- 追踪应用功能对应的函数与调用关系
- 反编译本机程序中的指定函数
- 梳理未运行的 JavaScript 应用结构
- 记录指定浏览器场景的交互证据
- 比较进程行为记录中的差异

核心亮点：从功能线索追到实现证据。从字符串、符号和调用关系追到实现代码，分析结果附带证据与未知项。REA 负责应用分析，编码智能体再用自己的编辑和测试工具，为你的项目实现相似功能。

适合谁：需要在缺少源码时研究应用功能、梳理未公开接口，或为自己的产品重建相似行为的开发者。
使用前准备：静态 JavaScript 检查需要 Node.js 和 npm；深度原生分析另需 Hopper、Ghidra 或 IDA Pro，依所选流程配置。

使用提醒：不保证恢复原始源码，也不自动克隆应用；安装配置变更需确认。进程捕获以用户权限运行，并非安全沙箱；智能体或模型提供方另有数据政策。

许可证：MIT

02｜skills
把需求澄清、任务拆分和测试审查变成可组合的智能体技能，让工程师自己掌握开发流程。

它能做什么：

- 通过追问澄清需求与设计分歧
- 把讨论整理为规格并发布到工单系统
- 将计划拆成带阻塞依赖的任务单
- 按先写失败测试的循环实现功能
- 分别审查代码规范与需求符合程度

核心亮点：按任务组合，而非接管开发流程。把需求追问、领域术语整理、测试驱动开发和代码审查拆成可组合的小技能。你选择何时调用流程，智能体也能按任务使用通用技能，而不是由整套框架接管开发。

适合谁：使用编码智能体开发应用，希望在需求对齐、任务拆分、测试和代码审查中保留流程控制权的工程师。
使用前准备：先安装到编码智能体；每个仓库使用工程技能前，运行 setup-matt-pocock-skills，配置工单系统、分类标签和文档位置。

使用提醒：插件版为只读包，市场更新可能滞后数天或数周；与可编辑文件版同时安装会重复。架构扫描只提供改进候选，不会自动解开旧代码的复杂结构。

03｜AnyPS5
为兼容性研究者将 PS5 可执行文件移植到 Linux 和 Windows，采用原生格式转换而非模拟。

它能做什么：

- 将可执行文件转换为目标系统原生格式
- 提供可动态链接的系统 prx 库实现
- 将着色器重编译为 SPIR-V
- 接入带摇杆和扳机的 SDL 映射手柄
- 通过配置文件设置键盘与鼠标控制

核心亮点：转换原生格式，不走模拟路线。重链接器把可执行文件转换成目标系统的原生格式，再配合可动态链接的系统 prx 库实现。它不使用模拟或独立运行时进程，但遇到不支持的状态会终止。

适合谁：研究 PS5 程序互操作、游戏保存与兼容性的开发者，需要尝试将可执行文件移植到 Linux 或 Windows。

使用提醒：遇到不支持或意外状态会报错并终止；系统库进度仅统计项目已知函数，不代表全部 PS5 系统函数。具体游戏的已测情况与问题需查兼容列表。

许可证：GPL-2.0
