01｜MoneyPrinterTurbo
输入主题或关键词，自动完成脚本、素材、配音、字幕和高清短视频合成

它能做什么：

- 生成多语言视频脚本或使用自定义脚本
- 匹配本地素材或在线高清素材
- 合成语音并实时试听不同音色
- 调整字幕样式、片段时长和背景音乐
- 上传成片至 TikTok、Instagram 和 YouTube Shorts

核心亮点：从主题到发布的完整链路。工作流把脚本生成、素材检索、语音合成、字幕与音乐配置串成成片流程，并提供批量候选和跨平台上传，减少在多个工具间手动搬运内容。

适合谁：适合需要批量制作短视频的内容创作者，以及希望通过 WebUI、API 或 CLI 接入视频工作流的团队
使用前准备：本地部署需要 Python 3.11 或更高版本；部分模型、语音、素材和发布服务需要对应 API Key

使用提醒：Windows 项目路径应避免中文、特殊字符或空格；Whisper 首次使用需下载模型，自动发布需另行配置账号凭据

许可证：MIT

02｜public-apis
按领域整理公共 API，并标出认证、HTTPS 与 CORS 情况，方便为产品寻找数据接口

它能做什么：

- 浏览不同业务领域的公共 API
- 查看每个接口提供的数据或任务
- 辨别接口是否要求 apiKey 或 OAuth
- 核对接口是否支持 HTTPS
- 筛选标明 CORS 状态的接口

核心亮点：把接口选择条件放在一张表里。每个分类用表格列出 API、用途、认证方式、HTTPS 和 CORS 状态，让读者先按领域缩小范围，再比较浏览器调用与凭据要求。

适合谁：适合为原型、课程作业或产品功能寻找外部数据接口，并希望先比较接入条件的开发者
使用前准备：调用前需按具体条目确认是否需要 apiKey 或 OAuth，并阅读对应接口文档

使用提醒：列表由社区成员人工维护；不同接口的认证、HTTPS 和 CORS 状态各异，接入前仍需核对目标服务

许可证：MIT

03｜ai-memory
为不同 AI 编程代理保存项目记忆，让中断后的任务能带着决策、失败尝试和待办继续

它能做什么：

- 捕获经过清理的提示与工具事件
- 汇总会话并生成下一次任务交接
- 检索历史决策、流程和失败尝试
- 切换代理时延续同一工作流
- 浏览和恢复 Git 版本化的记忆页面

核心亮点：让不同编程代理接着做。生命周期钩子把会话观察整理为 Markdown 维基和限长交接包；下一个代理可读取进度、开放问题与后续步骤，不必重新解释项目背景。

适合谁：适合频繁切换 Claude Code、Codex 等编程代理，或需要跨会话保留项目决策与上下文的开发者
使用前准备：快速启动需要 Docker，以及支持列表中的代理 CLI 或其他可使用 MCP 的客户端

使用提醒：生命周期捕获不是完整原生对话记录；Codex 无自动真实会话结束钩子，必要时需手动执行 finalize-session

许可证：MIT
