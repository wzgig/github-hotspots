01｜deepseek-harness
为开发者提供插件式智能体运行框架，并带有可本地启动的网页界面。

它能做什么：

- 通过 npm 命令启动本地网页界面
- 关闭启动时自动打开浏览器的行为
- 从源码构建后运行项目
- 在修改源码时自动重建网页客户端

核心亮点：以插件组织智能体运行框架。项目用 Cordis 支撑“一切皆插件”的架构，为智能体提供运行框架；既能通过 npm 启动网页界面，也提供源码构建和开发时自动重建客户端的流程。

适合谁：适合想研究插件式智能体架构，或从源码开发网页界面的开发者。
使用前准备：通过 npm 运行前需安装 Node.js；从源码运行需先用 pnpm 安装依赖并完成构建。

使用提醒：目前处于开发者预览阶段，会出现破坏兼容性的变更；运行前需阅读 SAFETY.md。源码启动使用已有构建产物，不会自动重新构建。

许可证：MIT

02｜ECC
把 AI 写代码变成有计划、测试和审查记录的开发流程，不必每次从提示词重新搭建。

它能做什么：

- 把功能需求整理成可确认的实施计划
- 用先写失败测试的流程推进代码实现
- 在独立上下文中审查代码改动
- 将会话经验提炼为可复用技能
- 扫描智能体配置中的权限与注入风险

核心亮点：让编程助手按工程流程交付。ECC 把计划、测试、实现、审查和验证串成可复用流程：技能按需加载，专门的智能体分担任务，事件触发脚本执行检查，再把会话经验沉淀为记忆与技能。

适合谁：适合用 AI 编程助手开发功能、修复缺陷，希望把计划、测试、独立审查和会话记忆纳入固定流程的软件团队。
使用前准备：通用包需 Node.js 18 或更新版；Claude 插件另需 Git 和 Claude Code 2.1 或更新版。扫描需已安装并审查的 Agent 与配置

使用提醒：各平台能力不齐；同一助手勿叠加安装。启用钩子需明确确认，记忆不能视为指令；Windows 原生记忆写入有已知缺陷。私有仓库托管分析属于付费 Pro。

许可证：MIT

03｜hermes-agent
在聊天中安排定时任务，让助手把完成任务的经验存成技能，供后续会话继续使用。

它能做什么：

- 从复杂任务经验中创建可复用技能
- 检索历史对话以找回跨会话信息
- 按自然语言安排定时任务和结果投递
- 通过聊天平台继续与远程助手协作
- 派出相互隔离的子智能体并行处理任务

核心亮点：把任务经验带到下一次会话。Hermes 在复杂任务后创建技能，并在后续使用中改进；配合持久记忆、历史对话检索和摘要，让后续会话能找回已有经验，而不只依赖当前聊天内容。

适合谁：适合希望通过聊天安排日报、备份或审计，并让助手跨会话记住任务经验的个人与自动化工作流开发者。
使用前准备：安装后需选择模型提供方与模型、配置启用的工具；通过聊天平台使用时，还需设置并启动消息网关。

使用提醒：Nous Portal 的模型与工具整合需订阅；Termux 完整依赖含不兼容的语音组件。手动开发时虚拟环境应放在源码目录外，避免被助手操作误删。

许可证：MIT
