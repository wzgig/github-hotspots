01｜skills
把软件工程方法拆成可组合的代理技能，帮助开发者对齐需求、测试代码和控制复杂度

它能做什么：

- 追问计划与设计中的未决问题
- 整理项目术语并更新上下文文档
- 把对话转成规格或可执行工单
- 按红绿重构循环实现和验证代码
- 诊断疑难缺陷并补充回归测试

核心亮点：小技能组合成工程流程。每项技能只负责一个清晰环节，可按任务组合使用；既有手动触发的流程编排，也有代理按场景调用的工程规范，让需求、设计、实现和反馈保持衔接。

适合谁：适合使用 Claude Code、Codex 等编码代理，并希望把需求澄清、实现、测试和审查流程标准化的开发者
使用前准备：安装后需在每个仓库运行一次 setup-matt-pocock-skills，并配置工单系统、标签与文档保存位置。

使用提醒：插件方式安装的是托管只读集合；文件方式可编辑但不会自动更新。两种方式同时安装会让每项技能重复出现。

许可证：MIT

GitHub 搜索：mattpocock/skills

02｜airi
在自己的设备上运行可对话、操控虚拟形象并参与游戏的数字伙伴

它能做什么：

- 进行实时语音输入、识别与说话检测
- 合成角色语音并切换多种服务提供方
- 控制 VRM 或 Live2D 模型及其动画
- 接入 Telegram 和 Discord 进行聊天
- 让角色参与 Minecraft 等游戏环境

核心亮点：把角色的脑耳口身接起来。项目把模型推理、音频输入、语音合成、角色动画和外部连接拆成协作模块，使数字角色不只停留在文字聊天，还能听、说、表现动作并进入游戏场景。

适合谁：适合制作 AI 虚拟角色、数字宠物或互动主播，并需要语音、形象、聊天与游戏能力协同的开发者和创作者
使用前准备：源码开发需先安装 pnpm 依赖；开发桌面版应按 CONTRIBUTING.md 配置环境。

使用提醒：项目仍处于早期开发阶段；Factorio 等部分游戏能力仍在开发，浏览器本地推理和记忆系统也尚未完成。

许可证：MIT

为什么本期上榜：过去 24 小时净增 +728 Star（历史快照核验）
GitHub 搜索：moeru-ai/airi

03｜GeoLibre
把本地地理数据带进浏览器、桌面和 Jupyter，完成制图、探索与空间分析

它能做什么：

- 加载并可视化多种地理空间数据
- 创建三维城市与地形地图场景
- 运行空间 SQL 查询和处理流程
- 按时间字段播放地图变化过程
- 分享、嵌入并复用地图项目

核心亮点：同一工作区跨端处理 GIS。它以 MapLibre、DuckDB-WASM Spatial 和 deck.gl 组成地图与分析能力，同一工作区可运行于现代浏览器、桌面、移动端和 Jupyter，并尽量把数据留在本地。

适合谁：适合需要制作地图、探索空间数据、执行地理分析或在 Jupyter 中嵌入 GIS 工作流的研究者与数据人员
使用前准备：网页版本无需安装；从源码运行或配置可选凭据时，需按 Getting Started 文档操作。

许可证：MIT
