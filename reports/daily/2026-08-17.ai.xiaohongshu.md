01｜unsloth
把大模型、图像与音频模型留在本机运行、训练和部署，并接入代理或应用工作流。

它能做什么：

- 在本机运行和训练多类 AI 模型
- 把本地模型接入 Codex 等代理
- 从 PDF、CSV、DOCX 构建数据集
- 导出 GGUF、FP8 等部署格式
- 通过兼容 OpenAI 的 API 提供模型

核心亮点：本地模型接入现有代理。Unsloth Start 先加载本地模型，再用一条命令连接 Codex、Claude Code 等代理；也可让代理保留当前模型，把 Unsloth 作为本地子代理。

适合谁：需要在自己的设备上训练或运行模型，并把模型接入编码代理、检索或内部应用的开发者。
使用前准备：桌面版可直接安装；代码版需按系统安装 Python 3.13、uv，并选择受支持的计算后端。

使用提醒：公开访问时，持有链接和 API Key 的人可在本机运行代码；暴露服务前应保管密钥并考虑关闭工具。

许可证：Apache 2.0 and AGPL-3.0（certain optional components, such as the Unsloth Studio UI）

02｜ToolJet
把数据库、API 和 SaaS 数据拖进可视化界面，搭出内部工具、仪表盘与业务应用。

它能做什么：

- 拖拽组件搭建多页面内部应用
- 连接数据库、API、云存储和 SaaS
- 在应用中运行 JavaScript 与 Python
- 用内置数据库保存业务数据
- 通过 Docker 或 Kubernetes 自托管

核心亮点：从数据源拖出内部应用。先连接数据库、API 或 SaaS，再用响应式组件组成表格、表单与图表；团队可共同编辑多页面应用，并用代码补足自定义逻辑。

适合谁：需要为运营、客服或管理团队快速制作数据后台、审批页面和内部业务应用的开发团队。
使用前准备：托管使用需创建 ToolJet Cloud 账户；自托管需准备 Docker、Kubernetes 或相应云环境。

使用提醒：自然语言生成应用、AI 查询、AI 调试和 Agent Builder 属于 ToolJet AI 企业版，不在社区版能力内。

许可证：AGPL-3.0（Released under the GNU Affero General Public License v3.0.）

03｜needle
让小型设备在本地选择并调用工具，把自然语言请求转换成受约束的结构化结果。

它能做什么：

- 调用已声明的 Python 函数并回传结果
- 把自由文本抽取为 Pydantic 类型对象
- 用结构化语法约束工具名和参数输出
- 从大型工具目录筛出当前相关工具
- 通过 LoRA 微调并导出单个 .cact 模型

核心亮点：置信度门控的本地工具调用。它把工具描述编译为逐 token 约束的语法，以结构化数据返回调用；每次响应附带置信度，超过阈值自动执行，低于阈值转交处理。

适合谁：为手机、穿戴设备、智能家居或机器人开发离线工具调用和结构化抽取功能的开发者。
使用前准备：先安装 cactus-needle；首次会从 Hugging Face 获取推理引擎并缓存，隔离环境需按文档离线配置。

使用提醒：长对话依靠 256-token 滑动窗口维持内存；低于置信度阈值的结果需要交由上层流程处理。

许可证：MIT
