别只看 Star。这期把上榜项目翻成三件能直接判断的事：它做什么、能帮你完成什么、适不适合你。

01｜i-have-adhd
让编码助手先给下一步行动，再用编号步骤交付答案

它能做什么：

- 让回答先给出下一步行动
- 为多步任务生成编号步骤
- 压缩无关话题和旁支信息
- 在每轮回复中重述当前状态
- 用具体下一步结束回复

核心亮点：把编码助手的回复变成可执行清单。这个 skill 通过 10 条输出规则约束编码助手：先行动、再分步、少跑题，并在结尾给出具体下一步。

适合谁：经常被长篇 AI 回复打断，想快速推进编码任务的开发者
使用前准备：需要先在 CLI 中安装 i-have-adhd skill/plugin。

使用提醒：README 只说明它如何约束编码助手的输出，没有说明对具体模型或工具的兼容范围。

许可证：MIT

为什么本期上榜：过去 24 小时净增 +2,755 Star（历史快照核验）
GitHub 搜索：ayghri/i-have-adhd

02｜deepseek-harness
用插件化架构搭建可运行的 AI Agent，并在本地打开 Web UI

它能做什么：

- 通过 npm 启动本地 Web UI
- 从源码安装并构建项目
- 用插件扩展 Agent 能力
- 按照架构文档开发 Agent
- 在本地浏览器中运行 dsh

核心亮点：Everything is a Plugin。DeepSeek Harness 把能力拆成插件，并由 Cordis 提供组合式架构；开发者可通过 npm 或源码启动本地 Web UI。

适合谁：需要搭建、运行或扩展 AI Agent 的 TypeScript 开发者
使用前准备：需要安装 Node.js；从源码运行还需 pnpm install 和 pnpm run build。

使用提醒：项目处于 developer preview，README 明确提示会出现兼容性破坏性变更；运行前应查看 safety notice。

许可证：MIT

为什么本期上榜：过去 24 小时净增 +1,268 Star（历史快照核验）
GitHub 搜索：deepseek-ai/deepseek-harness

03｜diagram-design
把架构、流程和数据关系变成可直接打开的 HTML + SVG 图表

它能做什么：

- 生成架构图、流程图和数据模型图
- 把来源图重绘为 HTML、SVG 或 PNG
- 按网站提取品牌颜色和字体
- 为图表增加可访问名称和描述
- 按文档、幻灯片或社交尺寸调整输出

核心亮点：语义模式先选行为，再选图形。项目先判断队列、策略链或信任边界等语义模式，再选择合适图表类型；默认输出静态 HTML，也支持可选动效。

适合谁：需要为文档、演示或社交内容制作一致图表的产品与技术团队
使用前准备：需要安装并配置对应 Agent Skills 宿主；PNG 导出还需安装 Playwright 和 Chromium。

使用提醒：导入时不会保留源文件的坐标、配色或字体；Excalidraw 只读取场景文件，不支持 PNG 或 SVG 导出文件。

许可证：MIT

GitHub 搜索：cathrynlavery/diagram-design
