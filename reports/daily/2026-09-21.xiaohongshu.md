01｜ECC
ECC 给 AI 编程助手补上计划、测试、审查和记忆流程，让团队不必每次重新交代开发步骤。

它能做什么：

- 把功能需求整理成可确认的实施计划
- 先用失败测试复现缺陷再推进修复
- 用独立上下文审查代码改动
- 将会话经验提炼成可复用技能
- 扫描编程助手配置中的权限与注入风险

核心亮点：让 AI 编程留下验证依据。ECC 将计划、测试、实现、独立审查和验证串成流程，再把会话经验保存为记忆与技能。交付的不只是代码，还有失败测试、通过测试和审查记录，便于追溯改动依据。

适合谁：使用 AI 编程助手开发功能、修复缺陷，希望把测试、审查和跨会话交接纳入固定流程的软件团队。
使用前准备：通用安装包需 Node.js 18 或更新版本；Claude 插件安装还需 Git 和 Claude Code 2.1 或更新版本。

使用提醒：各编程助手功能不对等；自动执行脚本须明确授权，记忆内容仍需核验。同一助手勿叠加安装方式。私有仓库托管分析属于付费 Pro；原生 Windows 记忆写入存在已知缺陷。

许可证：MIT

02｜cua
把桌面交给 AI 操作：cua 提供应用控制、隔离电脑环境和评估工具，供开发者搭建电脑操作智能体。

它能做什么：

- 操控桌面应用和浏览器中的界面元素
- 从云端桌面池领取隔离的运行环境
- 在 Apple Silicon 上创建本地虚拟机
- 评估智能体完成电脑操作任务的表现
- 导出电脑操作轨迹用于训练

核心亮点：从桌面操作到任务评估。Driver 负责操作应用，Fleets 提供隔离云桌面，Lume 管理本地虚拟机，Bench 构建任务并评估结果。你自带智能体和模型，用这些组件连接操作环境与训练评估流程。

适合谁：需要让 AI 操作桌面软件的自动化开发者，以及构建电脑操作任务、评估智能体并收集训练轨迹的研究人员。
使用前准备：需自备智能体和模型；Lume 需 Apple Silicon；Bench 入门需 Python 3.12 或 3.13 及 uv。

使用提醒：后台操作不抢焦点取决于应用和平台支持；云桌面领取结束后，池中付费容量可能仍保留，需清理。专用决策模型不替代通用规划，模型与数据许可须另查。

许可证：MIT（Optional `cua-agent[omni]` includes ultralytics (AGPL-3.0)）

03｜claude-code
在终端描述开发需求，claude-code 结合代码库执行日常任务、解释复杂代码并处理 Git 流程。

它能做什么：

- 解释代码库中的复杂代码
- 按自然语言指令执行日常开发任务
- 处理项目中的 Git 工作流
- 通过插件扩展自定义命令与智能体

核心亮点：在项目里用自然语言推进开发。在项目中启动 Claude Code 后，可用自然语言提出开发任务，由它结合代码库执行操作、解释代码或处理 Git 流程。仓库还提供插件，用自定义命令和智能体扩展功能。

适合谁：希望在终端或编辑器里用自然语言理解现有代码、执行日常开发任务和处理 Git 流程的程序员。
使用前准备：先安装 Claude Code，再进入项目目录运行 claude；README 提供 macOS、Linux 和 Windows 安装方式。

使用提醒：npm 安装方式已弃用。使用时会收集代码采纳或拒绝等使用数据、相关对话及问题反馈；具体数据处理规则需查阅其政策。
