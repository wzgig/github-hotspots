AI 项目的名字往往很抽象。这一期不堆术语，只讲清它替谁做什么、能完成哪些任务，以及是否值得加入你的工具箱。

先看结论：
- agent-skills：把资深工程师的软件开发流程装进编程 Agent，让需求、实现、测试、评审和发布按检查点推进
- superpowers：让编程 Agent 先澄清需求和确认设计，再按计划分派子 Agent 编码、测试与评审
- hermes-agent：在终端或聊天平台运行能记住历史、自建技能并持续执行定时任务的 AI Agent

01｜agent-skills
把资深工程师的软件开发流程装进编程 Agent，让需求、实现、测试、评审和发布按检查点推进

它能做什么：

- 编写规格并先确认要构建什么
- 拆解带验收条件的原子任务
- 按测试驱动方式逐步实现代码
- 审查代码质量、安全与性能
- 通过清单完成发布前检查

核心亮点：把工程纪律变成 Agent 工作流。以 24 项技能承载研发方法，再用 8 个斜杠命令覆盖定义、计划、构建、验证、评审和发布；每项技能都带步骤、检查点、退出条件与证据要求。

适合谁：希望编程 Agent 遵循明确研发流程，并在合并或发布前留下验证证据的开发团队
使用前准备：需在所用编程 Agent 中安装对应集成；Codex 插件要求 Codex CLI v0.122+。

使用提醒：单独安装某项技能时不会复制仓库级 references 目录，补充检查清单路径可能不可用；自动构建遇到失败或高风险步骤会暂停。

许可证：MIT

02｜superpowers
让编程 Agent 先澄清需求和确认设计，再按计划分派子 Agent 编码、测试与评审

它能做什么：

- 提问澄清需求并形成设计文档
- 建立隔离工作区并检查测试基线
- 拆分带路径和验证步骤的实施计划
- 派发子 Agent 逐项实现并复核
- 验证测试后选择合并或保留分支

核心亮点：先设计，再让子 Agent 分工实现。工作流从需求访谈和设计确认开始，随后生成细粒度计划；执行阶段为每项任务派发新的子 Agent，并依次检查规格符合度和代码质量。

适合谁：需要让编程 Agent 长时间推进功能开发，同时保留设计确认和人工检查点的开发者
使用前准备：需按所用编码工具分别安装；同时使用多个工具时，每个工具都要单独安装。

使用提醒：可选视觉伴侣默认从网站加载标志并携带 Superpowers 版本信息；可通过环境变量关闭遥测。

许可证：MIT

为什么本期上榜：过去 24 小时净增 +604 Star（历史快照核验）
GitHub 搜索：obra/superpowers

03｜hermes-agent
在终端或聊天平台运行能记住历史、自建技能并持续执行定时任务的 AI Agent

它能做什么：

- 切换模型提供商而无需修改代码
- 安排定时任务并投递到聊天平台
- 并行派发隔离的子 Agent 工作流
- 在本地、容器、SSH 或云端运行
- 迁移 OpenClaw 的设置、记忆与技能

核心亮点：能从经验沉淀技能的学习闭环。它会从复杂任务中生成技能，在后续使用中继续改进，并通过持久记忆、历史会话搜索和用户模型把不同会话里的经验重新用于当前任务。

适合谁：需要把个人 AI 助手放在云端持续运行，并从终端或聊天软件远程交办任务的用户
使用前准备：安装脚本会准备 uv、Python 3.11、Node.js、ripgrep、ffmpeg 和 Git Bash。

使用提醒：Termux 的完整依赖会拉取不兼容 Android 的语音组件，需使用专用 termux 扩展；手动开发时虚拟环境应放在源码树外。

许可证：MIT
