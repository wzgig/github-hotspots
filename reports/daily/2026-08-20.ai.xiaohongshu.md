01｜MoneyPrinterTurbo
输入主题或关键词，它会串起脚本、素材、配音、字幕和音乐，交付高清短视频

它能做什么：

- 输入主题或关键词生成视频脚本
- 匹配本地或在线高清素材
- 合成语音、字幕与背景音乐
- 批量生成多个视频供人工挑选
- 上传成片到多个短视频平台

核心亮点：把主题变成完整短视频。工作流先生成或接收脚本，再匹配画面素材，加入语音、字幕和背景音乐，最后合成横屏或竖屏成片；既能在界面操作，也能接入 API 和命令行。

适合谁：需要批量制作短视频、调整字幕配音，或把成片发布到多个短视频平台的内容创作者与开发者
使用前准备：本地部署需要 Python 3.11 或更高版本；Windows 项目路径应避免中文、特殊字符和空格。

使用提醒：批量生成后仍需人工挑选成片；部分云端服务和自动发布需要对应 API Key，首次使用 Whisper 还需下载模型。

许可证：MIT

02｜OpenViking
把智能体的记忆、资料和技能收进可浏览的虚拟文件系统，让检索过程可分层、可追踪

它能做什么：

- 统一存放智能体记忆、资源和技能
- 按 L0、L1、L2 分层加载上下文
- 沿目录逐层检索并保留周边上下文
- 记录每次检索经过的目录路径
- 提交会话后提取偏好与经验

核心亮点：像浏览文件一样管理上下文。记忆、资源和技能都映射到 viking:// 路径，写入时生成摘要、概览和详情三层内容；智能体先定位目录，再按需深入读取，并留下完整检索轨迹。

适合谁：需要为编码助手、聊天智能体或多智能体系统管理长期记忆、知识资料和技能上下文的开发者
使用前准备：需要 Python 3.10 或更高版本，并通过初始化向导配置模型提供方和连接信息。

使用提醒：桌面助手仍处于 Beta，仅覆盖 macOS 和 Windows x64；开源版需自行部署和运维。

许可证：AGPL-3.0

为什么本期上榜：过去 24 小时净增 +1,194 Star（历史快照核验）
GitHub 搜索：volcengine/OpenViking

03｜hermes-agent
让 AI 助手从任务经验中生成和改进技能，并跨终端与聊天平台持续执行自动化工作

它能做什么：

- 从任务经验中创建并改进技能
- 搜索历史会话并汇总长期记忆
- 设置定时任务并投递执行结果
- 派生隔离子智能体并行处理任务
- 切换模型提供方而无需修改代码

核心亮点：让智能体从使用中持续学习。它把任务经验整理成技能，在后续使用中继续改进；同时搜索历史会话、维护用户模型，并通过定时任务与子智能体把长期工作拆开执行。

适合谁：需要让个人 AI 助手长期记忆偏好、定时执行任务，或在终端与聊天软件间连续工作的用户和开发者
使用前准备：需准备可用的模型提供方或自有端点；安装脚本会处理 Python 3.11、Node.js、ripgrep 和 ffmpeg 等依赖。

使用提醒：不同模型与外部工具通常需要对应服务凭据；Termux 的完整依赖含不兼容语音组件，需使用专用安装项。

许可证：MIT
