01｜OpenShell
为自主 AI Agent 提供受策略约束的隔离运行环境，限制它能访问的文件、网络和凭据

它能做什么：

- 按策略限制 Agent 的文件访问范围
- 隔离运行 Agent 并限制系统调用
- 拦截并审核 Agent 的网络连接
- 在策略变更前检查新增访问权限
- 通过网关和 SDK 接入沙箱能力

核心亮点：给自主 Agent 划定可验证的活动边界。它把 Agent 放进隔离沙箱，由内核级控制检查文件、系统调用和网络请求；策略变更还要经过形式化验证并等待人工确认。

适合谁：需要为自主 AI Agent 设定文件、网络和凭据边界的开发者与平台团队
使用前准备：需要 Linux、Apple Silicon Mac，或实验性的 Windows WSL 2，并准备 Docker、Podman 或主机虚拟化。

使用提醒：策略放行新增主机、凭据或 API 权限前会等待人工确认；软件还会收集可关闭的匿名运行遥测。

许可证：Apache-2.0

GitHub 搜索：NVIDIA/OpenShell

02｜openrig
把 Claude Code、Codex 等编程 Agent 组织成可持续运行、分工协作的本地团队

它能做什么：

- 用 YAML 定义 Agent 团队拓扑
- 启动并查看多个 Agent 会话
- 让 Agent 通过消息和队列协作
- 发现并接管已有 tmux 会话
- 保存团队状态并在重启后恢复

核心亮点：把终端里的 Agent 变成持久团队。OpenRig 由本地守护进程、CLI、终端界面和 MCP 服务组成，以 tmux 管理各个 Agent 座位；团队拓扑、角色和上下文可以持续保存与恢复。

适合谁：需要让 Claude Code、Codex 等编程 Agent 组成长期协作团队的开发者和技术负责人
使用前准备：需要 Node.js 22 或 24、tmux，以及 macOS 或 Linux；还要准备并登录所选的 Claude Code 或 Codex。

使用提醒：会写入 tmux、Provider 信任设置、Hook 和工作区文件；原生 Windows 尚不支持，WSL2 也未测试。使用前需备份相关文件。

许可证：Apache-2.0

为什么本期上榜：过去 24 小时净增 +701 Star（历史快照核验）
GitHub 搜索：mvschwarz/openrig

03｜hyperframes
把 HTML、CSS、媒体和动画组合成可重复渲染的 MP4 视频，适合人工或 Agent 编排

它能做什么：

- 用 HTML 和 CSS 编排视频画面
- 为元素设置时间轴和动画轨道
- 预览并检查视频组合内容
- 将组合渲染为 MP4 视频
- 接入媒体、字幕、图表和转场组件

核心亮点：用 HTML 写视频，再逐帧渲染成 MP4。HyperFrames 把 HTML 组合交给无头 Chrome逐帧定位，再用 FFmpeg 编码和混音；同一份输入可在本地、Docker 或 AWS Lambda 中重复渲染。

适合谁：需要把网页、数据、动画和媒体素材编排成可重复渲染视频的前端开发者与内容团队
使用前准备：需要 Node.js 22+ 和 FFmpeg；可通过 CLI 本地预览、检查并渲染视频。

使用提醒：需要 Node.js 22+ 和 FFmpeg；完整仓库开发还需要 Git LFS。不同动画运行时需遵守可定位到具体帧的编排方式。

许可证：Apache-2.0
