01｜archify
把代码库或系统描述变成交互式、可验证的架构图与流程图

它能做什么：

- 输入代码库或系统描述，生成系统地图
- 选择架构、工作流、时序、数据流或生命周期图
- 对比验证前后的架构快照
- 搜索节点并追踪上下游关系与路径
- 导出自包含 HTML、PNG、SVG 和 WebM

核心亮点：让架构图先验证，再交付。Agent 先生成带类型的 JSON 中间表示，Archify 再执行结构、布局、路径和标签检查，通过后渲染成可分享文件。

适合谁：需要梳理系统、评审架构变更或制作技术演示的软件团队
使用前准备：需要支持 Agent Skills 的 AI agent；本地命令行流程还需要 Node.js。

使用提醒：不是通用绘图编辑器或 Mermaid 主题；架构变更对比不会推断影响、风险或合并安全。

许可证：MIT（free to use, modify, and distribute.）

为什么本期上榜：过去 24 小时净增 +2,370 Star（历史快照核验）
GitHub 搜索：tt-a1i/archify

02｜scientific-agent-skills
给 AI agent 装上一套覆盖科研数据、分析工具与写作流程的技能库

它能做什么：

- 检索科学数据库和全文研究资料
- 执行基因组、单细胞和多组学分析
- 开展分子性质预测、虚拟筛选和药物发现任务
- 生成统计分析和出版级科研图表
- 撰写带证据追踪的综述、报告和演示材料

核心亮点：把科研工具装进 AI agent。技能以 SKILL.md、代码示例和参考资料封装数据库、Python 包与研究流程，让 agent 能按领域调用并保留验证和来源边界。

适合谁：需要让 AI agent 协助文献、数据分析或实验规划的科研人员与研发团队
使用前准备：需要 Python 3.13+、uv，以及支持 Agent Skills 标准的 AI agent；Windows 需 WSL2。

使用提醒：技能可能执行代码、安装包、联网或修改文件；不能替代诊断、治疗、认证或方法放行决定。

许可证：MIT（These licenses may differ from the repository's MIT License.）

为什么本期上榜：过去 24 小时净增 +890 Star（历史快照核验）

03｜gods-eye-view
在浏览器里把公开实时信号放进一颗可探索的三维地球

它能做什么：

- 在三维地球上查看公开实时数据
- 锁定目标并查看轨迹与详细元数据
- 把公共摄像头投影进三维城市并查看覆盖范围
- 用语音切换图层、移动镜头和绘制标注
- 录制镜头导览并分享当前视图

核心亮点：把公开信号变成可探索的地球。浏览器客户端把航班、船舶、卫星、地震、摄像头等公开源叠加到三维地球，并标注实时、延迟、模拟或不可用状态。

适合谁：适合做地理情报探索、数据可视化演示和公开信号研究的用户
使用前准备：需要 Node.js 24.14.x 或 26.x，并配置 Google Maps API key；语音功能另需 OpenAI key。

使用提醒：数据可能延迟、不完整、模拟、推断或错误；不得用于导航、应急、医疗、投资等安全关键用途。

许可证：MIT License（Bundled and live datasets carry their own terms）
