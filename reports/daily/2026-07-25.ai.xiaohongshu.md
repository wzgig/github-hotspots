01｜worldmonitor
把全球新闻、地缘风险与基础设施信号汇入同一仪表盘，供读者研判局势与追踪变化。

它能做什么：

- 聚合新闻源并生成 AI 简报
- 切换三维地球仪与平面地图
- 叠加多类地缘与基础设施图层
- 计算重点国家的局势压力评分
- 通过 MCP、REST、CLI 或 SDK 调用数据

核心亮点：跨信号的全球态势看板。它把新闻、地图图层、市场与风险评分放进同一界面，并关联军事、经济、灾害等信号，便于从多个维度核对局势。

适合谁：需要持续跟踪地缘、金融、灾害或基础设施动态的研究者、分析人员与自建情报看板团队
使用前准备：本地开发需安装项目依赖；基础运行不要求环境变量，特定功能的数据源可能需要凭据。

使用提醒：MCP 的 tools/call 需要 X-WorldMonitor-Key 或 OAuth；部分功能的数据源需要凭据。

许可证：AGPL-3.0-only（Separate commercial or trademark permission needed）

02｜OmniRoute
把多个模型供应商收进一个兼容接口，按配额、成本、延迟或故障自动选择与切换模型。

它能做什么：

- 连接不同供应商与本地模型
- 用 auto 模式实时选择可用模型
- 为组合配置优先级、轮询等路由策略
- 压缩提示词与工具输出以控制上下文
- 通过 MCP、A2A、REST 或远程 CLI 管理网关

核心亮点：配额感知的模型组合路由。它把多个模型串成可自动切换的组合，根据健康状态、配额、成本和延迟选择目标；某个供应商失败或额度不足时，继续尝试后续模型。

适合谁：需要为编码工具统一接入多家模型、管理配额并降低切换成本的个人开发者与 AI 平台团队
使用前准备：全局安装需要 Node ≥22.22.2；也可使用 Docker、桌面应用或从源码运行。

使用提醒：远程模式中，启动进程的路由仅限本机回环；记忆功能默认关闭，需要主动启用。

许可证：MIT

03｜ego-lite
让 AI 代理在共享浏览器的独立空间里操作真实登录页面，同时不占用你的标签页。

它能做什么：

- 读取页面快照并定位可操作内容
- 填写、点击、等待与跳转网页
- 并行运行多个代理浏览任务
- 复用现有登录状态处理需认证页面
- 让外部代理通过 ego-browser 驱动浏览器

核心亮点：人和代理共享浏览器但互不抢页。每个代理在独立 Space 中读取页面快照并执行 JavaScript 工具，可继承现有登录状态；你继续使用自己的标签页，也能随时接管或停止代理空间。

适合谁：需要让 Codex、Claude Code 等外部代理处理登录后网页、并行采集或批量操作的 macOS 用户
使用前准备：当前需在 macOS 安装 ego lite 应用与 ego-browser skill；首次任务会引导完成安装。

使用提醒：Windows 和 Linux 尚在路线图中；经验积累与复用能力仍标为即将推出。

许可证：MIT
