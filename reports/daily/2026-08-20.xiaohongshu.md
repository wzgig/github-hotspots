# 正文

2026-08-20 · D040 · 综合主榜

别只看 Star。这期把上榜项目翻成三件能直接判断的事：它做什么、能帮你完成什么、适不适合你。

先看结论：
- MoneyPrinterTurbo：输入视频主题或关键词，自动完成脚本、素材、配音、字幕与音乐，输出高清短视频
- public-apis：按领域汇总公共 API，并标出认证、HTTPS 与 CORS 信息，方便为产品快速找接口
- OpenViking：把智能体的记忆、资料和技能收进可浏览的虚拟文件系统，按任务深度取用上下文

01｜MoneyPrinterTurbo
输入视频主题或关键词，自动完成脚本、素材、配音、字幕与音乐，输出高清短视频

它能做什么：

- 输入主题或关键词生成视频脚本
- 匹配本地或在线高清素材
- 合成配音、字幕和背景音乐
- 批量生成多个成片供选择
- 自动上传至 TikTok、Instagram 和 YouTube Shorts

核心亮点：把短视频制作串成自动流程。项目把脚本生成、素材检索、语音合成、字幕与音乐配置接成工作流，可从同一主题批量产出成片，再挑选结果或继续发布。

适合谁：需要批量制作短视频，并希望通过网页、接口或命令行衔接内容流程的创作者与开发者
使用前准备：本地部署需要 Python 3.11 或更高版本；部分模型、语音、素材及发布服务需要对应凭据。

使用提醒：部分模型、语音和跨平台发布依赖第三方凭据；Whisper 首次使用需下载模型。

许可证：MIT

02｜public-apis
按领域汇总公共 API，并标出认证、HTTPS 与 CORS 信息，方便为产品快速找接口

它能做什么：

- 按业务领域浏览公共 API
- 查看接口用途说明
- 筛选是否需要 API Key 或 OAuth
- 核对 HTTPS 支持情况
- 核对 CORS 支持情况

核心亮点：按领域查接口条件。它把公共 API 按领域编成索引，每条同时列出用途、认证方式、HTTPS 与 CORS，方便先缩小候选，再进入对应文档判断是否接入。

适合谁：为自己的产品寻找公共接口，并需要比较认证、HTTPS 与 CORS 条件的开发者

使用提醒：清单由社区成员人工维护。

许可证：MIT

为什么本期上榜：过去 24 小时净增 +1,880 Star（历史快照核验）
GitHub 搜索：public-apis/public-apis

03｜OpenViking
把智能体的记忆、资料和技能收进可浏览的虚拟文件系统，按任务深度取用上下文

它能做什么：

- 统一存放记忆、资料与技能
- 用 ls、tree 和 find 浏览上下文
- 按 L0、L1、L2 分层加载内容
- 追踪每次检索经过的目录路径
- 将会话偏好与经验沉淀为长期记忆

核心亮点：像文件系统一样管理上下文。记忆、资料和技能都获得 viking:// 地址，并在写入时生成分层内容；智能体先定位目录，再按需深入读取，同时留下可检查的检索路径。

适合谁：需要为编码助手或多轮智能体管理长期记忆、知识资料、技能，并排查检索过程的开发者
使用前准备：本地安装需要 Python 3.10 或更高版本，并在初始化时配置模型或服务提供方。

使用提醒：仅开源 VikingMem 论文所述核心能力的一个子集；OpenViking Helper 仍处于 Beta。

许可证：AGPL-3.0（The OpenViking project uses different licenses for different components:）
