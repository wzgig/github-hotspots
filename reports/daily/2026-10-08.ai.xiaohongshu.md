AI 项目的名字往往很抽象。这一期不堆术语，只讲清它替谁做什么、能完成哪些任务，以及是否值得加入你的工具箱。

先看结论：

01｜rea
没有源码，也能让智能体借助 rea 追查应用功能的实现方式，并带回可核对的证据。

它能做什么：

- 反编译原生程序中的函数为伪代码
- 梳理未运行的 JavaScript 应用模块关系
- 追踪字符串或符号对应的实现代码
- 采集指定浏览器场景中的交互证据
- 比较两次进程捕获中的行为差异

核心亮点：从功能线索追到实现证据。先从字符串、调用关系和伪代码追踪功能，再把证据与未解问题交给智能体；智能体用自身编辑和测试工具实现新版本，而不是直接复制整款应用。

适合谁：需要在缺少源码时理解应用功能、编写兼容实现或追查异常行为的开发者与逆向分析人员。
使用前准备：静态 JavaScript 分析需 Node.js 与 npm；深入分析原生程序需配置 Hopper、Ghidra 或 IDA Pro，平台要求随流程而异。

使用提醒：不保证恢复原始源码或自动克隆应用；配置变更须确认，Hopper 单独许可。进程捕获以用户权限运行，并非安全沙箱；模型服务的数据政策需另行核对。

许可证：MIT

02｜agency-agents
把开发、设计和营销任务分给不同 AI 角色，agency-agents 提供可安装、可修改的工作说明。

它能做什么：

- 挑选前端角色辅助实现网页组件
- 调用评审角色检查代码质量
- 借助内容角色规划多平台营销文案
- 按团队或单个角色选择安装范围
- 转换角色文件以适配不同编程助手

核心亮点：把角色分工写成可复用工作说明。每份角色文件都包含身份、任务流程、交付示例与评价标准。按任务选择工程、设计或营销角色，再安装到所用助手中，也能修改角色内容适配自己的项目。

适合谁：适合希望为产品原型、代码评审或内容营销任务配置专门 AI 角色的开发者与运营人员。
使用前准备：集成使用需已有对应助手；脚本安装到部分工具前须先生成转换文件，也可直接复制角色内容作为参考。

使用提醒：README 提醒 OpenCode 仅注册约 119 个角色，超出部分会被静默丢弃，宜按团队安装；Aider 默认加载角色索引，完整说明需另行读取。

许可证：MIT

03｜claude-mem
让编程助手在新会话里接上旧进度：claude-mem 自动整理操作记录，再找回相关项目记忆。

它能做什么：

- 记录会话中的工具使用情况
- 生成历史记录的语义摘要
- 向新会话注入相关项目上下文
- 按类型、日期或项目检索记忆
- 查看某条记录前后的时间线

核心亮点：先找记忆索引，再按需读详情。会话记录和摘要存入 SQLite，结合语义与关键词检索。查询先返回简短索引，再看时间线，只为选中的记录读取全文，避免把全部历史塞进新会话。

适合谁：适合反复开启编程会话、需要找回项目决策与修复记录，并控制历史上下文加载范围的 AI 编程助手使用者。
使用前准备：需 Node.js 20.0.0 或更高版本；Claude Code 集成需支持插件的最新版。Bun 与 uv 缺失时自动安装。

使用提醒：全局 npm 安装仅提供库，不会配置插件与后台服务；云端观察服务试用结束后，未订阅会回退到 Anthropic 套餐，也可显式选择其他提供方跳过登录。

许可证：Apache-2.0
