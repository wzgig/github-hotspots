01｜rea
没有源码也想弄懂应用功能？REA 帮开发者追踪实现，并把证据交给智能体解释。

它能做什么：

- 提取原生二进制的伪代码与调用关系
- 梳理 Electron 应用的模块与进程通信
- 检查网站页面结构与网络请求
- 读取 Android APK 的声明与反编译方法
- 记录进程运行时的终端与文件系统变化

核心亮点：让功能解释带上代码证据。通过 MCP 这一智能体调用工具的接口，REA 在本地检查目标，返回代码、引用关系和未知项。智能体再据此追问、解释行为，或编写并测试相似实现。

适合谁：需要分析自有或获授权软件、追踪功能实现，或研究软件互操作与保存的开发者。
使用前准备：可用 Node.js 24.x（>=24.11）与 npm；深度原生分析另需 Hopper、Ghidra 或 IDA。

使用提醒：安装变更需审核批准；运行时采集会以用户权限运行或操作目标。分析虽在本地，结果仍会交给智能体，其模型服务商有独立数据政策。

许可证：MIT（REA grants no tool license, key, or activation entitlement.）

02｜diagram-design
把文字描述或已有图表变成贴合品牌风格的 HTML 图稿，供博客和演示文稿使用。

它能做什么：

- 根据文字描述绘制架构图与流程图
- 提取网站配色和字体用于图表
- 重绘 Mermaid、draw.io 与 Excalidraw 图
- 按展示场景调整图表尺寸与细节
- 导出用于幻灯片的 PNG 或 SVG

核心亮点：把图表做成品牌风格的单文件。智能体先选图型并说明布局计划，再生成内嵌 SVG 的单个 HTML 文件。配色与字体可从网站提取；重绘旧图时会列出合并、折叠和删去的内容，方便核对。

适合谁：为博客、演示文稿或客户项目制作架构图、流程图，希望图表沿用品牌配色与字体的作者和设计者。
使用前准备：需使用支持 Agent Skills 的智能体宿主；导出 PNG 另需安装 Playwright 与 Chromium。

使用提醒：首次使用需确认品牌风格；效果依赖模型，同一提示可能生成不同布局。结果没有可拖拽画布，不适合频繁版本对比；默认字体需联网，可改系统字体。

许可证：MIT

03｜gods-eye-view
想在地图上探索航班、卫星和天气？这个浏览器地球把公开数据叠在一起，还能用语音查询。

它能做什么：

- 追踪飞机、船舶与卫星的位置和轨迹
- 投影公共摄像头画面到地理场景
- 回放雷达、云图与闪电观测
- 用语音查询当前图层中的目标
- 绘制沿真实道路延伸的出行路线

核心亮点：在同一地球上串联公开信号。把航班、船舶、卫星、地震和公共摄像头放进同一个可探索地球。点击目标即可查看轨迹与资料，语音查询会读取当前场景；每个图层独立，便于接入自己的数据。

适合谁：想探索公开航班、卫星与天气数据的学习者，以及需要制作地理场景演示、扩展数据图层的开发者。
使用前准备：可用 Pinokio 8.2 或更高版本安装；终端方式需 Node.js 24.x（24.14.0 起）或 26.x；基础启动无需密钥。

使用提醒：数据可能延迟或有误，车流位置是模拟，勿用于导航或应急决策。写实地图与语音受服务条款、配额及计费约束；共享服务会让可访问者使用已配置的接口额度，不支持个人追踪。

许可证：MIT License（Bundled and live datasets carry their own terms）
