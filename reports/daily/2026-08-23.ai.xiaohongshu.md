01｜MoneyPrinterTurbo
输入主题或关键词，自动串起脚本、素材、配音、字幕和音乐，输出高清短视频

它能做什么：

- 生成多语言视频脚本或使用自定义脚本
- 匹配本地或在线高清素材
- 调用文生视频模型生成新画面
- 合成配音、字幕与背景音乐
- 批量出片并上传多个短视频平台

核心亮点：从主题到成片的自动化链路。它把脚本生成、素材检索或生成、语音合成、字幕和音乐串成同一流程，并提供 WebUI、API、CLI 与 Agent 入口，方便反复制作短视频。

适合谁：需要批量制作竖屏或横屏短视频，并希望减少脚本、找素材和后期操作的内容创作者
使用前准备：本地部署需要 Python 3.11 或更高版本；Windows 项目路径应避开中文、特殊字符和空格

使用提醒：云端模型、语音和跨平台发布通常需要对应 API Key；Whisper 首次使用还需下载模型

许可证：MIT

02｜hermes-agent
把长期使用中的经验沉淀为记忆和技能，让 AI Agent 跨会话继续执行与改进任务

它能做什么：

- 创建并持续改进可复用技能
- 搜索历史会话并总结相关上下文
- 安排定时任务并把结果送到消息平台
- 派生隔离子 Agent 并行处理工作流
- 切换模型与终端后端而无需改代码

核心亮点：会从使用经验中生长的 Agent。它把会话记忆、用户模型和技能创建组成学习闭环：复杂任务完成后沉淀技能，后续使用时继续改进，并能从历史会话找回相关信息。

适合谁：需要长期运行个人 Agent，并希望它记住历史、自动执行计划任务或从消息平台远程操作的用户
使用前准备：需在 Linux、macOS、WSL2、Termux 或原生 Windows 环境安装，并按所选模型与工具服务完成配置

使用提醒：Termux 的完整可选依赖包含不兼容的语音组件；若不使用 Nous Portal，部分模型和工具需分别准备密钥

许可证：MIT

03｜superpowers
在编程 Agent 写代码前先澄清需求，再按计划、测试、审查和收尾流程推进开发

它能做什么：

- 澄清需求并分段确认设计
- 创建隔离工作区并验证测试基线
- 拆分可执行任务并写明验证步骤
- 派发子 Agent 实现并分阶段审查
- 完成测试后提供合并或保留选项

核心亮点：让编程 Agent 先设计再动手。它用一组自动触发的技能约束开发顺序：先澄清和确认设计，再拆计划、隔离实现、测试驱动、逐项审查，最后验证并处理开发分支。

适合谁：希望编程 Agent 少凭猜测直接写代码，改为按设计、计划、测试和审查流程完成研发任务的开发者
使用前准备：需要在所用编程 Agent 中安装对应插件或扩展；使用多个运行环境时，要分别安装

使用提醒：可选视觉伴侣默认会从网站加载标志并携带版本信息；可通过环境变量关闭遥测

许可证：MIT
