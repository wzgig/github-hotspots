01｜OpenMAIC
把主题或资料变成可互动课堂，并让 AI 教师与同学陪你学习

它能做什么：

- 根据主题或资料生成课程大纲
- 把大纲转成幻灯片、测验和互动场景
- 导入文档、音频和视频作为课程素材
- 让 AI 角色讲解、讨论并绘制白板
- 导出可编辑 PPTX 或互动 HTML 页面

核心亮点：把资料变成可互动课堂。输入主题或学习资料后，系统先生成课程结构，再组合幻灯片、测验、模拟和项目活动，交由多名 AI 角色带领学习。

适合谁：想把学习资料变成互动课程的教师、培训者和自学者
使用前准备：需要 Node.js >= 20、pnpm >= 10，并配置至少一个 LLM 提供商密钥。

使用提醒：服务端持久化的公开 token 不提供保密或用户隔离，只适合 localhost 或可信网络的单用户部署。

许可证：MIT（commercial use is permitted free of charge.）

为什么本期上榜：过去 24 小时净增 +1,930 Star（历史快照核验）
GitHub 搜索：THU-MAIC/OpenMAIC

02｜archify
把系统描述或代码库变成可验证、可交互的架构图

它能做什么：

- 把系统描述转成架构、流程或时序图
- 分析代码库并标注来源证据
- 校验节点、布局、路径和标签
- 对比变更前后并列出新增与移除事实
- 导出自包含 HTML、PNG、SVG 和 WebM

核心亮点：让架构图可验证、可追溯。代理先生成 typed JSON IR，再检查结构、布局和路径，最后输出自包含 HTML；交互只沿作者写入的节点与关系展开。

适合谁：需要讲清系统结构、评审架构变更或制作技术分享图的团队
使用前准备：需要 Node.js；可通过 npx skills add 安装，也可直接使用零依赖 CLI。

使用提醒：不是通用绘图编辑器，也不支持自动 Mermaid 解析、托管分享或所见即所得编辑。

许可证：MIT（free to use, modify, and distribute.）

为什么本期上榜：过去 24 小时净增 +2,614 Star（历史快照核验）
GitHub 搜索：tt-a1i/archify

03｜deepseek-harness
把 AI Agent 的能力拆成可插拔模块，便于本地运行和继续扩展

它能做什么：

- 通过插件方式扩展 Agent 能力
- 用 npx 启动本地 Web UI
- 从源码安装依赖并构建项目
- 按开发指南维护插件相关代码

核心亮点：插件化的 Agent Harness。DeepSeek Harness 以插件为基本扩展单元，基于 Cordis 组织运行能力；开发者可启动本地 Web UI，再按文档继续扩展。

适合谁：想开发可扩展 Agent、插件或本地 AI 工作台的工程师
使用前准备：需要 Node.js；从源码运行还需 pnpm，并先执行 pnpm install 与 pnpm run build。

使用提醒：当前处于 developer preview，可能出现兼容性破坏变更；运行前应先阅读 safety notice。

许可证：MIT

为什么本期上榜：过去 24 小时净增 +1,075 Star（历史快照核验）
GitHub 搜索：deepseek-ai/deepseek-harness
