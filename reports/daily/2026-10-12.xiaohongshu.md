01｜AnyPS5
把 PS5 可执行文件移植到 Linux 和 Windows，为游戏兼容性研究提供不依赖模拟的路径。

它能做什么：

- 转换可执行文件为目标系统的原生格式
- 提供可供动态链接的系统库实现
- 将着色器重新编译为 SPIR-V
- 接入手柄的摇杆与扳机输入
- 通过配置文件设置键盘和鼠标控制

核心亮点：转换程序格式，而不是模拟运行。重链接器负责把可执行文件转换为目标系统的原生格式，配套系统库提供动态链接所需的实现。这条移植路径不使用模拟，也不另起运行时进程。

适合谁：研究游戏兼容性、软件保存或可执行文件移植，需要探索 PS5 程序在电脑上运行方式的人。

使用提醒：遇到不支持或意外状态会报错并终止；系统库进度仅统计项目已知函数，不代表全部功能。使用者须确保二进制文件的获取和使用合规。

许可证：GPL-2.0

02｜rea
没有应用源码，也能让智能体借助 rea 追踪功能实现，并拿到可核对的分析证据。

它能做什么：

- 提取原生二进制的伪代码与调用关系
- 梳理 Electron 应用的模块和进程通信
- 检查网页结构、脚本与网络活动
- 读取 Android APK 的声明与反编译方法
- 记录进程交互和文件系统变化

核心亮点：让逆向分析结论带上证据。通过 MCP 这个供智能体调用工具的接口，REA 在本地检查目标并返回代码、引用和未知项。智能体据此继续追踪、解释功能，再编写和测试类似实现。

适合谁：需要在没有源码时追踪应用功能、分析程序行为，并依据证据重建类似实现的软件研究者与开发者。
使用前准备：需 npm 与 Node.js 22.x（>=22.19）、24.x（>=24.11）或 26+；原生分析另需 Hopper、Ghidra 或 IDA。

使用提醒：安装变更需审核批准；运行时采集会以用户权限运行或交互目标。分析在本地进行，但工具结果交给智能体后受模型提供方的数据政策约束；逆向研究需取得必要授权。

许可证：MIT

03｜ECC
给编程智能体装上规划、测试、审查和记忆流程，不必每次重新交代工程步骤。

它能做什么：

- 将功能需求整理成可编辑的实施计划
- 用先失败后通过的测试驱动代码实现
- 交由独立上下文中的智能体审查改动
- 把会话经验提炼成可复用技能
- 用 AgentShield 扫描智能体配置风险

核心亮点：把编程提示变成可复用工程流程。技能提供可复用流程，专职智能体分担规划和审查，事件触发脚本执行检查，记忆保存会话要点。让计划、测试、实现和复核形成可追踪的工作过程。

适合谁：使用编程智能体开发功能、修复缺陷，希望固定测试与审查步骤，并在长会话后继续工作的开发者。
使用前准备：通用包需 Node.js 18 或更新版；Claude 插件另需 Git 和 Claude Code 2.1 或更新版。扫描需预装并审核 AgentShield

使用提醒：各平台能力不齐，Windows 原生记忆写入仍有缺陷；同一工具不要叠加安装。启用自动脚本需明确确认，记忆不等于可信指令；私有仓库托管分析属于付费 Pro。

许可证：MIT
