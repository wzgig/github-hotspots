AI 项目的名字往往很抽象。这一期不堆术语，只讲清它替谁做什么、能完成哪些任务，以及是否值得加入你的工具箱。

先看结论：

01｜hindsight
给聊天和任务型 Agent 加上会持续积累的长期记忆

它能做什么：

- 记录对话和工具调用产生的新记忆
- 按语义、关键词、实体和时间检索记忆
- 对已有记忆做深度分析并建立关联
- 维护观察、心智模型和知识页
- 通过 SDK、REST API 或 MCP 接入 Agent

核心亮点：让 Agent 从记住对话走向持续学习。用 retain、recall、reflect 管理记忆：先提取事实与关系，再按多种策略检索，或基于积累内容形成更完整的判断。

适合谁：需要给聊天或任务型 Agent 加长期记忆、个性化和项目上下文的开发者
使用前准备：需要配置 LLM 提供商和 API 密钥；也可使用本地模型或兼容 OpenAI 的端点。

使用提醒：简单 n8n 等工作流可能用它过重；托管云与自部署的功能、费用和运维方式不同。

许可证：MIT

GitHub 搜索：vectorize-io/hindsight

02｜ai-engineering-from-scratch
从数学、模型到 Agent，把 AI 工程知识拆成可运行课程和可复用工具

它能做什么：

- 按课程路径学习数学、机器学习和深度学习
- 从零实现算法并对照生产库使用
- 运行课程代码并保存命令、输出和修改记录
- 沿 MCP 或 Agent Skills 专题路线学习
- 产出可安装的提示词、技能、Agent 和 MCP 服务

核心亮点：从原理推导到可复用 AI 工具。每节课都按理解问题、推导概念、手写实现、调用生产库和交付产物推进，把抽象知识变成可运行代码与可复用工具。

适合谁：想系统学习 AI 原理、工程方法，并通过代码积累可复用成果的学习者和开发者
使用前准备：需要会写代码；课程说明 Python 有帮助，并希望理解 AI 如何工作，而不只是调用 API。

使用提醒：课程不能保证通过 Claude 或 MCPA 认证；缺少 Node.js、npx、Python 或兼容主机时，真实主机实验无法完成。

许可证：MIT（Attribution appreciated, not required.）

03｜univer
把表格、文档和演示编辑能力嵌入自己的产品，并让浏览器与 Node.js 共用一套运行架构

它能做什么：

- 嵌入可编辑的表格、文档和演示界面
- 用插件组合、替换或延迟加载产品能力
- 在 Node.js 无界面处理工作簿和文档
- 通过 Facade API 操作工作簿、范围和公式
- 让 Agent 检查、修改并验证 Office 内容

核心亮点：浏览器编辑与 Node.js 处理共用一套架构。插件架构负责组合能力，Canvas 渲染复杂编辑界面，公式引擎处理计算，Facade API 则统一连接浏览器与 Node.js。

适合谁：要在 SaaS、内部工具、BI 或 AI 应用中嵌入 Office 编辑能力的前端和全栈团队
使用前准备：开发仓库需要 Node.js >=22.18 和 pnpm >=11；无界面运行支持 Node.js >=18.17.0。

使用提醒：实时协作、共享修订和 Worktree 工作流需要对应 Web SDK 与协作能力；功能可用性和许可证因特性而异。

许可证：Apache-2.0
