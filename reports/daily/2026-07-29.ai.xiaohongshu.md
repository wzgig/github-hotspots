01｜airi
把大模型装进可自托管的虚拟角色，让它陪你语音聊天、控制形象并参与游戏

它能做什么：

- 接收浏览器或 Discord 的语音输入
- 调用多种服务或本地方案合成语音
- 驱动 VRM 与 Live2D 模型动作
- 接入 Telegram 和 Discord 对话
- 参与 Minecraft 等游戏任务

核心亮点：让虚拟角色走出聊天框。它把大模型、语音输入输出、VRM 与 Live2D 角色和游戏连接放进同一套容器，让角色不只聊天，还能在设备与游戏场景中持续互动。

适合谁：想搭建自有数字伙伴、AI 虚拟主播，或研究语音交互与游戏智能体的开发者和创作者
使用前准备：开发网页端需先用 pnpm 安装依赖；桌面端需按 CONTRIBUTING 配置环境。

使用提醒：项目仍处早期开发阶段；Factorio、长期记忆与纯浏览器本地推理等部分能力仍在开发。

许可证：MIT

为什么本期上榜：过去 24 小时净增 +728 Star（历史快照核验）
GitHub 搜索：moeru-ai/airi

02｜ECC
给编程代理补上一套工程流程，让规划、测试、复核、安全检查和经验沉淀连续运转

它能做什么：

- 规划功能并生成可确认的实施方案
- 按测试驱动流程保留验证证据
- 调用独立上下文审查代码改动
- 扫描提示词、钩子、MCP 与权限配置
- 沉淀会话摘要、记忆和可复用技能

核心亮点：把代理开发变成验证闭环。它把计划、测试、实现、独立复核、验证和记忆串成固定流程，并用技能、代理、规则与钩子分别承接按需工作、委派、标准和自动检查。

适合谁：需要约束编程代理工作方式、统一团队开发流程，或审查代理配置安全性的研发团队
使用前准备：需按所用工具选择一种安装路径；Claude Code 插件要求 CLI v2.1.0 或更高版本。

使用提醒：同一工具不可叠加安装方式；Codex 尚无 Claude 式钩子能力，市场插件也可能无法完整加载技能。

许可证：MIT

为什么本期上榜：过去 24 小时净增 +623 Star（历史快照核验）
GitHub 搜索：affaan-m/ECC

03｜hermes-agent
让个人 AI 助手记住跨会话经验、自动改进技能，并从终端或聊天软件持续执行任务

它能做什么：

- 从复杂任务经验中创建并改进技能
- 搜索历史会话并摘要相关信息
- 定时执行报告、备份和审计任务
- 派生隔离子代理并行处理工作流
- 通过统一网关接入多种聊天平台

核心亮点：把任务经验变成可复用技能。它把会话记忆、定期提醒、技能生成与使用中改进连成闭环：完成复杂任务后沉淀经验，后续对话再检索并继续完善。

适合谁：需要长期个人助手、跨聊天平台任务入口，或想研究会学习和并行工作的智能体开发者
使用前准备：安装后需选择模型提供方并完成配置；安装器会准备 Python、Node.js、ripgrep 和 ffmpeg。

使用提醒：Termux 需使用专门的手动安装路径，完整依赖集合包含与 Android 不兼容的语音依赖。

许可证：MIT
