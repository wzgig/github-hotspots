01｜ego-lite
让 Codex、Claude Code 等智能体复用你的登录态，在独立浏览空间执行网页任务而不占用当前标签页

它能做什么：

- 继承 Chrome 登录、Cookie、扩展和书签
- 分配互不干扰的独立浏览空间
- 并行执行多个智能体网页任务
- 调用快照、填写、点击和导航工具
- 接管或停止正在运行的智能体空间

核心亮点：共享登录态，不争抢标签页。智能体通过 ego-browser 连接同一浏览器，在各自隔离空间读取页面快照并调用 JavaScript 工具；本人可继续浏览，也能随时接管或停止任务。

适合谁：需要让编码智能体代办网页操作，同时保留本人标签页和既有登录状态的开发者
使用前准备：目前仅支持 macOS；可下载应用或用 npx 添加 ego-browser skill。

使用提醒：Windows 和 Linux 尚在路线图中；Chrome 数据迁移需首次启动时由用户选择。

许可证：MIT

为什么本期上榜：过去 24 小时净增 +833 Star（历史快照核验）
GitHub 搜索：citrolabs/ego-lite

02｜open-code-review
把 Git 变更交给受约束的审查流水线和智能体，返回定位到具体代码行的结构化意见

它能做什么：

- 审查暂存、未暂存和未跟踪变更
- 比较分支范围或指定提交
- 扫描没有有效差异的完整文件
- 搜索代码库补充跨文件上下文
- 恢复中断的分支或提交审查

核心亮点：硬约束流水线配合智能体。工程逻辑负责选文件、组合关联文件、匹配规则和校正评论；智能体负责动态检索上下文与判断问题，让审查过程不只依赖自然语言提示。

适合谁：需要审查工作区、分支、提交或陌生代码目录，并希望减少漏审和位置偏移的研发团队
使用前准备：需要 Git >= 2.41；默认模式还需配置 LLM，委托模式除外。

使用提醒：项目明确以较低召回率换取更高精度，因此仍可能漏掉真实缺陷。

许可证：Apache-2.0

为什么本期上榜：过去 24 小时净增 +776 Star（历史快照核验）
GitHub 搜索：alibaba/open-code-review

03｜Chat2DB
把多种数据库连接、SQL 编辑和自选模型助手放进同一个本地工作区

它能做什么：

- 连接多种数据库并浏览元数据
- 编辑、补全、格式化并执行 SQL
- 生成、解释和优化 SQL
- 管理表和对象并就地编辑数据
- 导入导出数据并制作图表看板

核心亮点：数据库工作区内置 AI 助手。它把 SQL 编辑器、数据库对象管理和可视化放在本地客户端中，并允许接入自己的 AI 模型，用自然语言处理 SQL 编写与理解任务。

适合谁：需要跨数据库写 SQL、维护表和数据，或借助自有模型分析查询的开发者、DBA 与分析人员
使用前准备：桌面版安装后可直接连接；Docker 部署需 Docker 19.03.0+、Compose 2.0.0+、2+ 核 CPU 和 4+ GiB 内存。

使用提醒：社区版是单用户本地应用，没有用户账户或用户间授权边界；HTTP 服务不得暴露给不可信网络。

许可证：source-available license（based on the Apache License 2.0 with additional conditions.）
