AI 项目的名字往往很抽象。这一期不堆术语，只讲清它替谁做什么、能完成哪些任务，以及是否值得加入你的工具箱。

01｜ponytail
ponytail 给 AI 编程助手加上精简规则，让它先找现成方案，再写必要的代码。

它能做什么：

- 引导助手优先复用已有代码和原生功能
- 审查当前改动并列出可删减项
- 检查整个仓库中的过度设计
- 汇总标记为延后处理的简化事项
- 切换精简强度或关闭规则

核心亮点：写代码前，先判断能否不写。先读相关代码、追踪实际流程，再依次判断是否必要、能否复用、能否用标准库或原生功能；找到够用的方案就停止加码，而不是一味压缩代码行数。

适合谁：用 AI 编程助手开发功能、审查改动，希望减少重复实现和过度设计的程序员。
使用前准备：需要能读取规则或加载技能的编程助手；命令依赖技能支持。Codex 安装后需信任生命周期钩子并新建会话。

使用提醒：仅加载规则的适配方式不提供命令；精简不能删掉校验、错误处理、安全或无障碍支持，费用与耗时也不保证下降。

许可证：MIT

02｜ECC
把每次重复交代的规划、测试、审查和交接步骤，变成 AI 编程助手可复用的工程流程。

它能做什么：

- 把功能需求整理成可编辑的实施计划
- 用先失败后通过的测试推进功能实现
- 在独立上下文中审查代码改动
- 保存可供不同编程助手读取的任务记忆
- 扫描智能体配置中的权限与注入风险

核心亮点：把编程过程变成可复核流程。技能提供可复用步骤，子智能体分别承担规划与审查，钩子在工具事件发生时执行检查，记忆保存交接信息，让计划、测试和复核不必每次靠提示词重建。

适合谁：用编程助手开发功能、修复缺陷，需要保留测试证据、独立审查和跨会话交接的软件团队。
使用前准备：通用包需 Node.js 18 或更新版；Claude 插件另需 Git 与 Claude Code 2.1.0+。扫描需预装经审查的扫描器。

使用提醒：各助手能力不齐；钩子需明确授权，记忆须核验。Windows 原生记忆写入有已知缺陷；同一助手勿叠加安装。私库托管分析属付费 Pro。

许可证：MIT

03｜OpenMontage
给出主题或参考视频，让 AI 编程助手沿着研究、脚本、素材和剪辑流程制作成片。

它能做什么：

- 分析参考视频并提出差异化制作方案
- 检索开放影像素材并剪成纪录蒙太奇
- 把长视频拆成排序后的短片
- 为已有视频制作翻译配音与字幕
- 在本地分镜板查看素材、成本和审批状态

核心亮点：边制作，边看分镜并确认。编程助手读取流程清单与阶段说明，调用工具完成研究、脚本、素材和合成。Backlot 分镜板从项目文件显示进度与成本，素材须经你确认后再进入渲染。

适合谁：想借助 AI 编程助手制作科普短片、产品演示，或将长视频改编成短内容的视频创作者。
使用前准备：需 Python 3.10+、FFmpeg、Node.js 18+，以及能读文件并执行 Python 的编程助手；HyperFrames 需 Node.js ≥

使用提醒：方案、脚本、分镜、素材与发布均需人工确认；付费云端生成与免费素材路线不同，本地视频生成需 GPU。全流程本地语言模型支持仍在计划中。

许可证：AGPL-3.0
