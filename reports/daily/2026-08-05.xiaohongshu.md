01｜pdf-inspector
先判断 PDF 是否需要 OCR，再把原生文本、表格和版面转成结构化 Markdown

它能做什么：

- 检测 PDF 类型并返回置信度
- 提取带坐标和字体信息的文本
- 还原多栏内容的顺序与从右到左文本
- 识别表格并转换为 Markdown
- 通过 Rust、Python、Node.js、浏览器或命令行调用

核心亮点：按页分流 OCR 的 PDF 解析。它先检查页面内容流，判断哪些页已有文本、哪些页需要 OCR；可直接解析的部分再经过版面、表格和 Markdown 流程，避免所有文档都走 OCR。

适合谁：需要在文档处理流程中筛选 OCR 任务，或提取报告、论文、发票等原生文本 PDF 的开发者
使用前准备：按使用方式准备 Rust、Python、Node.js 或浏览器环境；Python 源码安装需 maturin。

使用提醒：不执行 OCR；扫描件、图像型 PDF 或编码异常页面需要交给外部 OCR 流程。

许可证：MIT

02｜reverse-skill
把逆向、安全研究和授权测试任务路由到对应方法、工具与留证流程

它能做什么：

- 判断任务类型并匹配对应技能目录
- 初始化包含授权范围和网络配置的案例
- 检查并索引本机可用工具
- 编排 APK、二进制、恶意软件等分析流程
- 记录时间线、证据、发现和报告

核心亮点：先过授权范围再路由工具。任务先经过全局规则和案例初始化，确认授权范围与网络配置后，再进入场景技能、工具和脚本；过程持续记录时间线与证据链，减少临时猜命令。

适合谁：使用代码 AI 客户端处理授权逆向、安全研究、CTF 或渗透测试，并需要统一工作流程的人员
使用前准备：需 Java/JDK、Node.js 22.12+、Python 3.x，以及 Claude Code、Codex CLI、Cursor 等代码 AI 客户端。

使用提醒：在授权范围和网络配置就绪前不得对目标执行操作；集成工具仍受各自许可证约束。

许可证：MIT（**CTF-Sandbox-Orchestrator/**: **GNU GPLv3**）

03｜skills
给代码 AI 加上一组可组合的工程技能，用于澄清需求、测试、调试和控制代码复杂度

它能做什么：

- 追问需求并补齐未决分支
- 建立项目术语、上下文和架构决策记录
- 把对话整理成规格和可阻塞工单
- 按红绿重构循环实现与测试代码
- 诊断缺陷并从复现推进到回归测试

核心亮点：小技能组合成工程闭环。每项技能聚焦一个工程环节，可由用户调用或由模型按任务匹配；需求澄清、领域建模、规格拆分、测试实现和代码审查可以按需组合，而非由单套流程接管项目。

适合谁：希望保留工程决策控制权，并让 Claude Code、Codex 等代理按可检查流程完成开发任务的团队和个人
使用前准备：需使用 Claude Code 插件或 skills.sh 安装；每个仓库首次使用前运行 /setup-matt-pocock-skills。

使用提醒：两种安装方式不要同时使用，否则每项技能会重复；Claude Code 插件为托管只读包，skills.sh 版本可自行编辑。

许可证：MIT
