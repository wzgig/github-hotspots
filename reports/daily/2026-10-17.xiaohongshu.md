01｜rea
REA 让代理带着证据拆解应用、二进制与运行时行为，再复现目标功能

它能做什么：

- 分析原生二进制并返回伪代码与调用关系
- 拆解 JavaScript、Electron 应用的模块与 IPC
- 观察网站结构、脚本和网络行为
- 读取 APK、.NET 程序集与固件等工件
- 让代理根据证据解释行为并编写复现代码

核心亮点：让代理带证据拆解软件行为。REA 通过 MCP 把代理连接到多类分析工具，返回带证据和限制说明的结果，再用于追问、解释、实现和测试。

适合谁：需要分析应用、二进制或运行时行为，并据此复现功能的软件开发者与研究者
使用前准备：需要 Node.js 22.x、24.x 或 26+ 及 npm；部分分析还需对应工具。

使用提醒：静态 JavaScript 与 .NET 分析不运行应用；运行时捕获会按用户权限交互，商业工具需另行授权。

许可证：MIT（You must legally obtain and be authorized to use commercial tools）

02｜claude-plugins-official
为 Claude Code 集中浏览、安装和维护内部及第三方插件

它能做什么：

- 浏览内部与第三方插件目录
- 通过插件系统直接安装插件
- 按标准结构组织命令、代理和技能
- 让第三方插件提交到市场审核
- 用不可变名称维护已发布插件

核心亮点：把 Claude Code 插件放进可管理目录。目录把 Anthropic 内部插件与社区第三方插件分开管理，并统一提供插件元数据、MCP 配置、命令、代理、技能和文档入口。

适合谁：需要为 Claude Code 挑选、安装和维护插件的开发者与团队
使用前准备：需要使用 Claude Code 的插件系统；安装可通过插件命令或 Discover 界面完成。

使用提醒：安装、更新或使用前要信任插件；Anthropic 不控制其中的 MCP 服务器、文件或其他软件，也无法验证其行为。

许可证：Apache-2.0

为什么本期上榜：过去 24 小时净增 +1,627 Star（历史快照核验）
GitHub 搜索：anthropics/claude-plugins-official

03｜ECC
ECC 把编码代理的计划、测试、审查、记忆和安全检查串成一套工作流

它能做什么：

- 先生成计划再进入实现
- 用测试驱动开发验证改动
- 从新上下文复查代码
- 保存会话记忆并跨工具交接
- 扫描代理配置中的安全风险

核心亮点：给编码代理加上完整研发流程。ECC 把代理工作拆成计划、测试、实现、审查、验证、记忆和改进，并用 agents、skills、hooks、rules 组合成可复用流程。

适合谁：使用 Claude Code、Codex 等编码代理，希望固定研发流程的个人开发者和团队
使用前准备：通用安装需要 Node.js 18 或更新版本；Claude 插件还需要 Git 和 Claude Code 2.1 或更新版本。

使用提醒：不同代理的功能并不完全对齐；部分可选能力依赖 Bash、Python 或特定工具。

许可证：MIT
